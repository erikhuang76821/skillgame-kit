# Size Budget — 包體 5～10 MB 內

- **目標**：完整版磁碟大小 ≤ **8 MB**（硬上限 10 MB），首次下載 ≤ 3 MB
- **檢查**：`npm run build && npm run size`（`game/scripts/size-check.mjs`，超過 8 MB 直接失敗）

## 目前實測（原型 v0.2，2026-10-19）

| 類別 | 原始 | gzip | brotli |
|---|---|---|---|
| JS（遊戲 + PixiJS + GSAP，含 Pixi 延遲載入的 WebGPU / Canvas 後備分塊） | ~710 KB | ~230 KB | ~205 KB |
| 主視覺 WebP | 113 KB | — | — |
| UI 圖示 atlas（12 個） | 44 KB | — | — |
| 像素字型 Pixelify Sans（400 / 700，woff2 + woff 後備） | 36 KB | — | — |
| Sprite PNG（3 張） | 9 KB | — | — |
| **合計** | **~922 KB** | **~429 KB** | **~405 KB** |

## 完整版預算

| 類別 | 預算 | 備註 |
|---|---|---|
| 引擎 + 程式 | 1.0 MB | 目前 0.7 MB；Pixi 的 WebGPU/Canvas 分塊只在需要時載入 |
| 角色 sprite（3 英雄 × 5 動畫 × 8 方向） | 0.6 MB | 32×40 原生、PNG-8；單英雄全動畫約 150 KB |
| 敵人 / 頭目 | 0.4 MB | 一張 atlas，換色做變體 |
| 場景（3 地圖的 tile + prop） | 0.6 MB | tile 程式繪製為主 |
| UI 圖示、點陣字 | 0.3 MB | |
| 主視覺 / 商店圖 | 0.4 MB | WebP |
| 音樂 | 2.0 MB | Opus 循環 ×3（首包只帶 1 首，其餘延遲載入） |
| 音效 | 0 | Web Audio 合成 |
| 多語系 | 0.1 MB | 純文字 |
| **合計** | **5.4 MB** | 預留 2.6 MB 給活動內容 |

## 壓縮與載入

- 伺服器開 Brotli（文字資產再省 ~10%）；檔名含 hash，長期快取
- Sprite 不用 Basis/KTX2（像素圖會糊、檔案不會更小）
- 首包：引擎 + 程式 + 英雄 + Greyling + 第一張地圖 + 1 首音樂 ≈ 2.5 MB；其他地圖、頭目、英雄外觀在進大廳後背景載入

## 降低動態效果（同時是效能與無障礙設定）

| 項目 | HIGH | LOW / `prefers-reduced-motion` |
|---|---|---|
| 介面進場動畫（GSAP） | 0.25–0.7 s 淡入位移 | 不播放，直接出現 |
| Howl 衝擊波 | 0.35 s 擴散環 | 0.12 s 靜態環 |
| Perfect Dodge 星芒 | 上飄淡出 | 0.15 s 靜態 |
| 受傷畫面震動 | 有 | 無 |
| 敵人漂浮、走路上下晃、松果旋轉 | 有 | 無 |
| 濾鏡（模糊、發光、位移） | **永不使用** | — |
| 粒子 | 不做通用粒子系統；只有固定數量的程式 sprite | — |

切換：遊戲中按 Q（設定存在 localStorage），或跟隨系統「減少動態效果」。

**這些全部只影響渲染層**：模擬層（`sim/`）不知道特效等級，所以高低特效的玩家在同一種子上的結果完全相同（03 E2）。
