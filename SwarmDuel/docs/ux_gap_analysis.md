# 畫面吸睛度與 UI/UX 落差分析（v0.2）

- **目的**：對照直版 / survivor-like 競品，列出落差、已改善項目與下一步
- **對標**：Survivor.io（直版手遊 UI 標竿）、Vampire Survivors（打擊回饋與數字）、20 Minutes Till Dawn（夜間光照氛圍）
- **限制**：包體 ≤ 8 MB、不用濾鏡、降動態模式下仍要可讀；所有特效只在渲染層，不影響模擬（03 E2）

## 落差與處理

| 面向 | 競品做法 | v0.1 原型 | v0.2 改善 | 成本 |

## 原則（避免為了吸睛違反 skill game 精髓）

- 特效不得遮擋判定：敵人、飛彈、光束警示永遠在特效之上或清楚可辨
- 傷害數字只是裝飾；分數來源以結算明細為準
- 外觀付費項目不得改變判定範圍顯示（07）
- 低特效模式只拿掉「動態」，不拿掉「資訊」（血條、警示圈、倒數照常）
