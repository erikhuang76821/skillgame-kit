## 6. 法規版圖

### 6.1 州別限制（各來源不一致，需上線前以法律意見確認）

| 來源（日期） | 禁止現金賽州 |
|---|---|
| Skillz 條款存檔（2025-05） | AR、CT、DE、LA、SD |
| Solitaire Cube / 21 Blitz App 頁（2026） | AR、CT、DE、IN、LA、ME、SD |
| Skillz Pool App 頁 | AZ、AR、CT、DE、IL、IN、LA、ME、MT、SC、SD、TN |
| terms.law 第三方分析（2026-04） | AZ、AR、CT、DE、IN、LA、ME、MT、SC、SD、TN、VT（可玩 38 州） |
| Pocket7Games（Avia, 2026） | AR、DE、LA、SC、SD、VT、波多黎各；牌類另禁 IN、ME |
| Bingo Clash（Avia, 2026） | AR、DE、LA、MI、SD、波多黎各 |
| Solitaire Cash（Papaya，評測） | AZ、IA、IN、LA、MA、MT、SC |
| Bingo Cash（Papaya，評測） | AZ、IA、LA、SC |
| WorldWinner App 頁（2026） | AR、CT、DE、LA、SD；牌類另禁 IN、ME |

- **所有來源共通**：AR、DE、LA、SD（CT 幾乎都有）。**常見加列**：AZ、MT、SC、TN、VT、IN、ME（牌類）、IA、MI。
- 法理：多數州採「主要因素測試（dominant factor test）」判定技巧 vs 機率；佛州法條文字上禁止對技巧賽下注但豁免「僅參賽者出資」的錦標賽；各州標準不同。
- 平台以 GPS / IP 地理圍欄執行；Skillz 坦承未取得任何證明其合規的執照或核准（10-K）。

## 7. 新作設計教訓

| # | 教訓 | 依據 |
|---|---|---|
| 1 | **同種子＋非同步**是公平核心：雙方同牌序 / 同盤面 / 同道具，才能宣稱「技巧決勝」 | Tether 各作官方規則一致採用 |
| 2 | **嚴禁未揭露 bot**；若需填場，AI 對手必須明示且不得進入現金池 | Papaya $7.19 億判決、Avia 集體訴訟 |
| 3 | 接受配對等待：Skillz 曾等 10 分鐘以上，Papaya 以 bot 換「即時」— 改用多人非同步錦標賽（6~20 人）提升流動性 | Casino.org 庭審報導 |
| 4 | 計分要「可拆解、有上限」：基礎分＋連擊＋時間獎勵，方便平衡與異常偵測（如 Solitaire Cube 滿分 3,220＋1,200） | Tether 規則 |
| 5 | 速度權重依品類調整：接龍 / 21 點時間分占 25~30%，文字類僅 ≤60 分 | Tether 規則 |
| 6 | 局長 1~5 分鐘；賓果 2 分、21 點 3 分、接龍 5 分 | 各作規則 |
| 7 | 用道具 / 加成條獎勵正確操作（賓果塗記充能），讓技巧好的人拿更多道具 | Blackout Bingo、Bingo Cash |
| 8 | 失誤要有明確代價（3 次爆牌出局、誤塗扣分、超額回收 −20） | 21 Blitz、Solitaire Cube |
| 9 | 頭部集中＝平台風險：Skillz 70% 營收來自 3 款、2 家開發商，Tether 一離開即動搖 | 10-K |
| 10 | 牌類受州限制較多（IN、ME）；選題時考慮非撲克牌包裝（例：Yatzy Royale 改用牌反而增加限制） | App 頁州表 |
| 11 | 防「再玩一次」誤觸高入場費等 UX 陷阱，信任是此品類最大資產 | 21 Blitz 使用者評論 |
| 12 | 規則透明：每局提供「Rules」與計分明細、公開滿分理論值 | Papaya Rules 鈕、Tether 規則頁 |
