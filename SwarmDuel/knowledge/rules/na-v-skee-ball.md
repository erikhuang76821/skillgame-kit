# Skee-Ball（Skee-Ball Live / Classic）

- **代號**：na-v-skee-ball
- **市場**：北美（FEC、海濱遊樂場、酒吧聯賽、保齡球館）
- **形態**：票券兌換（ticket redemption）技巧機 / 酒吧社交運動
- **代表產品 / 廠商**：Skee-Ball Classic、Skee-Ball Glow、Skee-Ball Live（連網版，型號年份未證實）— Bay Tek Entertainment（2016 收購 Skee-Ball 品牌）
- **熱度依據**：1908 年專利至今；北美 FEC 標配；Brewskee-Ball 等全國酒吧聯賽
- **技巧 vs 運氣**：技巧主導（力道與方向一致性）；物理彈跳有少量變異

## 一句話玩法

把 9 顆球沿斜坡滾上跳台，落入越小越高的環洞得分，分數換票券。

## 規則書

### 勝負條件
- 單人：分數越高、票券越多；機台可設高分獎勵（打破當日/歷史最高分給大量票）。
- 多人並排：同時開局比總分（酒吧聯賽採回合制對戰）。

### 單局流程
1. 投幣/刷卡（價格由營運商設定，未證實）。
2. 釋放 9 顆球（傳統規格，各機型可設定）。
3. 逐球從球道底端滾出，經跳台（ball-hop）彈入目標區。
4. 每球進洞即時加分；未進高環則落入最低分區（10 分環/溝）。
5. 9 球結束 → 依分數門檻出票（遊戲中或結束時發放）。

### 計分規則
| 目標 | 分數 |
|---|---|
| 外環 | 10 |
| 第二環 | 20 |
| 第三環 | 30 |
| 第四環 | 40 |
| 中央最小洞 | 50 |
| 左右上角洞（現代機台才有） | 100 |
| 理論最高（9 球全 100） | 900 |
| 票券 | 依分數門檻發放，倍率由營運商設定（未證實具體表） |

- 分數環數值為業界慣例（Wikipedia 僅確認「越高越小越值錢」與兩個 100 分角洞，10–50 數值依通行版本，未證實逐機型）。

### 操作
- 手持球、下手滾球；球道長約 10～13 英尺（街機版較短）。
- 無電子操控；Live 版加入螢幕模式、連網對戰（未證實細節）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 純物理；結果由玩家出手決定。
- 營運商只能調整票券對分數的兌換率與高分獎門檻，不影響得分本身。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 出手力道一致性 | 決定落在哪一環 |
| 路線選擇（直攻 50 / 打角 100） | 高風險高報酬 |
| 利用側牆反彈 | 進 100 分角洞常用手法 |
| 節奏 | 部分機台限時，快速出手 |

## 隨機 / 運氣來源

- 球與跳台、環邊的彈跳變異。

## 參賽與變現

- FEC：單局付費 → 票券 → 兌換櫃台小獎（業者以票券成本率控制毛利）。
- 酒吧聯賽：報名費、賽季制，社交為主（Brewskee-Ball 為代表）。

## 主題與美術風格

- 經典木質/海濱嘉年華風；Glow 版霓虹燈光；Live 版加大螢幕與動畫。
- 復古、懷舊、全家同樂定位。

## 可借用的設計點

- 「同心環 + 角落高分」的風險選擇：簡單、易懂、可量化技巧。
- 純物理技巧 + 票券兌換 = 法規最安全的現金外變現路線。
- 數位化疊加（螢幕任務、連網對戰）延長經典玩法生命週期。

## 法規 / 風險備註

- 純技巧票券兌換機，各州普遍許可；兌換獎品仍受各州「非現金、價值上限」規範。
