# 籃球機與體感技巧機台（Arcade Basketball，附：拳擊機、音樂節奏機）

- **代號**：tw-basketball-arcade
- **市場**：台灣
- **形態**：店面技巧機台（普通級遊藝場、夜市、百貨遊樂場、KTV／商場角落）
- **代表產品 / 廠商**：各式投籃機（台灣、中國、日本 Namco 等製造）；拳擊機（打擊力量測試）；音樂節奏機：太鼓之達人（BANDAI NAMCO）、maimai DX（SEGA）
- **熱度依據**：湯姆熊（50 多店）、大魯閣遊戲愛樂園（10 據點）等連鎖必備品類；夜市「投籃換獎品」攤長青；營收數據（未證實）
- **技巧 vs 運氣**：技巧主導（純物理準度／體能／節奏），隨機極少

## 一句話玩法

限時內盡量把籃球投進會移動的籃框，分數過關卡門檻即延長時間並換彩票。

## 規則書

### 勝負條件
- 在每關時限內達到**過關分數**才能進下一關；最終分數換算彩票或登上排行榜。

### 單局流程（以常見 3 關式投籃機為例，數值（未證實），依機台設定）
1. 投幣（常見 NT$20–50）；部分機台可選單人／雙人連線對戰。
2. 第 1 關：約 40–60 秒，籃框固定；每球 2 分。
3. 達門檻（例 60–80 分）→ 第 2 關：籃框左右移動，門檻提高。
4. 第 3 關：籃框移動更快或前後移動；**最後 10 秒每球 3 分**（常見「最後衝刺」）。
5. 時間到結算：分數 → 彩票張數；破紀錄顯示於最高分榜。

### 計分規則
| 項目 | 常見設定（（未證實）） |
|---|---|
| 一般進球 | 2 分 |
| 最後衝刺 | 3 分（最後 10 秒或特定關） |
| 過關門檻 | 逐關上升，可由店家調整 |
| 彩票 | 依總分級距給票；普通級遊藝場獎品每次兌換價值 ≤ NT$1,000 |
| 連線對戰 | 2–4 台同步，比總分 |

### 操作
- 雙手投籃；球自動回流。拳擊機：單擊打擊沙包測力量分數。太鼓：鼓面（咚）與鼓邊（咔）依譜面敲擊，判定「良／可／不可」，魂量表達標即過關。maimai：圓形觸控螢幕＋8 顆按鍵。

### 公平機制（同種子、同牌序、配對、防作弊）
- 物理感測（光柵計球）；店家可調整門檻與彩票比，但需經評鑑分類、不得改機。
- 音遊：線上排行榜、卡片記錄（Aime／Banapass），全國統一曲譜。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 出手節奏（雙手輪流、一秒一球） | 決定總進球數 |
| 移動框預判 | 第 2/3 關命中率 |
| 體能分配 | 保留最後衝刺 |
| 節奏與讀譜（音遊） | 精準度與連段 |

## 隨機 / 運氣來源

- 球彈框的物理變異；機台調整差異。極低。

## 參賽與變現

- 單次付費 + 彩票兌換禮品；店家排行榜活動（月冠軍送獎品，需注意獎品價值上限）。音遊有官方大賽（例：maimai 有 WEC 等世界賽），台灣區賽事情況（未證實）。

## 主題與美術風格

- 運動風（NBA 風球場、霓虹計分板）；音遊為日系動漫、VOCALOID、流行曲；拳擊機常用怪獸／格鬥角色。

## 可借用的設計點

- **關卡門檻延長時間**：技巧直接換「多玩時間」，是最乾淨的技巧回饋。
- **最後衝刺加分**：結尾高潮。
- **連線同步對戰**：鄰台 PvP，旁觀性強。
- **全國排行榜＋卡片存檔**：音遊模式的長線技巧成長。
- **彩票→禮品**：技巧型獎勵的合法框架（價值有上限）。

## 法規 / 風險備註

- 普通級電子遊戲場僅能放益智類機具；未滿 15 歲上課時間與 22:00 後禁入；代幣不得仿真幣、不得直接收現金或信用卡投機。
- 獎品不得為現金或有價證券，不得買回。
