# 快艇骰皇家版（Yatzy Royale）

- **代號**：na-m-yatzy-royale
- **市場**：北美
- **形態**：手機現金錦標賽（非同步 1v1 / 多人錦標賽，Skillz 平台）
- **代表產品 / 廠商**：Yatzy Royale — Tether Studios（Skillz）；同類「Yahtzee 式」現金遊戲尚有多款骰子版（市占未證實）
- **熱度依據**：Tether 為 Skillz 最大開發商（2025 年占 Skillz 營收 51%）；本作為其 Yahtzee 類代表（個別營收未證實）
- **技巧 vs 運氣**：中度技巧；抽牌有運氣，但雙方同牌序，勝負取決於保留與填格決策

## 一句話玩法

用撲克牌取代骰子的 Yahtzee：5 張牌換兩次，填 13 格計分表。

## 規則書

### 勝負條件
- 5 分鐘內比總分，高者勝；雙方牌序相同（每手牌都以相同順序發出），可能非同時遊玩。
- 平手處理：官方頁未說明（未證實）。

### 單局流程
1. 牌組：每花色 10、J、Q、K、A 共 20 張＋2 張鬼牌 = 22 張；每手重新洗牌（雙方相同）。
2. 每手先拿 5 張 → 選擇保留（Hold）→ 其餘換牌（第 1 次「擲」）→ 可再換第 2 次 → 之後必須打出。
3. 下一次抽牌的第一張會顯示在手牌右側（可預知 1 張）。
4. 將手牌填入計分表一個空格；每格只能用一次。不符合任何空格要求 → 「Burn」該格得 0。
5. 13 格填滿或 5 分鐘到即結束。

### 計分規則
牌面值：10=10、J=20、Q=30、K=40、A 與鬼牌=50。

| 格子 | 分數 / 條件 |
|---|---|
| 上半區 10 / J / Q / K / A | 只計該牌型的牌面值總和 |
| Sum | 5 張牌面值總和 |
| 3 of a Kind | 三條的牌面值＋另外兩張 |
| 4 of a Kind | 四條的牌面值＋另一張 |
| 5 of a Kind | 固定 750 |
| Small Run（4 張連續） | 固定 200 |
| Large Run（10→A 五張連續） | 固定 400 |
| Full House | 固定 300 |
| Royal Flush（同花 10→A） | 固定 500 |
| 5 of a Kind / Royal Flush 重複出現 | 可再填入其他符合條件的格並得額外獎勵（額度未公開，未證實）；例：第二次五條可填 3 of a Kind 格，但不能填 Full House |
| 上半區獎勵 | 上半區 ≥450 分 +350（每種牌各 3 張剛好達標） |
| 全卡獎勵 Full Card | 全程無 Burn +500 |
| 時間獎勵 | 官方頁未提（未證實） |
| 官方參考 | >5,000 優秀；>6,000 驚人 |

### 操作
- 點牌切換保留；按鈕換牌；點計分表空格填入（顯示預估分數）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 雙方每一手都同牌序（同種子）；技術分配對；地理圍欄、18+。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 保留策略 | 追五條（750）或順子（400）的機率判斷 |
| 填格順序 | 早期避免浪費高價值格；保留 Sum 作安全格 |
| 上半區 450 門檻管理 | +350 獎勵 |
| 避免 Burn | +500 全卡獎勵 |
| 利用「下一張預覽」 | 減少換牌不確定性 |
| 時間管理 | 5 分鐘內填完 13 格 |

## 隨機 / 運氣來源

- 抽牌隨機；因雙方同牌序，同樣決策會得到同樣結果，運氣差主要來自「不同決策走到不同牌」的分岔。

## 參賽與變現

- Skillz 經濟（現金 / Bonus Cash、Z 幣、Ticketz）。
- 牌類遊戲在部分州（IN、ME）另有限制（同 Tether 牌類作品）。

## 主題與美術風格

- 皇家 / 宮廷金色主題（「Royale」）、撲克牌面＋皇冠徽章；Vegas-lite 但無老虎機元素。

## 可借用的設計點

- 「骰子 → 撲克牌」：同樣機率玩法，但可用「同牌序」實現雙方完全相同的隨機，比擬骰子更易保證公平與可重播。
- 22 張小牌組（只用 10~A＋鬼牌）讓五條、順子機率可控、節奏快。
- 「預覽下一張」提供可學習的資訊技巧。
- 固定分＋浮動分混合計分表，兼具保底與追高。

## 法規 / 風險備註

- 以撲克牌呈現可能被部分州視為「牌類遊戲」而套用較嚴限制（IN、ME 的牌類禁令）。
- Tether 與 Skillz 合約爭議進行中。
