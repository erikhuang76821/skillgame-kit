# 跑跑卡丁車（KartRider：Rush+ / Drift / 經典）＋ Garena 極速領域

- **代號**：tw-kartrider
- **市場**：台灣
- **形態**：線上 F2P 競速（手機為主；PC 版已停服）
- **代表產品 / 廠商**：
  - 《跑跑卡丁車 RUSH+》（手機，NEXON）——目前台灣仍在營運的主力版本。
  - 《跑跑卡丁車：飄移》（KartRider: Drift，Nitro Studio／NEXON）——2023-01-12 上市；全球跨平台版 2025-02-27 停止；韓、台 PC 版 **2025-10-16 停服**；開發商 2025-10-21 申請破產。
  - 原版 PC《跑跑卡丁車》台服——2007 年公測；2022-11-01 停止新帳號註冊，**2023-01-31 關服**（原因是代理合約到期）。
  - 《跑跑卡丁車》經典版——NEXON 2026-06 在韓國公開前導站，名稱沿用《跑跑卡丁車》；台灣時程（未證實）。
  - 《Garena 極速領域》（天美開發、Garena 代理台港澳）——同類手機賽車，主打競速與道具雙模式。
- **熱度依據**：跑跑卡丁車是台灣 2000 年代代表性的國民線上遊戲，台灣選手（如「爆哥」）曾在國際賽擊敗韓國奪冠，停服新聞引發大量「告別童年」討論；Rush+ 國際版事前預約破 500 萬（年份未標，（未證實））；極速領域 App Store 台灣 3.9 分／8.4 萬則評分、賽車類免費榜第 7（2026-10 快照）。Rush+ 在台灣 2024–2026 的營收名次（未證實）
- **技巧 vs 運氣**：**競速賽（Speed）＝技巧主導**（同車道、無道具，比路線與甩尾）；**道具賽（Item）＝技巧＋明顯運氣**（隨機道具箱、落後補償）。另外，車輛性能差異會造成養成或付費落差

## 一句話玩法

最多 8 人同場賽車，靠甩尾集氣加速（N2O），先完成指定圈數者勝。

## 規則書

### 勝負條件
- **個人競速**：依抵達終點名次排序，第 1 名勝。
- **組隊競速**：以全隊成員名次換算積分總和比較；跑跑卡丁車聯賽常見名次積分為 10／8／6／5／4／3／2／1（未證實，依賽制）。
- **完賽倒數**：第 1 名抵達後，其他人需在倒數時間內完賽，否則記為未完賽（Retire）；倒數秒數（未證實）。
- **道具個人賽變體**（2025-01-09～01-23 限時）：新增「搶旗」（拿到旗子後率先帶回終點）與「收集硬幣」（硬幣數＋抵達順序加成計總分）兩種勝利條件。

### 單局流程
1. 配對 → 選車（Rush+ 的 Ultimate Item 模式中，每隊可先 ban 掉對手 1 台車）。
2. 起跑倒數；起跑瞬間按加速可獲得起步加速（未證實具體判定窗）。
3. 跑完指定圈數（依賽道，（未證實））。
4. 競速賽：甩尾累積氮氣量表 → 施放 N2O 加速；碰撞、撞牆會掉速。
5. 道具賽：經過道具箱隨機取得攻擊（飛彈、水球…）、防禦（護盾）、加速類道具並施放。
6. 依名次結算排位分／經驗與獎勵。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| Rush+ Ultimate Speed（2026-05 S39 新排位） | 8 人競速；勝利後可選擇「鎖定」排位分，或挑戰最多 **4 連勝**換取大量加分 |
| Rush+ Ultimate Item | **3v3** 道具賽；開局每隊 ban 對方 1 台車 |
| Rush+ Ultimate League | 只開放 **Master** 以上段位 |
| Rush+ 段位 | 銅牌 → … → 傳奇（Living Legend）（App Store 描述；完整階層與分數（未證實）） |
| Rush+ 駕照 | Pro 駕照最長 **180 天**，兩類任務都完成才能續期，未續期降回 L1；L1／L2 考試降低難度 |
| Rush+ 每日首勝 | 排位賽每日首勝有活動獎勵（S26「史詩世紀」活動例，年份（未證實）；S33「電音疾馳」於 6-25 更新） |
| 極速領域單局 | 約 3 分鐘；模式含標準競速、標準道具、排位、超能、時空賽，另有 2v2 足球、3v3 塗鴉、2v6 非對稱追逐、24／48 人淘汰活動 |

### 操作
- 手機：左右轉向、甩尾鍵、N2O 鍵、道具鍵（道具賽）；常見技術有連續甩尾、短甩、「拖曳加速」（未證實命名）。

### 公平機制（同種子、同牌序、配對、防作弊）
- **競速賽**：所有人同一條賽道、同時起跑，沒有隨機元素——這是最公平的模式。
- **配對**：依段位／排位分配對（細節（未證實））。
- **車輛性能落差**：車輛分稀有度與性能等級，高階車可抽卡或購買取得，是「付費／養成影響勝負」的主要爭議點；Ultimate Item 的 ban 車制度是部分緩解（未證實官方說法）。
- **駕照制度**：需通過駕照考試才能進入高階賽事，防止新手被高手輾壓。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 路線與過彎線（Racing line） | 競速賽的核心 |
| 甩尾集氣效率、N2O 時機 | 直接決定圈速 |
| 碰撞迴避 | 8 人混戰時保持速度 |
| 道具時機（領先時保留防禦、落後時保留攻擊） | 道具賽技巧，但上限受運氣限制 |
| 團隊配合（組隊時的卡位、護送王牌） | 組隊賽決勝 |

## 隨機 / 運氣來源

- **道具賽**：道具箱的內容是隨機的；玩家普遍觀察到名次與道具分布有關（落後者較容易拿到強力攻擊道具，屬玩家經驗，官方權重（未證實））。結果是領先者可能被一發逆轉——這是「娛樂性 > 公平性」的設計。
- 物理碰撞的混沌性（兩種模式都有）。
- 抽車（Gacha）取得的車輛性能差。
- **結論**：本知識庫只把「競速賽」視為純技巧格式；道具賽屬於技巧＋運氣混合。

## 參賽與變現

- 賽季通行證、抽車（Gacha）、角色與車輛外觀、VIP；排位每日首勝獎勵。
- 極速領域 App Store 台灣內購約 NT$33–1,690（2026-10 頁面）。

## 主題與美術風格

- Q 版角色（達奧、蝶妮）、卡通賽車、主題賽道（森林、冰原、城堡）；季度主題（電音、海灘、史詩世紀）；跨品牌聯名（輪胎品牌等）。

## 可借用的設計點

- **把模式分成「純技巧」和「有道具」兩條軌道**：排位只計純技巧，休閒保留道具的爆笑逆轉，兩種客群都照顧到。
- **連勝挑戰（贏了可鎖分或續挑最多 4 連勝）**：自己選擇風險，張力高，而且不需要隨機。
- **對戰前 ban 車**：用 ban 機制降低付費強勢載具的影響。
- **駕照考試**：用技能門檻取代等級門檻，進階玩家的入場才有意義。
- **教訓**：Drift 跨平台大作的商業失敗加上兩度停服，說明台灣玩家對 IP 情懷的期待，比不上對「操作手感」與「營運穩定」的要求。

## 法規 / 風險備註

- 極速領域在台灣為輔 12 級（含服裝性暗示、虛擬戀愛／結婚）。Rush+ 台灣分級（未證實）。
- 抽車需公開機率（台灣定型化契約要求）。
- 停服退款：Drift 停服時針對付費商品提供退款安排——新作需預先規劃停服條款。
