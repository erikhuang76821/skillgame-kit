# 泡泡方塊 2（Bubble Cube 2）

- **代號**：na-m-bubble-cube-2
- **市場**：北美
- **形態**：手機現金錦標賽（非同步 1v1 / 多人錦標賽，Skillz 平台）
- **代表產品 / 廠商**：Bubble Cube 2 — Tether Studios（Skillz）；同類競品 Bubble Cash — Papaya Gaming（Papaya 兩大創始產品之一）
- **熱度依據**：Tether 為 Skillz 最大開發商（2025 年占 Skillz 營收 51%），Bubble Cube 2 為其泡泡射擊主力；Bubble Cash 為 Papaya 2019 年起家作之一（具體下載與營收未證實）
- **技巧 vs 運氣**：技巧主導；雙方同盤面、同彈匣（hopper）序列、同道具

## 一句話玩法

3 分鐘泡泡龍：同盤同彈序，拚長連鎖、倍率與清色。

## 規則書

### 勝負條件
- 比總分，高者勝；雙方可能非同時遊玩。
- 結束條件：清空所有泡泡、任何泡泡觸底、或 3 分鐘時間到。
- 平手處理：官方規則頁未說明（未證實）。

### 單局流程
1. 開局盤面隨機但雙方相同；**第一次射擊才開始計時**。
2. 彈匣（Hopper）顯示接下來的泡泡，雙方序列相同。
3. 射出泡泡，同色 3 顆以上相連即消除（標準泡泡龍規則；連結數門檻官方未明寫，未證實）。
4. 「連擊計數器（combo counter）」顯示還需幾次成功消除；若彈匣用完前未填滿 → 整個盤面下移一排（drop）。
5. 每局固定 1 種道具，雙方相同：炸彈、冰、彩虹。
6. 清空某顏色所有泡泡即「清色」，該色若仍出現在彈匣中則不能算清色。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 每發第一顆被打破的泡泡 | +10 |
| 連鎖距離遞增 | 鄰接 +20、下一圈 +30……每遠一圈 +10；長連鎖單顆可達 +1,000 以上 |
| 2x 倍率泡泡 | 乘上該連鎖價值；串接多個可達 4x、6x、8x |
| 連續命中 Streak | 2 連 +25、3 連 +40、4 連 +55，之後每多一發 +15 |
| 清色獎勵（乘在遊戲分上） | 清 1 色 +10%、2 色 +20%、3 色 +30%、4 色 +40%、5 色 +50%、6 色 +100% |
| 炸彈道具 | 爆炸消除周圍泡泡 |
| 冰道具 | 每回合向周圍擴張佔位 |
| 彩虹道具 | 變成擊中泡泡的顏色 |
| 剩餘時間獎勵 / 懲罰 | 官方頁未提（未證實） |
| 官方參考 | 20,000+ 好；100,000+ 優秀；300,000+「Bubble Master」 |

### 操作
- 點擊螢幕任意處射擊；按住拖曳可瞄準輔助線；可打牆反彈。

### 公平機制（同種子、同牌序、配對、防作弊）
- 同盤面、同彈匣序列、同新增泡泡、同道具（全由同一種子產生）。
- 技術分配對、地理圍欄、18+。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 打斷「根部」造成大面積掉落 | 距離遞增計分使長連鎖單顆可破千 |
| 串接 2x 泡泡 | 倍率可疊到 8x |
| 清色規劃 | 清 6 色可讓總分 ×2 |
| 維持連續命中 | Streak 加分且填滿 combo counter 避免盤面下壓 |
| 反彈角度 | 打到被擋住的目標 |

## 隨機 / 運氣來源

- 盤面與彈匣序列隨機但雙方相同；不同局間分數尺度差異極大（2 萬~30 萬），故只適合同局比較。

## 參賽與變現

- Skillz 經濟：現金 / Bonus Cash 入場、Z 幣練習、Ticketz；Bubble Cash（Papaya）則為多人錦標賽、Gems 練習。

## 主題與美術風格

- 高彩度寶石泡泡、方塊立體造型（「Cube」品牌系列一致性）、大量粒子與數字飛出特效。

## 可借用的設計點

- 「距離遞增計分」把「打掉落」這個高技巧動作變成指數級回報。
- 乘法型清色獎勵（最高 +100%）提供長線目標。
- 「彈匣用完前未達 combo 就下壓」：把失誤懲罰轉成壓力而非直接扣分。
- 每局隨機但雙方相同的單一道具：增加變化又不破壞公平。
- 分數尺度大（數十萬）帶來爽感，但需教學說明以免玩家誤判勝負。

## 法規 / 風險備註

- Papaya 的 Bubble Cash 為 Skillz v. Papaya 不實廣告案的涉案產品之一（bot 使用）。
- Tether 與 Skillz 合約爭議進行中（2025-09 起），平台歸屬可能變動。
