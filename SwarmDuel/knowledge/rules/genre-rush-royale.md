# 合成 PvP 塔防（Rush Royale 進擊的皇室／Random Dice 隨機骰子）

- **代號**：genre-rush-royale
- **市場**：台灣＋北美
- **形態**：線上 F2P 手遊，1v1 即時 PvP＋2 人合作 PvE；卡牌收集＋格子合成塔防
- **代表產品 / 廠商**：Rush Royale（台區名《進擊的皇室 - 骰子 塔防遊戲》）— IT Territory 開發、MY.GAMES 發行（2020-12-08）；Random Dice（台區名《隨機骰子：塔防》）— 111%（韓國）
- **熱度依據**：
  - **北美**：Rush Royale 美區 App Store 約 9.6 萬則評分、4.5 星、卡牌類免費榜 #174（2026-10）；2022 年營收約 1.02 億美元、累計下載逾 5,000 萬（Wikipedia，2022 數據）；2025-03 推出「幻影 PvP」新模式仍持續營運。Random Dice 北美熱度數據未取得（未證實）。
  - **台灣**：Random Dice 台區約 5 萬則評分、4.1 星、策略類免費榜 #102（2026-10）——評分數遠高於 BTD6（約 1.6K）與 KR5（約 1.2K），是本類在台最大眾的作品。Rush Royale 台區約 4,867 則評分、卡牌類免費榜 #191。
- **技巧 vs 運氣**：**混合，運氣成分明顯**——召喚出哪種單位、合成後變成哪種單位、出現在哪一格皆為隨機；永久卡牌等級（付費 / 時間累積）直接影響傷害。原版不符合本知識庫「純技巧」標準，收錄是因使用者指定且其框架可改造（見下方「去隨機化」）

## 一句話玩法

花魔力（SP）在 3×5 格子召喚隨機單位，兩個相同單位合成升階，擋住送往自己這邊的怪；擊殺的怪會送到對手那邊。

## 規則書

### 勝負條件
- PvP：先讓怪突破自己城門（耗盡生命）者敗（Rush Royale）。生命數常見說法為 3（未證實）。
- Random Dice PvP：比對手撐得久（生命數同樣常見說法為 3，未證實）。
- Rush Royale「鏡像對決」活動：12 勝封頂、累計 3 敗出局。

### 單局流程（Rush Royale）
1. 賽前：5 張卡組成牌組（常見配置 2 張主輸出＋3 張輔助）＋1 名英雄（新手預設「訓練師」，召喚會爆炸的稻草人減速）。
2. 開局：3×5 空格子；擊殺怪物獲得魔力。
3. **召喚**：按鈕一次，從牌組中隨機抽一種單位、放在隨機空格；每次召喚費用比上一次高（起始費與增幅未證實，社群常見說法 10 起、每次 +10）。
4. **合成**：兩個同種、同階單位疊合 → 變成高一階的**隨機**種類單位（牌組內）。
5. **強化**：局內花魔力為某卡種全場升級（費用遞增，未證實數值）。
6. **波次**：每波結束時清場剩餘小怪，出現 Boss（類型隨機）。
7. PvP：自己擊殺的怪會（部分）送到對手側，形成間接攻擊。

### 單局流程（Random Dice，差異點）
1. 5 顆骰子組成牌組，有 5 套牌組可切換。
2. SP 由擊殺取得；召喚隨機骰子到隨機格，費用持續上升，後期一次數百 SP。
3. 合成：同種且同點數的兩顆骰子 → 點數 +1、種類**隨機**改變。
4. 局內強化（Power Up）也花 SP，價格遞增、只在本局有效。
5. 擊殺怪物會送更多怪給對手。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 棋盤 | 3×5（Rush Royale；Random Dice 同為 15 格，未證實） |
| 牌組 | 5 張 / 5 顆 |
| 召喚 | 隨機種類＋隨機位置；費用逐次遞增（數值未證實） |
| 合成 | 同種同階 → 高一階、種類隨機 |
| 卡牌等級（局外） | Rush Royale 每升一張卡全帳號暴擊傷害 +2%（Funovus 分析） |
| 排位 | 勝場得獎盃、敗場扣；Random Dice 有賽季金獎盃押注 |
| 鏡像對決 | 雙方同牌組但**用各自的卡牌等級**；12 勝封頂、3 敗出局；重入場 100 紫鑽或 15,000 金幣 |
| 幻影 PvP（2025-03） | 帶 3 套牌組；Boss 波前死去的敵人化為幽靈，打幽靈的傷害會加給對手 Boss 血量；先清完該波 Boss 者全場獲得魔力加成；無死亡波、怪物護甲逐波上升；輸了不扣積分 |

### 操作
- 點「召喚」、拖曳單位到同種同階單位上合成、點卡圖示局內強化、點英雄技能。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原版：依獎盃配對；但卡牌等級、英雄等級、天賦是局外累積（可付費加速），鏡像對決也只統一牌組不統一等級——評論者認為等同付費優勢。
- Funovus 分析指出兩作在對手間幾乎沒有直接互動（只靠送怪），更像「各自拉霸」的單人體驗——對競技公平是重大缺陷。
- **去隨機化競技版設計**（本專案建議）：
  1. 全員固定等級（例如全卡 Lv.10、無天賦），只比操作。
  2. 召喚序列與合成結果用同一 seed：第 n 次召喚出的種類與格子、第 m 次合成的結果，兩名玩家完全一致。
  3. 或改為「看得見的牌庫」：顯示下 3 次召喚內容（類似俄羅斯方塊的 Next），把運氣轉成規劃。
  4. 怪物生成腳本固定；送怪量只依擊殺數。
  5. 計分：非同步比「存活波數 × 1000 + 剩餘生命 × 300 + 總傷害 / 1000」，或同步 1v1 比誰先倒。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 召喚 vs 強化的魔力分配 | 召喚加數量、強化加質量，費用都遞增 |
| 合成時機 | 太早合成浪費格子產出，太晚卡格子（攻略建議盤面滿再合） |
| 位置利用 | 部分單位效果依相鄰 / 位置觸發 |
| 牌組構築 | 主輸出 × 輔助（加魔力、換位、減速）的搭配 |
| Boss 前存魔力 | Boss 波需要爆發強化 |

## 隨機 / 運氣來源

- 召喚種類、召喚位置、合成結果種類、Boss 種類——全部隨機（核心樂趣即「抽到大獎」）。
- 局外卡牌等級（付費 / 時間）。
- 結論：原版**不能**直接作為公平技巧賽；需上述去隨機化改造。

- Rush Royale 台區：高級通行證 NT$430、水晶 NT$40–3,590。

- 主要營收引擎是**卡牌升級**（＝戰力），與純技巧競賽目標衝突。

## 主題與美術風格

- Rush Royale：Q 版奇幻（法師、騎士、精靈、龍），明亮卡通；有名人聯名（2023 Jake Paul）。
- Random Dice：極簡扁平「骰子」圖示，各色骰子＝不同屬性，介面乾淨、易讀。

## 可借用的設計點

- 「合成騰格子」：有限格子逼玩家在數量與品質間取捨。
- 「擊殺＝送怪給對手」：PvP 塔防最低成本的互動方式。
- 「召喚費遞增」：自然的通膨曲線，避免早期滾雪球。
- 幻影 PvP 的「先清 Boss 者得永久加成」：製造比速度的競爭點。
- 鏡像對決的「固定牌組」概念值得借用——但要連等級一起固定。

## 法規 / 風險備註

- 隨機召喚＋付費提升數值，在「純技巧」定位下屬高風險；若加入現金 / 兌換獎勵，可能被視為運氣主導（北美技巧遊戲判斷標準）。
- 台灣：隨機要素若與付費抽卡結合，需注意轉蛋機率揭露規範。
