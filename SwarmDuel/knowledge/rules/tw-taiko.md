- **代號**：tw-taiko
- **市場**：台灣
- **形態**：店面技巧機台（音樂節奏機；普通級遊藝場、百貨遊樂區）
- **代表產品 / 廠商**：太鼓の達人 ニジイロ Ver.（新筐體，2020-03-24 日本稼働，120fps）— BANDAI NAMCO Amusement；家用／手機：Switch 繁中版、《太鼓之達人 RHYTHM CONNECT》（LINE × 萬代南夢宮）
- **熱度依據**：
  - 湯姆熊（50 多店）、大魯閣遊戲愛樂園等連鎖常見機種（見 `tw-basketball-arcade.md`）；全台台數（未證實）。
  - 《RHYTHM CONNECT》2023-08 選在**台灣首發搶先體驗**，600 首以上曲目看廣告免費玩，並設計與街機／家用版連動（新頭殼、Saiganak）。
  - 台北國際電玩展 2026：萬代南夢宮舞台安排《太鼓之達人 咚咚雷音祭》玩家對戰（4Gamers）。
  - 系列 25 週年（2026）：與《初音未來 繽紛舞台》合作，2026-02-25～04-19 於中國大陸以外的街機版實施（Siliconera）。

- **技巧 vs 運氣**：純技巧（固定譜面、固定判定窗、固定配分），無隨機。

## 一句話玩法

依捲動譜面敲鼓面（咚）與鼓邊（咔），以判定精準度累積分數與「魂量表」，量表過線即通關。

## 規則書

### 勝負條件
- **通關（ノルマクリア）**：曲終時魂量表（魂ゲージ）達到通關線。
- **成績指標**：分數（天井約 1,000,000）、王冠、分數評價（Score Rank）。
- **段位道場**：連續 3 首課題曲，同時達成所有條件即「合格」。
- **對戰**：雙人同機（左右兩鼓）比分數；舞台活動／大會以分數或良數比勝負。

### 單局流程
1. 投幣（價格與每幣曲數依店家設定（未證實））；可刷 Banapass 卡保存紀錄。
2. 選曲 → 選難度：かんたん（★1–5）、ふつう（★1–7）、むずかしい（★1–8）、おに（★1–10），部分曲有「裏譜面」。
3. 選擇演奏選項（速度「はやさ」、隱藏、音符位置調整等；只影響視覺／手感，不改判定）。
4. 演奏：音符從右往左流到判定圈時敲擊；GOGO TIME 區段畫面特效加強（ニジイロ已無加分）。
5. **譜面分岐**：部分曲在分岐點依前段成績（良數、分數或連打數）切換「普通 / 玄人 / 達人」譜面。
6. 曲終結算：通關與否、分數、王冠、評價；寫入卡片。

### 計分規則
**判定窗（±ms，AC15／ニジイロ）**
| 難度 | 良 | 可 | 不可（判定邊界） |
|---|---|---|---|
| おに | ±25.025 | ±75.075 | ±108.442 |
| むずかしい・ふつう・かんたん | ±41.708 | ±108.442 | ±125.125 |

**配分（ニジイロ新制）**
| 項目 | 分數 / 條件 |
|---|---|
| 天井（滿分） | 約 1,000,000，與曲目難度無關；= 最大 Combo × 每音符分（初項）＋ 氣球／くすだま總打數 × 100 |
| 良 | 每音符固定分；每音符分與「總音符數」成反比（例：330 分） |
| 可 | 良的一半，個位數捨去（例：良 330 → 可 160） |
| 不可 | 0 分；Combo 歸零；已得分不扣 |
| 大音符（特良 / 特可） | 與一般良 / 可**同分**（不再額外加分） |
| 黃色連打（大小） | 每打 100 分 |
| 氣球、くすだま | 實際打數 × 100；打破無額外獎勵 |
| GOGO TIME 加成 / Combo 加成 | **皆已廢除**（ニジイロ） |

**魂量表與通關**
| 項目 | 條件 |
|---|---|
| 良 | 量表增加最多 |
| 可 | 增加量為良的一半 |
| 不可 | 量表小幅減少；音符越多的譜面，每顆增加越少、扣得越多 |
| 連打／氣球未打 | 不影響量表與 Combo，也不算不可 |
| 通關線 | おに 40 格、むずかしい / ふつう 35 格、かんたん 30 格（新 AC 一律）；量表滿格時「魂」字點亮 |

**王冠**
| 王冠 | 條件 |
|---|---|
| 銀（クリア） | 通關 |
| 金（フルコンボ） | 無「不可」通關 |
| 虹（ドンダフルコンボ） | 全良（漏特良仍算） |

**分數評價（7 段）**：粋（白／銅／銀）→ 雅（金／桃／紫）→ 極；門檻常見說法為 50 萬／60 萬／70 萬／80 萬／90 萬／95 萬／100 萬（未證實）。

**段位道場（ニジイロ）**
| 項目 | 內容 |
|---|---|
| 段位 | 五級～一級、初段～十段、玄人、名人、超人、達人 |
| 結構 | 3 首課題曲連續演奏 |
| 條件 | 必含魂量表，另加最多 3 項：良數、可數、不可數、連打數、叩けた数、分數、最大 Combo（可逐曲設定） |
| 合格等級 | 赤合格（基本）、金合格（各條件更嚴）；另依結果給銀／金／虹「框」 |
| 例：初段（2026） | 魂量表 赤 ≥97% / 金 100%；良 赤 ≥814 / 金 ≥862；不可 赤 <36 / 金 <18；連打 赤 ≥141 / 金 ≥158（總音符 1,189） |
| 更新 | 日本 2026 年版：五級～十段 2026-06-06 開放，玄人～達人 2026-09-12 開放；亞洲版時程（未證實） |

### 操作
- 兩支鼓棒；**紅音符（咚）**敲鼓面，**藍音符（咔）**敲鼓邊；大音符需雙手同時敲才算「特良」。
- 黃色長條＝連打（盡量快打），氣球＝打滿指定次數使其破裂。
- 兩台鼓並排，可雙人同時演奏。

### 公平機制（同種子、同牌序、配對、防作弊）
- **完全確定性**：同一譜面、同一判定窗、同一配分表；無隨機事件。
- **新制配分去除 Combo 與 GOGO 加成**：每顆音符等值，分數直接反映準確度，天井一致（約 100 萬）便於跨曲比較。
- **大音符不額外加分**：降低雙手同敲判定（受鼓況影響）對分數的權重（本條為設計推論）。
- 段位道場由官方統一課題曲與條件；Banapass 卡綁定紀錄。
- 機台維護差異（鼓面感度）是主要不公平來源，玩家社群常抱怨各店鼓況不一（未證實）。

| 技巧 | 影響 |

## 主題與美術風格

- 日本祭典＋Q 版吉祥物（小咚、小咔），色彩鮮豔、手繪感；選曲涵蓋 J-POP、動畫、VOCALOID、古典、遊戲音樂、原創曲。
- 判定字「良／可／不可」用漢字，具和風辨識度；虹王冠作為最高榮譽視覺。

## 可借用的設計點

- **固定天井配分**：每曲滿分一致，排行榜可跨曲比較、新手容易理解。
- **良＝2×可**：清楚的精準度梯度。
- **段位道場**：多條件（量表＋良數＋不可上限＋連打）組合考核，提供長線目標；赤／金兩級合格。
- **王冠三色**：通關、無失誤、全完美三層成就，簡單好懂。
- **譜面分岐**：依表現動態調整難度，同一首曲有多條路線。
- **實體「鼓」介面**：低門檻、圍觀性強，適合親子與聚會。
