# 氣球塔防（Bloons TD 6／Bloons TD Battles 2）

- **代號**：genre-bloons-td
- **市場**：台灣＋北美
- **形態**：BTD6＝付費單機 / 合作塔防（手機、Steam、主機）；BTDB2＝F2P 1v1 即時 PvP 塔防
- **代表產品 / 廠商**：Bloons TD 6、Bloons TD Battles 2 — Ninja Kiwi（紐西蘭）
- **熱度依據**：
  - **北美**：BTD6 美區 App Store 約 34.9 萬則評分、4.9 星、策略類付費榜 #1（US$6.99，2026-10 擷取）；Sensor Tower：2025 Q1 美區 iOS 塔防營收前五，週營收高峰約 14.7 萬美元（2 月初）。Steam 2025 月高峰同時在線 27,674（6 月）、歷史高峰約 5.38 萬。持續擴平台：PS4（2024-07）、付費 DLC Rogue Legends（2025-02）、Frontier Legends（2025-12）、Switch（2026-06）；至 2026-10 已 57 次大改版。BTDB2：Steam 約 2.48 萬則評論、83% 好評（2021-11 上線，F2P）。
  - **台灣**：BTD6 台灣 App Store 定價 NT$220、約 1,564 則評分、4.9 星、策略類付費榜 #38（2026-10 擷取）。蘋果公布的 2025 台灣付費 App 前三名未含遊戲類資料；BTD6 在台屬「小眾但口碑極高」的付費遊戲（推論）。
- **技巧 vs 運氣**：技巧主導；每回合氣球組成是固定腳本（同一模式同一回合內容相同），隨機只存在於少數塔的攻擊判定（例如機率觸發技能，未證實），競速活動已天然是同種子比賽

## 一句話玩法

在固定路線兩側放猴子塔，撐過固定腳本的氣球波次，漏一顆扣生命。

## 規則書

### 勝負條件
- BTD6：撐到該難度最終回合即勝；生命歸零即敗。
- BTDB2：雙方各一張對稱分割地圖，先把對手生命打到 0 者勝（詳見下方 PvP 規則）。

### 單局流程（BTD6 標準模式）
1. 選地圖 → 難度 → 模式；選英雄。
2. 起始金錢 $650（Race 活動規則頁明載；雙倍金錢模式為 $1,300 可佐證）。
3. 放塔、升級（每座塔 3 條升級路線，可兩路並升；最高 5 階，未證實細節以遊戲內為準）。
4. 按「開始」送出回合；氣球沿路線前進，被戳破的層數換金錢；回合結束另給獎勵金。
5. 漏網氣球依其強度扣除對應生命（越強的氣球扣越多）。
6. 第 50 回合後每次戳破的金錢收益遞減（第 51 回合起）。
7. 通關後可進入無盡「Freeplay」。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| Easy（標準） | 40 回合、200 生命；塔價 ×0.85（例：Dart Monkey $170） |
| Medium（標準） | 60 回合、150 生命；塔價基準（Dart Monkey $200） |
| Hard（標準） | 80 回合、100 生命；塔價約 ×1.08（Dart Monkey $215）；Fandom 稱自第 3 回合開始（未證實） |
| Impoppable | 第 6→100 回合、1 生命；塔價 ×1.2（Dart Monkey $240） |
| CHIMPS | 第 6→100 回合；禁止 Continue、生命補充、額外收入、猴子知識、道具、賣塔；生命數（未證實，常見說法 1） |
| 起始金錢 | $650（各模式另有規定者除外） |
| 戳破收益 | 約每層 $1，第 51 回合後遞減（相對比例見 wiki Double Cash 表） |
| 回合獎勵 | 每回合結束給獎勵金（BTD6 公式未證實；舊作為 $101 起每回合 +1） |
| 星等 / 獎章 | 依地圖 × 難度 × 模式通關給獎章（無分數制） |
| Race 活動 | 按下開始起計時，最快通關時間上全球榜；可提前送下一回合；禁用道具與雙倍金錢；每場約 4 天 |
| Boss 活動 | 第 40 回合起每 20 回合出現 Boss，比擊敗用時 |

### PvP：Bloons TD Battles 2 規則
| 項目 | 規則 |
|---|---|
| 起始 | 金錢 $650、收入（eco）250、生命 150 |
| 收入 | 每 6 秒獲得等於目前 eco 的金錢（不靠回合結算） |
| 送氣球（Bloon send） | 花錢把氣球送到對手路線；低階送兵會提高自己的 eco，高階送兵可能扣 eco |
| 送兵型態 | 分散 / 成群 / 緊密三種；同時最多 10 種可選、佇列 6 個 |
| 自然回合 | 雙方每回合自然出現相同的氣球 |
| 第 40 回合判定 | 生命多者勝（超過 150 的部分不計）；40 回合後任何漏失即敗（社群說法） |
| 驟死 | 第 40 回合生命相同 → 驟死再打 10 回合；打到第 51 回合仍相同 → 平手，不增減獎盃（社群討論，未證實） |
| 賽前選擇 | 1 名英雄＋3 種猴子塔 |
| 排位 | 9 個競技場，依段位配對；頂端 Hall of Masters 用 Elo 排行，賽季徽章 |

### 操作
- 點選塔 → 放置；點已放置塔 → 升級 / 改目標優先（第一 / 最後 / 最強 / 最近）/ 賣出。
- 調速（1× / 3×）、提前送下一回合。

### 公平機制（同種子、同牌序、配對、防作弊）
- 每回合氣球內容為固定腳本：同模式同回合所有玩家面對完全相同的敵人＝天生「同種子」。
- Race / Boss 活動：同地圖、同限制、同起始條件，比用時——已是可直接沿用的非同步競技格式。
- CHIMPS：禁用一切付費 / 外部加成（道具、猴子知識、雙倍金錢），是「排除付費優勢」的範本。
- BTDB2：Steam 頁面描述付費內容為外觀（裝扮、表情、皮膚）；依段位配對。但英雄 / 塔的解鎖進度是否形成新手劣勢未證實。
- 防作弊：Ninja Kiwi 帳號＋伺服器紀錄；競速榜作弊審查方式未公開（未證實）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 經濟規劃（早期農場 / 收入塔 vs 防守） | 決定中後期能否負擔 4–5 階塔 |
| 塔位與射程覆蓋 | 同一筆錢放在路線交會點效益可差數倍 |
| 針對性配置（迷彩、鉛、紫、MOAB 級） | 不同氣球屬性需要特定塔或升級，需預判回合腳本 |
| 提前送回合（競速） | Race 中決定名次的關鍵，風險是漏氣球 |
| PvP 送兵 eco 與壓制時機 | BTDB2 中「發展 vs 進攻」的核心取捨 |

## 隨機 / 運氣來源

- 標準模式幾乎無隨機（回合腳本固定）；少數塔 / 英雄有機率性效果（未證實）。
- BTDB2：對手送兵選擇是唯一「不確定性」，屬對局資訊而非運氣。
- 付費 Monkey Money 可買英雄、一次性道具、續關（PvE 有付費加成，競速 / CHIMPS 已禁用）。

## 參賽與變現

- BTD6：買斷 US$6.99 / NT$220＋內購（美區：Monkey Money US$1.99–19.99、全塔解鎖 US$4.99、Paragon 解鎖 US$4.99、猴子知識點 US$0.99/點、10 點 US$7.99）；付費 DLC（Rogue Legends、Frontier Legends）；Apple Arcade 版（BTD6+）與 Netflix 版。
- BTDB2：F2P；外觀內購＋賽季內容。
- 據 Steam 討論區轉述，Ninja Kiwi 2023 營收約 8,950 萬美元（未證實）。

## 主題與美術風格

- 卡通猴子 × 彩色氣球，鮮豔高飽和、無暴力流血，全年齡（老少咸宜）。
- 大量季節活動皮膚；英雄造型多樣（騎士、海盜、科學家）。

## 可借用的設計點

- 「固定回合腳本」：TD 天生適合同種子競賽，不需額外處理隨機。
- Race 格式：同條件、比用時、可提前送波＝高手天花板高，新手也能完賽。
- CHIMPS 式「純技巧模式」：明列禁用的付費 / 外部加成，給競技玩家信任感。
- BTDB2 的「eco 透過送兵增減」：把經濟和攻擊綁在同一個決策。
- 第 40 回合判生命＋驟死：給 PvP 一個保證結束的時間上限。

## 法規 / 風險備註

- BTD6 PvE 內購可買道具 / 續關，若做有獎競賽必須照 CHIMPS / Race 的方式全面禁用。
- 玩家曾抱怨 BTDB2 後期（40 回合後）卡頓與輸入延遲（社群說法）——即時 PvP 塔防要控制後期物件數量。
