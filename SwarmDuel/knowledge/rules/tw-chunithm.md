# CHUNITHM（CHUNITHM International ver.）

- **代號**：tw-chunithm
- **市場**：台灣
- **形態**：店面技巧機台（音樂節奏機：地面觸控滑條＋空中紅外線感測）
- **代表產品 / 廠商**：CHUNITHM International ver. — SEGA
- **熱度依據**：
  - **台灣是最早的海外市場之一**：首個海外版 CHUNITHM SUPERSTAR 於 2020-11-27 在台灣上線（新加坡 11-26、香港 12-02、韓國 12-09）（Wikipedia）。
  - 2022-03 起海外版改以日本「NEW!!」為基底並與日版同步路線（萌娘百科等，社群來源）。
  - 官方大賽 KING of Performai The 8th 設 CHUNITHM International ver. 部門；預選以「預賽① MASTER」「預賽② MASTER」兩組課題曲總分排名，2026-10-29～11-23 線上預選，2027-02-14 東京決賽。台灣是否列入報名地區（未證實）。
  - 台灣設機店數、台數：（未證實）。
- **技巧 vs 運氣**：分數純技巧；但「通關（CLEAR）」量表受角色技能影響（非隨機，但屬外掛加成）。

## 一句話玩法

在橫向觸控滑條上點、按、滑、撥音符，並在空中抬手觸發 AIR 音符，以準確度累積最高 1,010,000 分。

## 規則書

### 勝負條件
- **分數**：0～1,010,000；評價 D～SSS+。
- **CLEAR**：曲終前把量表填滿規定次數（所需量依曲目而異；高難度可填的量更多）；未達標為 FAILED。
- **連線對戰**：最多 4 台連線，每人演奏同曲；全員 FULL COMBO 以上可得「FULL CHAIN」；連線遊玩送第 4 首。
- **KOP 預選**：兩組 MASTER 課題曲合計分數排名。

### 單局流程
1. 投幣、刷 Aime 卡（價格與曲數依店家（未證實））。
2. 選地圖（Map）路線與角色（技能）、選曲、選難度：BASIC / ADVANCED / EXPERT / MASTER / ULTIMA；另有特殊模式 WORLD'S END（含不能打的音符、倒捲等特殊機制）。MASTER、ULTIMA 需先在 EXPERT 取得 S 評價或使用票券解鎖。
3. 演奏：音符從上往下落到判定線，依類型在滑條上操作或在空中揮手。
4. 結算：分數、評價、CLEAR／FULL COMBO／ALL JUSTICE 燈號、地圖前進格數。

### 計分規則
| 判定 | 準確度權重 |
|---|---|
| JUSTICE CRITICAL | 101% |
| JUSTICE | 100% |
| ATTACK | 50% |
| MISS | 0% |

- **分數** = 全曲平均準確度 × 10,000（滿分 101% → 1,010,000）。

| 評價 | 分數區間 |
|---|---|
| SSS+ | 1,009,000 – 1,010,000 |
| SSS | 1,007,500 – 1,008,999 |
| SS+ | 1,005,000 – 1,007,499 |
| SS | 1,000,000 – 1,004,999 |
| S+ | 990,000 – 999,999 |
| S | 975,000 – 989,999 |
| AAA | 950,000 – 974,999 |
| AA | 925,000 – 949,999 |
| A | 900,000 – 924,999 |
| BBB | 800,000 – 899,999 |
| BB | 700,000 – 799,999 |
| B | 600,000 – 699,999 |
| C | 500,000 – 599,999 |
| D | 0 – 499,999 |

| 燈號 | 條件 |
|---|---|
| CLEAR | 量表達到該曲要求 |
| FULL COMBO | 無 MISS |
| ALL JUSTICE | 全部 JUSTICE 以上 |
| ALL JUSTICE CRITICAL | 全部 JUSTICE CRITICAL（技能可對此給量表加成） |

- **Rating**：由分數與譜面「內部定數」（如 12.0–12.6，最高約 15.7）計算單曲值，再取最佳曲與近期遊玩的組合平均；精確斷點與採計曲數（未證實）。

### 操作
- **地面滑條**：橫向觸控面板（常見說法為 16 區（未證實））；TAP 點擊、HOLD 長按、SLIDE 滑動、FLICK 撥動（MASTER / ULTIMA 起有專用撥擊）。
- **AIR**：筐體兩側紅外線感測器，抬手（向上）或向下揮手觸發空中音符。
- 角色技能於選曲前裝備：提升 100 Combo、JUSTICE CRITICAL 或 AJC 時的量表增量；部分技能增益大但失誤懲罰更重。

### 公平機制（同種子、同牌序、配對、防作弊）
- **分數完全確定**：判定權重固定，分數與角色無關；排名、Rating、大會皆用分數。
- **CLEAR 與技能分離**：技能只影響量表（通關／地圖進度），不影響分數——把「收集養成」與「技巧排名」切開。
- 內部定數 Rating 使不同等級曲目可比較。
- 卡片綁定、官方網（CHUNITHM-NET）登錄成績；大會指定課題曲。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 時機精準度 | JUSTICE CRITICAL 比例決定 1,007,500（SSS）以上 |
| 雙手在滑條上的配置 | 高密度、交叉譜面 |
| AIR 動作節奏 | 空中音符與地面音符同時處理 |
| 讀譜與記譜 | ULTIMA / WORLD'S END 特殊機制 |
| 技能選擇 | 影響通關與地圖進度（不影響分數） |

## 隨機 / 運氣來源

- 無遊戲內隨機；部分技能可能含機率性效果（未證實）——只作用在量表。

## 參賽與變現

- 投幣按次；Aime 卡；遊戲內貨幣換票券，付費額外點數購買高級票券（加倍量表／地圖進度）。
- 角色、地圖、聯名活動驅動收集；KOP 大賽。

## 主題與美術風格

- 日系動漫美少女角色、科幻／學園地圖；選曲 VOCALOID、東方、動畫、遊戲曲與 SEGA 原創；筐體藍白色、大螢幕直立。

## 可借用的設計點

- **101% 判定（JUSTICE CRITICAL）**：100% 之上的 1% 給頂尖玩家。
- **「技能只影響通關、不影響分數」**：收集付費不破壞技巧排名的乾淨分層。
- **地圖進度**：每次遊玩都有可見的進度條，降低挫折感。
- **4 台連線同曲＋FULL CHAIN**：合作型成就（任一人失誤全隊斷鏈），增加社交。
- **地面＋空中雙層操作**：同一首曲兼顧手指精度與身體動作。

## 法規 / 風險備註

- 屬益智類電子遊戲機；機台介面正體中文規定（2025-10 修正）對海外英文版的影響（未證實）。
- 付費票券只改變量表與進度，不改分數；若在台灣推出類似設計需揭露付費道具效果，避免被認為影響競賽公平。
