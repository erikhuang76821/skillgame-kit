# 部落衝突：皇室戰爭（Clash Royale）

- **代號**：tw-clash-royale
- **市場**：台灣
- **形態**：手機線上 F2P 1v1 即時卡牌塔防（含 2v2）
- **代表產品 / 廠商**：《部落衝突：皇室戰爭》— Supercell
- **熱度依據**：App Store 台灣 4.3 分、7.8 萬則評分，動作類免費榜第 28（2026-10 快照）。全球 **2025 年是 2017 年以來最好的一年**：2025-07 月營收約 7,700 萬美元（年增 251%）、2025-10 月約 7,800 萬美元；累計約 49 億美元（十週年）；2025 年底週活躍玩家近 1.2 億（第三方報導）；CRL 2025 世界總決賽同時觀看峰值超過 69.8 萬。台灣：2026 GEG26 全球電競錦標賽中華代表隊選拔把本作列為正式項目。台灣營收名次（未證實）
- **技巧 vs 運氣**：技巧主導（聖水交換、卡牌循環、出牌位置與時機）；運氣來源是抽到的起手牌順序（8 張牌組隨機排序）與配對到的牌組相剋。卡牌等級是養成或付費落差，排位與賽事以等級上限來緩解

## 一句話玩法

用 8 張卡牌組成牌組，消耗會自動回復的聖水出兵，3 分鐘內摧毀比對方更多的塔。

## 規則書

### 勝負條件
- 每方 3 座塔：1 座國王塔＋2 座公主塔。
- **摧毀國王塔** → 立即獲勝（3 皇冠）。
- **正規時間 3 分鐘**結束時，摧毀塔數（皇冠）較多者勝。
- 平手 → **延長賽 2 分鐘**，先摧毀任一塔者勝（驟死）。
- 延長賽結束仍平手 → **Tiebreaker**：雙方所有塔快速等量扣血，血量最低的塔先倒，對方得 1 冠獲勝；若血量完全相同 → 和局。

### 單局流程
1. 帶入 8 張卡牌組；手上同時持有 4 張，打出一張後由牌組下一張補上（循環）。
2. 開局聖水 5 點（低信心來源，（未證實）），上限 **10**。
3. 聖水回復：單倍約每 **2.8 秒** 1 點；**最後 1 分鐘雙倍**（約 1.4 秒 1 點）；延長賽為雙倍，**延長賽最後 1 分鐘三倍**（2019-11 規則）。
4. 把卡牌放在己方半場（摧毀公主塔後可放進對方該側前場）；部隊自動沿路推進。
5. 國王塔在受到攻擊或任一公主塔被摧毀後啟動。
6. 依勝負條件結算盃數或排位進度。

### 計分規則（盃數與排位，2025-06 改版後）
| 項目 | 分數 / 條件 |
|---|---|
| Trophy Road 上限 | **10,000** 盃（9,000 解鎖 Valkalla 競技場、9,500 傳奇競技場） |
| 季節競技場 | 10,000–15,000 盃；勝 **+150**／敗 **−150** |
| 15,000 盃以上 | 勝 +30（只用於好友排行） |
| 賽季重置 | 依上季成績重置到 10,000–12,000（例：10,900 → 10,600；15,000 → 12,000） |
| 排位（Ranked，原 Path of Legends）入場 | 2025-06：當季季節競技場達 15,000 盃；2025-08 起：上季達到冠軍聯賽（Champion League） |
| 排位聯賽 | 移除 Challenger I–III，從 Master I 起算；共 7 個聯賽，最高為 Ultimate Champion（Wikipedia） |
| 排位卡牌等級上限 | 「新兵訓練營」賽季曾規定全聯賽卡牌與塔等級上限 **11**，並全季採 Mega Draft；常態上限（未證實）——另有文章提到 Path of Legends 曾上限 14 級後放寬 |
| 卡牌最高等級 | 15 級（Elite）（未證實，依版本） |
| 排位觀戰 | 排位、全球錦標賽、好友對戰關閉「聖水觀戰」，防止旁觀者報牌 |

### 操作
- 拖曳卡牌到場地放置；法術需要瞄準落點；Emote 表情互動。

### 公平機制（同種子、同牌序、配對、防作弊）
- **聖水對等**：雙方回復速率相同；資源公平，差異只在使用效率。
- **等級上限 / 標準化**：排位曾以等級 11 上限加輪抽（Mega Draft）消除養成差距；錦標賽常用「錦標賽標準等級」（未證實目前數值）。
- **盃數配對**：Trophy Road 依盃數配對；季節競技場 ±150 的大幅擺盪，讓實力快速歸位。
- **聖水觀戰關閉**：防止旁觀者用即時聖水資訊協助作弊。
- **Merge Tactics**（2025-06 新模式）：4 人回合制自走棋，雙方從相同卡池抽牌；但商店／抽牌有隨機性，不列入純技巧格式。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 聖水交換（Positive Elixir Trade） | 用更少聖水化解對手攻勢，累積優勢 |
| 卡牌循環計算（記住對手 4 張手牌） | 預判對手何時沒有反制牌 |
| 放置位置與時機（King Tower 拉怪、分推） | 直接決定攻防效率 |
| 雙倍／三倍聖水期的爆發 | 後期決勝 |
| 牌組構築與版本理解 | 克制關係 |

## 隨機 / 運氣來源

- 起手 4 張牌與補牌順序（牌組洗牌）。
- 配對到的對手牌組（相剋）。
- 少數卡牌有隨機要素（未證實具體卡牌）。
- 寶箱／Lucky Drop（只影響養成）。

## 參賽與變現

- 2019-07 起有月度賽季與 Pass Royale。
- **2025-04 移除寶箱計時器**，改為抽獎式「Lucky Drop」——帶動 2025 年營收復甦。
- 卡牌升級需金幣與卡片，可付費加速，是養成落差的來源。
- App Store 台灣內購約 NT$33–3,290（2026-10 頁面）。
- 電競：CRL（2018-08 成立；2021 起改為個人賽）；2025 世界總決賽獎金 50 萬美元，冠軍 Mohamed Light。

## 主題與美術風格

- 承接《部落衝突》世界觀：中世紀奇幻卡通（騎士、哥布林、巨人、法師），表情包式 Emote；季節主題競技場。

## 可借用的設計點

- **聖水（共用回復資源）＋ 4 張手牌循環**：每次出牌都是資源與資訊的交換，深度高、規則短。
- **三段式時間壓力**（單倍 → 雙倍 → 三倍）：保證單局在 3–5 分鐘內收斂。
- **Tiebreaker 依塔血量判定**：消除和局，又和場上表現掛鉤。
- **排位等級上限 + 輪抽**：「同一套數值的公平賽」與「養成的一般模式」分開。
- **關閉觀戰中的資源資訊**：小設計，大幅降低作弊空間。
- **營收教訓**：拿掉寶箱計時器、鼓勵每日對戰，反而讓營收回升——對戰頻率比卡時間更能賺錢。
