# 全黑賓果（Blackout Bingo）

- **代號**：na-m-blackout-bingo
- **市場**：北美
- **形態**：手機現金錦標賽（非同步 1v1 / 多人錦標賽，Skillz 平台）
- **代表產品 / 廠商**：Blackout Bingo - Win Real Cash — Big Run Studios 開發（App Store 2026-10 賣家欄顯示 Skillz Inc.）
- **熱度依據**：App Store 約 95K 則評分、4.5 星、Casino 類 #191（2026-10）；Skillz 10-K：與 Solitaire Cube、21 Blitz 合計占 2023 年營收 70%；Big Run 占 Skillz 2023 年營收 36%、2025 年 23%；2020 年 Skillz 稱其為平台第一名 Bingo 遊戲
- **技巧 vs 運氣**：技巧＋反應速度主導；雙方同球序同卡面，差在點擊速度、準確度與加成道具時機

## 一句話玩法

2 分鐘速度賓果：叫號滾動，搶快塗號、湊連線、用加成拚分。

## 規則書

### 勝負條件
- 2 分鐘內總分高者勝；雙方使用相同的賓果卡與相同的叫號序列。
- 一局可多次 Bingo。
- 平手處理：未公開（未證實）。

### 單局流程
1. 配對後開局，畫面上叫號依序滾過；玩家持 1 或 2 張賓果卡（依模式）。
2. 卡上有相符號碼即點擊塗記（daub）；越快塗記得分越多（速度獎勵）。
3. 每次正確塗記會充能「加成條（Powerup bar）」，滿格可取得 Boost。
4. 湊成 5 格一線（橫 / 直 / 斜，常見另含四角，未證實是否適用本作）時，要快速按「BINGO」鎖定得分。
5. 時間到即結算；使用時間加成可延長。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 正確塗記 | 得分，越快越高（確切數值未公開，未證實） |
| Bingo | 得分（數值未證實）；同格可貢獻多條線 |
| 錯誤塗記（未叫到的號） | 扣分（數值未證實） |
| 錯誤按 BINGO（未成線） | 扣分（數值未證實） |
| Golden Ball 加成 | 顯示最多 4 個號碼，選 1 個立即塗記；啟動時卡面暫時隱藏 |
| Free Daub 加成 | 任選一格塗記，不論是否叫到 |
| Time Boost 加成 | 計時器 +10 秒 |
| Double Points 加成 | 一段時間內得分 ×2（第三方評測稱約 10 秒，未證實） |
| 剩餘時間獎勵 | 是否存在未公開（未證實） |

### 操作
- 單點塗記；點擊 BINGO 按鈕領取；點擊加成圖示使用；雙卡模式需在兩張卡間快速切換視線。

### 公平機制（同種子、同牌序、配對、防作弊）
- 雙方相同卡面＋相同叫號序列（同種子）。
- Skillz 技術分配對、地理圍欄、18+（App 年齡分級 18+，標示含模擬賭博與競賽）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 反應速度 | 塗記越快分越高，也越快充能加成 |
| 準確度 | 誤塗、誤按 BINGO 直接扣分 |
| 加成時機 | Double Points 留到連線密集時、Time Boost 留到尾段 |
| Free Daub / Golden Ball 選格 | 選能同時完成多條線的格（四角、中心交叉點） |
| BINGO 即時確認 | 成線後快速領取 |

## 隨機 / 運氣來源

- 叫號序列與卡面隨機，但雙方相同；Golden Ball 給出的候選號碼（是否同種子未證實）。

## 參賽與變現

- Skillz 經濟：現金 / Bonus Cash 入場、Z 幣免費練習、Ticketz 兌換；有 1v1、錦標賽、排位賽。
- 現金賽約占美國 3/4 州可用（使用者評論，未證實）；詳見 _notes/na-mobile.md 州別表。

## 主題與美術風格

- 明亮糖果色、圓潤大按鈕、粗體數字；美式社區賓果氛圍＋手遊爆炸特效；曾與 NFL 球星 Marshawn Lynch 合辦「Beast Mode」錦標賽（2020），屬名人行銷。

## 可借用的設計點

- 把「被動等叫號」的賓果改成「速度＋準確度」技巧遊戲：塗記越快越多分、錯誤即扣分。
- 加成條由正確操作充能 → 技巧好的人拿到更多道具，強化技巧主導。
- 2 分鐘短局，適合通勤碎片時間。
- 「必須手動按 BINGO」增加一個可失誤、可搶快的決策點。

## 法規 / 風險備註

- Skillz 曾以本作類型對 AviaGames（Bingo Clash）提起專利與不正競爭訴訟，2024 年和解 $80M（Skillz 與 Big Run 共享）。
- 賓果在部分州被視為慈善博弈受監管；以「技巧賽」定位需確保速度與準確度確實決定勝負。
