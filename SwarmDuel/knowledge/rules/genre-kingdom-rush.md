# 王國保衛戰（Kingdom Rush 系列，代表作 Kingdom Rush 5: Alliance）

- **代號**：genre-kingdom-rush
- **市場**：台灣＋北美
- **形態**：付費單機塔防（手機買斷＋DLC / 英雄 / 塔內購；Steam；Apple Arcade 另有「+」版）
- **代表產品 / 廠商**：Kingdom Rush（2011）、Frontiers、Origins、Vengeance、Kingdom Rush 5: Alliance TD（2024-07-25）— Ironhide Game Studio（烏拉圭）
- **熱度依據**：
  - **北美**：KR5 美區 App Store 約 1.4 萬則評分、4.8 星、動作類付費榜 #44（US$6.99，2026-10 擷取）；Steam「極度好評 / 好評」（2026-03 第三方記 88% Very Positive）；第三方 AppGoblin 估 Apple Arcade 版 KR5+ 月活約 24.6 萬（估值）。系列持續推付費 DLC（Colossal Dwarfare、Wukong's Journey、Dragon Wars 各 US$8.99）。
  - **台灣**：KR5 台灣 App Store NT$220、約 1,189 則評分、4.9 星、策略類付費榜 #30（2026-10 擷取）；台灣媒體 / 部落格普遍把「王國保衛戰」列為塔防代表作，並有在地評論以「像王國保衛戰」形容其他作品（品類定義者地位）。無台灣營收數據（未證實）。
- **技巧 vs 運氣**：技巧主導；波次為固定腳本，戰鬥數值有少量隨機（傷害區間、暴擊類技能，未證實）

## 一句話玩法

在路邊固定塔位蓋四類塔、派兵擋路、施放主動技能，撐過固定波次不讓敵人進城。

## 規則書

### 勝負條件
- 戰役關卡：起始 20 條生命，撐完所有波次即勝；生命歸零即敗。
- 星等：剩 18–20 命＝3 星、6–17 命＝2 星、1–5 命＝1 星。
- 3 星通關後解鎖兩個挑戰：
  - **英雄挑戰（Heroic）**：只有 1 條命、6 波特殊敵人、專屬起始金、塔升級上限受限（前期關卡禁用英雄）；通關 +1 星。
  - **鋼鐵挑戰（Iron）**：1 條命、1 大波（wiki 列表推論）、限制可用塔種（未證實細節）；通關 +1 星。

### 單局流程
1. 選關 → 選難度（系列有休閒 / 普通 / 老兵，後作加「不可能」，名稱依作品，未證實）→ 選英雄。
2. 起始金（依關卡固定，未證實數值）。
3. 在預設塔位建塔；塔位數量固定，是核心限制。
4. 「呼叫下一波」：可提前呼叫，拿額外金幣並縮短技能冷卻（獎勵量依剩餘倒數而定，玩家回報「太早叫只有約 20 金」，未證實）。
5. 主動技能：火雨（範圍傷害）、援軍（召喚 2 名士兵擋路），有冷卻。
6. 敵人走到終點扣命（一般敵人 1 命，大型敵人更多，未證實）。

### 操作
- 點塔位 → 選塔；點塔 → 升級 / 賣 / 設兵營集結點。
- 拖曳英雄移動；點技能圖示 → 點地面施放。
- PC 快捷鍵：1＝火雨、2＝援軍、空白＝取消、P＝暫停。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原作無競技、無排行（以星數與成就為主）。
- 波次與出兵為固定腳本＝天然同種子。
- **付費強度問題**：KR5 內購販售英雄（US$6.99）、塔（US$4.99）、全塔包（US$19.99）——付費內容會直接影響通關難度。
- **競技化設計建議**：
  1. 「同關卡 × 同英雄 × 同可用塔」限定賽（類似鋼鐵挑戰），所有人用公版英雄 / 塔，抹平付費差。
  2. 計分：`剩餘生命 × 1000 + 剩餘金幣 + 提前呼叫總秒數 × 10`（鼓勵冒險提前叫波），或比 1 命挑戰的最快通關時間。
  3. 隨機數值（若有）以關卡 seed 固定。
  4. 伺服器以輸入紀錄（時間戳＋建塔 / 技能指令）重播驗證。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 塔位選擇（交叉火力點） | 塔位固定、數量有限，位置效益差異極大 |
| 兵營擋點 | 士兵把敵人卡在法師 / 砲塔射程內 |
| 物理 / 魔法搭配 | 重甲敵人要用法師塔、高魔抗要用物理 |
| 技能時機 | 火雨冷卻長，打在密集處或救急 |
| 提前呼叫風險 | 多賺金錢與冷卻 vs 被下一波壓垮 |
| 英雄微操 | 英雄可移動，補位與集火 |

## 隨機 / 運氣來源

- 波次固定；戰鬥中少量機率效果（暴擊、即死類技能等，未證實）。
- 付費英雄 / 塔帶來的強度差（非運氣，但影響公平）。

## 參賽與變現

- 買斷 US$6.99 / NT$220。
- 美區 KR5 內購（2026-10）：DLC 戰役各 US$8.99、英雄 US$6.99、單塔 US$4.99、Mega 塔包 US$14.99、全塔 US$19.99。

## 主題與美術風格

- 手繪卡通奇幻（中世紀王國、矮人、精靈、獸人、亡靈），Q 版比例、粗輪廓、溫暖色調。
- 大量流行文化彩蛋；全年齡但帶輕度戰鬥。

## 可借用的設計點

- 「固定塔位」：降低決策空間、提高每個決定的重量，適合手機與短局競技。
- 「兵營擋路」：把塔防從純輸出計算變成走位控制。
- 「提前呼叫換金錢＋冷卻」：讓高手用風險換節奏，天然的分數拉開器。
- 星等（18/6 門檻）＋解鎖英雄 / 鋼鐵挑戰：同一張地圖三種難度層，內容重複利用率高。
- 1 命挑戰 = 現成的競技模式原型。

## 法規 / 風險備註

- 付費英雄 / 塔影響難度，不能直接用在有獎賽事。
- 「Kingdom Rush / 王國保衛戰」為 Ironhide 商標；市場上「像王國保衛戰」的仿作多，美術與命名需避開。
