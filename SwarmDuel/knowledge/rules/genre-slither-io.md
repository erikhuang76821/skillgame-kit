# slither.io（多人即時貪食蛇 io）

- **代號**：genre-slither-io
- **市場**：台灣＋北美
- **形態**：線上 F2P（瀏覽器＋iOS / Android），大廳式即時多人、無回合
- **代表產品 / 廠商**：slither.io — Steve Howse（Android 版由 Lowtech Studios 發行），2016-03 上線
- **熱度依據**：
  - **北美**：2016 年美國 Google 搜尋最多的電玩；2017-09 前行動版下載逾 6,800 萬、瀏覽器遊玩逾 6,700 萬（WSJ/TechCrunch 引述）。2024–2026 仍在營運：Ahrefs 估 2025-06 自然搜尋流量約 630 萬（單月，較前月 +320 萬）；美區 App Store 約 3.3K 則評分、3.8 星、動作類免費榜 #42（2026-10 擷取）；2025-12 起可選伺服器、2026-01 共 66 款預設外觀。熱度遠低於 2016 高峰，屬「長尾經典」。
  - **台灣**：台灣 App Store 僅 13 則評分（2026-10），移除廣告定價 NT$120；台灣市場上同類頭部是 Snake.io（台區名稱「貪食蛇大作戰」，見 [genre-snake-io.md](genre-snake-io.md)）。slither.io 在台主要以瀏覽器形式被玩，無可信流量拆分數據（未證實）。
- **技巧 vs 運氣**：技巧主導（走位、圍殺、加速時機）；運氣來自出生位置與同服對手組成，且「大蛇優勢」使新進玩家不對等——原版不適合直接當公平競賽

## 一句話玩法

在數百人共享的地圖上吃光點長大，讓別人的頭撞上你的身體來吃掉他。

## 規則書

### 勝負條件
- 無終局；目標是成為該伺服器最長的蛇。右上排行榜顯示該伺服器質量前 10 名。
- 你的**蛇頭**碰到任何其他蛇的**身體**（含頭）即死亡；別人撞上你的身體則是別人死。
- 撞到圓形地圖邊界即死亡，且**不留下光點**。

### 單局流程
1. 進入伺服器（第三方指南稱單服最多約 500 人，未證實），以小蛇出生於隨機位置。
2. 蛇持續朝游標 / 搖桿方向前進，吃地上光點增長。
3. 玩家可隨時按住加速：速度變快，但持續流失質量，流失的質量在身後化為一排小光點（自己或別人都可吃回）。
4. 任何蛇死亡時，屍體化為一大片明亮大光點，價值遠高於普通光點。
5. 地圖上另有會逃跑的「追逐光點」，給較多質量。
6. 死亡後顯示最終長度，重新開始（原版死亡後播放廣告）。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 分數 | 等於當前長度（質量）；排行榜依此排序 |
| 普通光點 | 小量成長（數值未公開，未證實） |
| 加速留下的光點 | 小量成長 |
| 死蛇屍體光點 | 大量成長（約為原蛇質量的一部分，比例未證實） |
| 加速成本 | 持續扣長度；舊 wiki 兩頁分別寫每秒 5 與每秒 15（版本不同，未證實） |
| 長度只會因加速或死亡而減少 | 無被動衰減（舊 wiki） |
| 轉彎半徑 | 越長越大、轉得越慢（官方未公布公式） |
| 視覺上限 | 舊 wiki 稱約 40,000 質量後外觀不再變大但分數仍增（單一來源，未證實） |

### 操作
- 桌機：滑鼠方向；按住左鍵 / 空白鍵 / 上方向鍵 = 加速。
- 手機：拖曳方向、雙擊（或按住）加速。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原版：無配對、無分級，大小蛇同場；靠「小蛇轉彎快、能切斷大蛇」作為以小搏大的平衡。
- 營收模式只有廣告與 $3.99 去廣告，作者刻意不賣道具或加成——**無付費優勢**，這是此作最值得借鏡的公平設計。
- **競技化設計建議**：
  1. 改為「限時同場 Battle」：10–20 人同時出生、同長度、同一張地圖 seed（光點分佈固定），限時 3–5 分鐘。
  2. 計分：`最終長度 + 擊殺數 × K + 存活時間獎勵`；死亡可設定「重生但扣 50% 分」或「一命制」。
  3. 地圖縮圈（大逃殺式）避免後期龜縮。
  4. 加速成本、光點價值、屍體轉換率全部寫死公開，伺服器權威判定碰撞（避免延遲爭議）。
  5. 依 MMR 配對，杜絕「滿級大蛇屠新手」。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 切頭（cut-off） | 加速衝到對手頭前，讓對手撞上自己身體；以小殺大的核心 |
| 圍圈（encircle） | 大蛇繞圈把小蛇困死，再收縮 |
| 加速時機 | 加速有成本，只在追殺 / 逃命 / 搶屍時用 |
| 搶屍 | 大戰後屍體光點是最大收益來源，要判斷何時進場 |
| 風險管理 | 長度越長、轉向越慢，越容易被切 |

## 隨機 / 運氣來源

- 出生位置、附近是否剛好有大戰屍體。
- 同服玩家組成（有無超大蛇）。
- 網路延遲造成的碰撞判定差異。

## 參賽與變現

- 原版：死亡後插頁廣告；去廣告 US$3.99 / NT$120；外觀可免費使用。
- 不賣加成、不賣虛擬貨幣（作者明言避免付費優勢）。
- 據報 2016 年高峰日收入約 10 萬美元（廣告為主，Wikipedia 引述）。

## 主題與美術風格

- 深色六角網格背景＋霓虹發光蛇身＋彩色光點，極簡、可讀性高。
- 外觀以花紋 / 配色為主，近年有生成式 AI 背景引發批評（Wikipedia）。

## 可借用的設計點

- 「攻擊＝讓對方撞你」：不需要攻擊鍵，一個方向輸入就能完成攻防。
- 「加速有成本、成本化為地上資源」：每次加速都是風險投資，也給追擊者回收機會。
- 「死亡掉落＝別人的大獎」：製造高風險高報酬的搶奪點。
- 「越大越笨重」：內建追趕機制，讓小蛇有逆轉手段。
- 純廣告＋去廣告，不賣戰力，是 io 類維持公平口碑的簡單方式。

## 法規 / 風險備註

- 2025–2026 slither.io 對 Snake.io 提起商標侵權訴訟（標誌相似，Wikipedia）；自製作品需避免相似名稱 / 標誌。
- 2024-12 曾因反猶太用戶名受批評：開放暱稱需過濾機制。
- 即時多人需處理延遲公平與外掛（自動繞圈 bot），現金賽極不建議用原版大廳模式。
