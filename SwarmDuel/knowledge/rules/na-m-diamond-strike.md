# 鑽石突擊（Diamond Strike）— 三消現金賽代表

- **代號**：na-m-diamond-strike
- **市場**：北美
- **形態**：手機現金錦標賽（1 分鐘多人對戰，Skillz 平台）
- **代表產品 / 廠商**：Diamond Strike - Match 3 Games — Skillz Inc.（Skillz 自營第一方遊戲，App 上架 ID 早於多數平台作品）；同類：Tile Blitz（AviaGames）、Triple Match Cash（Papaya）、Party Blast（Tether，點消類）
- **熱度依據**：App Store 約 1.8K 則評分、4.7 星（2026-10）— 規模遠小於接龍 / 賓果；三消在現金技巧賽中屬「次要品類」。列入本庫是為了覆蓋三消類型
- **技巧 vs 運氣**：技巧＋手速主導；是否雙方同盤面同掉落序列：官方未公開（未證實，Skillz 平台常見做法為同種子）

## 一句話玩法

1 分鐘寶石三消比分，手速與連鎖決定勝負。

## 規則書

### 勝負條件
- 1 分鐘多人對戰，分數高者勝（官方描述「1 minute multiplayer matches」）。
- 平手處理：未公開（未證實）。

### 單局流程
1. 配對同等級對手。
2. 交換相鄰寶石形成 3 顆以上同色連線即消除（標準三消）。
3. 消除後上方寶石落下，可能產生連鎖（cascade）。
4. 1 分鐘結束時比較分數。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 三消 / 四消 / 五消 | 得分（數值未公開，未證實） |
| 連鎖 cascade | 加分（未證實） |
| 特殊寶石（四消 / 五消產生） | 有無與效果未公開（未證實） |
| 加成 / 獎勵機制 | 使用者評論提及額外獎勵機制，內容未證實 |
| 同類參考（Party Blast，Tether 官方公開） | 每盤 1,200 基礎分平分給所有目標；同一步清多個目標第二個起分數 ×2；一步清 5/10/15/20 個目標各 +10/+25/+50/+100；道具量表 1/2/3 星 = 基礎分 ×2/×3/×4；剩餘每秒 +10（不乘倍率）；限時 3 分鐘 |

### 操作
- 滑動交換相鄰寶石（標準三消慣例）。

### 公平機制（同種子、同牌序、配對、防作弊）
- Skillz 技術分配對、地理圍欄、18+。
- 盤面同種子：未證實。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 掃盤速度 | 1 分鐘內步數上限由手速決定 |
| 由下往上消除 | 增加自然連鎖機率 |
| 製造特殊寶石 / 道具 | 大範圍消除（同類遊戲通則） |

## 隨機 / 運氣來源

- 補落寶石隨機；若非同種子，連鎖運氣差異大（未證實）。

## 參賽與變現

- Skillz 經濟：現金或虛擬幣參賽、Ticketz 兌換獎品（開發者回覆提及以現金賽累積 Ticketz）。

## 主題與美術風格

- 經典寶石、亮面高光與閃光特效；Bejeweled 式視覺。

## 可借用的設計點

- 1 分鐘極短局：適合高頻小額入場。
- 三消在現金賽要成立，必須「同種子補落」，否則運氣占比過高 — 可參考 Party Blast 的「盤面隨機但雙方相同」＋「目標分攤固定 1,200 基礎分」設計，讓分數上限可控、易做反作弊。
- 道具量表倍率（×2~×4）且「時間獎勵不吃倍率」：避免速度與倍率互相放大造成分數爆炸。

## 法規 / 風險備註

- 三消類若補落非決定性，易被質疑為機率遊戲；在「主要因素測試」（dominant factor test）州可能有風險。
- 本作具體規則多數未公開，設計參考價值主要來自同類 Party Blast 的公開規則。
