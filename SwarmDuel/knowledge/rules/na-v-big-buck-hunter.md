# Big Buck Hunter（Big Buck Hunter Reloaded）

- **代號**：na-v-big-buck-hunter
- **市場**：北美（酒吧、保齡球館、娛樂中心；另有澳洲聯賽）
- **形態**：酒吧光槍射擊街機（連網排行 + 世界錦標賽）
- **代表產品 / 廠商**：Big Buck Hunter Reloaded（2020）— 設計 Play Mechanix（George Petro）、製造發行 Raw Thrills（早期由 Incredible Technologies 製造）
- **熱度依據**：系列自 2000 年；2026 世錦賽 Big Buck World Championship XIX（10/23–24，Milwaukee Turner Hall，BuckFest）獎金 $125,000+、冠軍 $25,000 + Pappy's Jug；128 名來自美、加、澳；2025 冠軍 Jordan Classen
- **技巧 vs 運氣**：技巧主導（反應、準度、辨識公母）；動物出場順序有隨機但條件公開一致

## 一句話玩法

用泵動式光槍在限時內射殺奔跑的公鹿，誤殺母鹿即出局，距離越遠、體重越重、用彈越少分越高。

## 規則書

### 勝負條件
- 單人：分數越高越好；挑戰排行榜。
- 雙人對戰（兩把槍，Pro 起）：同場競爭總分；同一隻獵物先擊倒者得分（未證實細節）。
- 錦標賽：雙敗淘汰；每輪 1 個 trek，冠軍賽 3 個 trek。

### 單局流程
1. 投幣選遊戲（Reloaded 為多遊戲平台：Big Buck 鹿、麋鹿、野生動物等，另有弓箭模式）。
2. 選 trek（地區/動物）；一個完整狩獵分為多個場景（trek 由數個狩獵點 + 獎勵關組成）。
3. 每個狩獵點：公鹿從遠近不同位置奔跑；限時內射殺目標數（常見 3 隻公鹿）。
4. 彈匣打空需「泵動裝填」（拉動槍身）。
5. 誤擊母鹿 → 該狩獵點立即結束（舊版為整局出局）。
6. 場景之間有**獎勵關**：限時射擊約 30～40 個小目標（瓶子、地鼠、牛糞等），重準度與速度（版本依存）。
7. 結算總分；連網機台上傳排行。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 擊殺公鹿 | 依距離（越遠越高）、體重/角叉數、用彈數 |
| 一槍斃命 | 加分；三隻皆一槍、命中率 100% 有成就獎 |
| 誤擊母鹿 | 結束該點、失去剩餘得分機會 |
| 獎勵關 | 每個目標加分，全命中獲額外獎（數值未證實） |
| Pro Mode（2018 起） | 以各 trek 各動物最佳成績排名 Skill 排行；Reloaded 取槍法前 3、弓法前 2 成績 |

### 操作
- 泵動式光槍（shotgun 造型）：扳機射擊、拉泵裝填；畫面外射擊亦可裝填（系列慣例，未證實 Reloaded）。
- 弓模式：拉弓蓄力（Reloaded）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 動物路徑/出場在每個 trek 有固定模式 + 隨機變化；錦標賽各對手同時打相同場景。
- Pro Mode 用玩家帳號累積最佳成績；世錦賽需透過連網 Pro Mode 季度資格賽晉級。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 公母辨識速度 | 避免誤殺（最大失分） |
| 優先打遠距大公鹿 | 分數倍增 |
| 準度（一槍一隻） | 加分與節省裝填時間 |
| 裝填節奏 | 泵動時機決定連續火力 |
| 場景記憶 | 熟悉出現位置可預瞄 |

## 隨機 / 運氣來源

- 動物出場順序/距離的變化；兩人對戰時的搶殺。

## 參賽與變現

- 每局投幣（價格由營運商設定，常見 $1～$2/局，未證實）。
- 世錦賽：每位進入決賽者皆有獎金；另設 Ladies、Rookie 分組獎。
- Beat the Champ 巡迴（2026-05～07，北美 6 城）：區域獎（例如男子最高分 $100）。
- 酒吧聯賽、品牌活動（BuckFest）。

## 主題與美術風格

- 北美狩獵文化：森林、雪原、濃霧、草原；公鹿、麋鹿、馴鹿、野牛等。
- 粗獷戶外/鄉村風、迷彩色機殼、鹿角圖騰；酒吧與藍領客群高度契合。
- 搞笑獎勵關（地鼠、牛糞）平衡寫實狩獵。

## 可借用的設計點

- **懲罰型誤擊（母鹿）**：簡單規則創造「辨識 + 速度」的技巧張力。
- 分數 = 難度係數（距離、重量、效率），讓高手與新手分數差距大。
- 主關 + 短獎勵關節奏，降低疲勞。
- Pro Mode 長期最佳成績排行 + 季度資格賽 + 實體大賽，構成完整電競漏斗。

## 法規 / 風險備註

- 純技巧娛樂機，賽事獎金依各州技巧競賽法規；無兌現機制，風險低。
