# 接龍方塊（Solitaire Cube）

- **代號**：na-m-solitaire-cube
- **市場**：北美
- **形態**：手機現金錦標賽（非同步 1v1 / 多人錦標賽，Skillz 平台）
- **代表產品 / 廠商**：Solitaire Cube: Real Cash Game — Tether Studios（金流與配對由 Skillz / 現為 Firy Inc. 旗下提供）
- **熱度依據**：App Store 美區約 96K 則評分、4.6 星（2026）；Skillz 10-K：Solitaire Cube + 21 Blitz + Blackout Bingo 合計占 Skillz 2021 年營收 72%、2023 年 70%；2025 年 Tether 單一開發商占 Skillz 營收 51%
- **技巧 vs 運氣**：技巧主導；雙方同一副洗牌（同種子），差異只來自決策速度與路線規劃，但個別牌局本身可能無解

## 一句話玩法

5 分鐘內以同一副牌比賽 Klondike 接龍，比總分高低。

## 規則書

### 勝負條件
- 與配對到的對手比較總分，高者勝（多人錦標賽依名次分獎金）。
- 雙方拿到完全相同的牌序，但不一定同時遊玩（非同步）。
- 平手處理：官方規則頁未說明（未證實）。

### 單局流程
1. 配對：系統依技術等級配對對手；可能等對手稍後才完成。
2. 發牌：標準 Klondike — 7 列 Tableau（遞減、紅黑交錯）、4 個 Foundation（同花 A→K）、抽牌堆。
3. 計時：限時 5 分鐘，**第一次操作時才開始計時**。
4. 抽牌：一次翻 3 張（Draw-3），只能使用廢牌堆最上面那張。
5. 回收抽牌堆：前 3 次免費，之後每次 −20 分。
6. 結束：全部牌收進 Foundation、時間到、或玩家在無步可走時按「Finish」提前結束（提前結束才能拿到剩餘時間獎勵）。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 翻開 Tableau 背面朝下的牌 | +20 / 張 |
| 從抽牌堆打出一張牌 | +20 / 張 |
| 牌進 Foundation（依點數） | A=100、2=90、3=80 … 遞減 10；10/J/Q/K=10（4~9 依官方「etc.」規律推算為 70/60/50/40/30/20，總和驗算吻合 3,220） |
| 完整解完整副牌的基礎分 | 3,220（=21 張暗牌×20 + 24 張抽牌×20 + 4 花色×580） |
| 時間獎勵 | 剩餘每秒 +4（滿 5 分鐘上限 1,200）；未全部收完時會打折，折算公式未公開（未證實） |
| 第 4 次起回收抽牌堆 | −20 / 次 |
| 分數下限 | 0（不會變負） |
| 官方參考 | >3,000 優秀；>3,800 頂尖 |

### 操作
- 點擊自動移到合法位置、或拖曳；Undo 次數不限但只能撤銷最近一步；「Finish」按鈕提前交卷。

### 公平機制（同種子、同牌序、配對、防作弊）
- 雙方同一洗牌序（seed 相同）。
- 依技術評分配對（Skillz 配對系統）。
- 年滿 18 歲、地理圍欄（geofencing）判斷州別才可現金賽。
- 平台宣稱有反作弊監控；Skillz 在訴訟中主打「真人對真人、無 bot」。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 優先翻暗牌 vs 優先上 Foundation | 暗牌 +20 且開路；Foundation 低點數牌分高（A=100），兩者權衡 |
| 抽牌堆循環管理 | 3 次免費回收用完後每次 −20，需規劃 Draw-3 的節奏 |
| 判斷死局並提早 Finish | 無解局越早交卷，剩餘秒數 ×4 越多 |
| 手速 | 時間獎勵最多 1,200 分，占滿分約 27% |

## 隨機 / 運氣來源

- 牌序隨機（但雙方相同，故對「對手」而言無運氣差）；多人錦標賽中不同場次的牌難度不同，影響絕對分數但不影響同場比較。

## 參賽與變現

- Skillz 標準模式：入場費現金 / Bonus Cash（不可提領的贈金，只能用於付費賽）；免費練習用 Z 幣（虛擬幣）；勝場或參賽可得 Ticketz 兌換商品。
- 入場費級距大約 $0.60~$數十美元（使用者評論提及 60¢、$3 局；未證實完整級距）。
- 現金賽禁止州（App 頁面 2026）：AR、CT、DE、IN、LA、ME、SD。

## 主題與美術風格

- 經典撲克牌面、乾淨扁平 UI、藍綠色桌布；強調「錦標賽 / 獎盃」的競技感而非賭場霓虹。

## 可借用的設計點

- 「依點數遞減給分」：讓上 A 分數最高，鼓勵早期就上 Foundation，避免玩家只顧翻牌。
- 「免費次數＋超額懲罰」(3 次回收免費)：限制無腦循環又不打擊新手。
- 「第一次操作才開始計時」：降低 UI 讀取不公平。
- 「提早交卷換時間分」：把放棄死局轉成技巧決策。
- 滿分可算（3,220＋時間）方便平衡與防作弊（超出理論上限即異常）。

## 法規 / 風險備註

- Tether 於 2025-08-29 通知終止與 Skillz 合約；Skillz 在德拉瓦衡平法院提告，合約限制 Solitaire Cube 與 21 Blitz 終止後至少 18 個月不得下架；審判預計 2026-12 或延至 2027。產品平台歸屬可能變動。
- 使用者評論常見「被操控」「對手是錄影」質疑，屬未證實的使用者說法；非同步對戰天生難向玩家證明對手是真人。
