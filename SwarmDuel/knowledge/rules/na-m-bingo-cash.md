# 賓果現金（Bingo Cash）／賓果對決（Bingo Clash）

- **代號**：na-m-bingo-cash
- **市場**：北美
- **形態**：手機現金錦標賽（非同步多人錦標賽，自營平台）
- **代表產品 / 廠商**：Bingo Cash — Papaya Gaming（以色列）；同格式競品 Bingo Clash / Bingo Tour — AviaGames（Avia，美國）
- **熱度依據**：Bingo Clash App Store 約 124K 則評分、4.5 星、Casino 免費榜 #65（2026-10）；Avia 稱旗下產品年營收達「九位數美元」、累計 6,000 萬下載、每月 4.5 億場錦標賽（2025-10）；Bingo Cash 為 Papaya 四大主力之一（與 Solitaire Cash、Bubble Cash、21 Cash 並列）
- **技巧 vs 運氣**：技巧（反應＋準確＋道具時機）為主；所有人同卡面同號序；但 Papaya 已被法院認定大量使用未揭露 bot（見風險）

## 一句話玩法

同卡同號的限時速度賓果，搶快塗記、用加成，前三名分獎金。

## 規則書

### 勝負條件
- 限時結束時分數排名；Bingo Cash 為多人錦標賽，前 3 名獲現金獎（Penny Hoarder 評測）。
- 所有參賽者拿到相同卡面與號碼序列。
- 平手處理：未公開（未證實）。

### 單局流程（Papaya Bingo Cash）
1. 進入錦標賽、配對同等級玩家。
2. 叫號依序出現，於卡上點擊塗記；**越快塗記分越高，加成條也充得越快**。
3. 成線（橫、直、斜 5 格，或四角）後按 BINGO 鈕領取。
4. 加成條滿格得一次性加成（見下表）。
5. 計時歸零即結束並送出分數。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 正確塗記 | 依速度給分（數值未公開，未證實） |
| Bingo（橫/直/斜/四角） | 得分（數值未證實）；多重 Bingo 可加成（第三方評測） |
| 塗記未叫到的號 | 扣分 |
| 未成線就按 BINGO | 扣分 |

| Pick-A-Ball（Papaya） | 選一顆自己需要的號碼 |

| Bonus Time（Papaya） | 計時 +10 秒 |
| 「G」Gimme More（Avia Bingo Clash） | 預覽下一個號碼 |
| 「鑽石」Daub It（Avia） | 任選一個號碼塗記 |
| x2（Avia） | 分數加倍 |
| 加成持有上限（Avia） | 最多同時持有 2 個 |
| 局長 | 未公開（第三方評測多稱約 2 分鐘，未證實） |

### 操作
- 點擊塗記、點擊 BINGO 按鈕、點擊加成圖示；規則可於錦標賽畫面「Rules」鈕查看。

### 公平機制（同種子、同牌序、配對、防作弊）
- 宣稱：全員同卡同號、依技術配對（Avia 稱「智慧配對」與技術評分）。
- 實際：Skillz v. Papaya 判決認定 Papaya 2021–2024 年約 26 億場錦標賽中，超過 6.3 億場有「客製 bot」（tailored bots）刻意輸給真人以留存；另有「流動性 bot」填滿賽場；有 20 人賽僅 1 名真人。Papaya 稱已停用 bot。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 塗記速度 | 直接決定分數與加成充能 |
| 準確度 | 誤塗與誤報 BINGO 扣分 |
| 加成選擇 | Wild / Pick-A-Ball 選能完成多條線的格 |
| ×2 時機 | 在即將連續成線時開啟 |
| 持有上限管理（Avia） | 只能存 2 個，需及時使用避免浪費 |

## 隨機 / 運氣來源

- 號序與卡面隨機但全員相同；名次受同場對手水準影響（多人賽）；bot 存在時對手分數非真人產生（法院認定 Papaya 情形）。

## 參賽與變現

- 入場費約 $1 起、部分 $5 以上；單場最高獎金約 $83；前 3 名分獎（Penny Hoarder）。
- 免費練習：Papaya 用 Gems（寶石，虛擬幣），Avia 用 Tickets。
- 出金：PayPal、Apple Pay 等；Papaya 最低提領 $5、手續費 $1。
- 州限制：Bingo Cash 現金賽不開放 AZ、IA、LA、SC（Penny Hoarder）；Bingo Clash 不開放 AR、DE、LA、MI、SD 與波多黎各（App Store 2026）。

## 主題與美術風格

- 鮮豔粉紫、金幣、彩帶與獎盃；名稱直接帶「Cash」「Clash」強調獎金；Avia 搭配慈善活動（2025 Play for Paws：每局捐 5 美分，共捐 $222,100）塑造正面形象。

## 可借用的設計點

- 速度給分＋加成充能：讓賓果從純運氣變技巧。
- 道具持有上限（Avia 2 格）製造使用時機抉擇。
- 一局多次 Bingo＋多重 Bingo 加成，避免一次成線後無事可做。
- **反面教材**：未揭露 bot 導致 $7.19 億判賠與破產保護 — 新作必須在條款與 UI 明確揭露對手性質，並保留可稽核的配對日誌。

## 法規 / 風險備註

- Papaya：2026-04 陪審團認定違反 Lanham Act 不實廣告（$4.2 億損害賠償），2026-07-27 法官改判 $7.19 億利潤返還＋約 $1,010 萬費用；2026-08 Papaya 於特拉維夫申請債務重整並在美國德拉瓦提 Chapter 15；另於 2025 年以 $1,500 萬和解玩家集體訴訟（涵蓋 Solitaire Cash、Bubble Cash、Bingo Cash、21 Cash、Triple Match Cash）。
- Avia：2024 年 Skillz 專利案陪審團判賠 $4,290 萬（Bingo Clash 侵權），後與 Skillz/Big Run 以 $8,000 萬和解；玩家以 RICO 起訴 bot 的集體訴訟，美國最高法院已拒絕審理 Avia 的強制仲裁上訴（日期未證實），案件續行（結果未證實）。
