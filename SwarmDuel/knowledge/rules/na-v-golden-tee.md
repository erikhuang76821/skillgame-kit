# Golden Tee Golf（Golden Tee PGA TOUR 2026）

- **代號**：na-v-golden-tee
- **市場**：北美（酒吧、運動酒吧、保齡球館；另有家用版 Home Edition、Golden Tee Mobile）
- **形態**：酒吧技巧街機（線上連網 + 現金獎賽事）
- **代表產品 / 廠商**：Golden Tee PGA TOUR 2026 — Incredible Technologies（IT，伊利諾州）
- **熱度依據**：系列自 1989 年；2025 世界錦標賽（拉斯維加斯 Palms，7/17–20）冠軍 Clint Grover 獲 $30,000、總獎金近 $200,000，ESPN2 播出 30 分鐘特輯；2026 世錦賽 6/11–14 同地；Golden Tee Mobile 世錦賽另設 $15,000 獎池
- **技巧 vs 運氣**：技巧主導（揮桿力道/方向/旋轉、讀風讀地形），隨機性極低

## 一句話玩法

用軌跡球「拉—推」模擬揮桿打 18 洞，桿數越少越好，並可付費加入全國線上獎金賽。

## 規則書

### 勝負條件
- 標準高爾夫比桿：完成 9 或 18 洞，總桿數最低者勝（線上賽事以分數/桿數排名，含 Great Shot 等加分作為同分判定）。
- 本地多人（最多 4 人輪流，未證實上限）或線上單人對全國排行。

### 單局流程
1. 投幣/刷卡付費（價格由營運商設定；常見 18 洞約 $4～$6，未證實）。
2. 選模式：Casual / Online（排行計分）/ Daily Contest / Tour Mode / Skins / RUN IT 聯賽 / Classic Course of the Week。
3. 選球場、球桿組、球（裝備影響距離與旋轉，如 Comet 球加大切球距離）。
4. 每桿：選桿 → 調整瞄準方向 → 軌跡球揮桿 → 球飛行中可再搓球加旋轉（hook/slice/後旋，系列傳統操作，未證實 2026 細節）。
5. 推桿：讀果嶺坡度，以軌跡球推動速度控制距離。
6. 打完所有洞 → 結算桿數、加分、排名；線上分數上傳。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 桿數 | 標準比桿 |
| Great Shot Points | 精彩球（如長推、Eagle、命中旗桿）加分，作為同分判定 |
| Golden Tee Points | 次級同分判定 |
| Tour Mode | 每週指定球場打 5 場，合計得週排名與 Tour Points；20 週一季，期間 2 次 Elevated Event 給 1.5× 點數；需累計 ≥ 30 場才可參加 |
| 分級 | Gold / Silver / Bronze 依 Tour Points 分組，季末發獎並產生世錦賽資格 |
| Skins（2026 新版） | 每洞獎值隨回合遞增，可線上對戰 |

### 操作
- **軌跡球**：向後拉 = 上桿；向前推的速度 = 力量；推動軌跡偏左/右 = 左曲/右曲。
- 按鍵：選桿、瞄準左右、視角、切換球位。
- 2026 新增擊球型：**Flop**（高拋短距）、**Punch**（低平穿樹）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 同球場、同風況/同 Daily Contest 修正（風、tee 位置）讓所有線上參賽者條件一致。
- 結果完全由輸入決定，無隱藏 RNG 勝率（風向等環境因子對所有人一致）。
- 機台連網上傳成績；賽事以帳號（玩家卡/App）追蹤，有最低場次門檻防衝分。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 揮桿力量控制 | 決定距離，影響是否上果嶺 |
| 揮桿直線度 / 刻意曲球 | 繞過障礙、應對狗腿洞 |
| 飛行中加旋轉 | 職業玩家核心技術，決定落地滾動 |
| 讀風、讀坡 | 推桿與長打精準度 |
| 球場記憶 | 熟悉每洞最佳路線（老玩家優勢） |

## 隨機 / 運氣來源

- 極少；每日風況/修正為公開條件。主要不確定性在玩家自身手感。

## 參賽與變現

- 機台收入：每場付費（營運商/酒吧分成，比例未公開，未證實）。
- 線上獎金賽：玩家每場額外付費加入 Events / Tour，獎金按排名發放（週獎與季獎，金額未公開，未證實）。
- 酒吧自辦聯賽：例如某酒吧主賽報名 $120、Closest to the Pin $20，Power Events 每人再加 $5 入獎池。
- 頂層：世錦賽（約 96 人場，2024 資訊）、PEGT 巡迴賽（如 2026 Nashville 站加碼 $8,000）。
- 外觀/裝備：Club Pass 季票解鎖服裝、球桿、橫幅。

## 主題與美術風格

- 寫實但誇張的原創球場：愛荷華玉米田、科羅拉多峽谷、秘魯馬丘比丘；搭配 PGA TOUR 授權球場（TPC Twin Cities）。
- 每年推出「Freaky Casual」怪奇球場（10 個/年）維持新鮮感。
- 酒吧風幽默旁白、慶祝動畫、Shots of the Game 精華倒數。

## 可借用的設計點

- **年度版本 + 季票（Club Pass）+ 每日賽**：讓實體機台有線上遊戲般的 Live Ops。
- **同條件線上錦標賽**：每日修正（風/tee）讓所有人公平比較，強化技巧主張。
- 最低場次門檻 + 分級聯賽：防止新手被老手壓制、維持各層級獎勵。
- 實體操作器（軌跡球）帶來獨特手感，難以被手機取代。

## 法規 / 風險備註

- 被普遍視為純技巧遊戲；現金獎賽事依各州技巧競賽法辦理（少數州可能限制，未證實）。
- 賓州 2026 判決後，業界擔心「付費可贏獎」的街機也受波及（Penn Capital-Star 報導），但判決本身針對類老虎機。
