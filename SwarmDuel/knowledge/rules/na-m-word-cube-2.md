# 文字方塊 2（Word Cube 2）

- **代號**：na-m-word-cube-2
- **市場**：北美
- **形態**：手機現金錦標賽（非同步 1v1 / 多人錦標賽，Skillz 平台）
- **代表產品 / 廠商**：Word Cube 2 — Tether Studios（Skillz）；同廠另有 Word Race
- **熱度依據**：Tether（Skillz 2025 年營收 51%）的文字遊戲代表作；個別營收 / 評分數未證實。文字類在現金技巧市場屬中小眾（相對接龍、賓果）
- **技巧 vs 運氣**：技巧主導（字彙量＋版面規劃）；雙方同字母序、同初始盤面

## 一句話玩法

類 Scrabble 拼字，同字母序連下 5 手，看誰分高。

## 規則書

### 勝負條件
- 5 分鐘內比總分，高者勝；可能非同時遊玩。
- 結束：完成第 5 手或時間到。
- 平手處理：官方頁未說明（未證實）。

### 單局流程
1. 盤面開局已有 2~3 個單字（隨機但雙方相同）。
2. 玩家連續下 5 手（不輪流，自己連下）；每手將字母牌放在盤上組成合法單字。
3. 字母牌依相同順序發給雙方；部分抽到的牌隨機變成「銀牌」。
4. 空白牌為萬用字母，放下時指定字母。
5. Swap（換牌）可換任意張數，但消耗 1 手。
6. **暫停時計時不會停止**。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 字母牌 | 右上角標示分值，最高 +10（完整字母表未公開，未證實；推測接近 Scrabble 分值） |
| 銀牌 | 不論字母一律 7 分 |
| 空白萬用牌 | 分值未公開（Scrabble 慣例為 0，未證實） |
| Double Letter | 該字母 ×2 |
| Triple Letter | 該字母 ×3 |
| Double Word | 整字 ×2 |
| Triple Word | 整字 ×3 |
| 倍率疊加 | 可疊乘 |
| 倍率格位置 | 每場固定相同 |
| 時間獎勵 | 剩餘每秒 +0.2（5 分鐘上限 60） |
| 字長獎勵 / Bingo（用完 7 張） | 官方頁未提（未證實） |
| 官方參考 | 約 200 好；300+ 優秀 |

### 操作
- 拖曳字母上盤；Recall 收回本手已放的牌；Shuffle 重排手牌；Swap 換牌（耗 1 手）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 同字母序、同初始單字、固定倍率格；技術分配對；地理圍欄、18+。
- 暫停不停表：防止玩家暫停查字典（但無法完全防外部查詢工具，屬文字類現金賽固有風險）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 字彙量 | 可組字數與長字 |
| 搶占 Triple Word | 整字 ×3 為最大分源 |
| 銀牌運用 | 低分字母（如 E、A）變銀牌值 7 分，放 DL/TL 收益大 |
| Swap 取捨 | 只有 5 手，換牌成本極高 |
| 速度 | 時間獎勵很小（≤60），速度次要 |

## 隨機 / 運氣來源

- 字母序與銀牌隨機但雙方相同；初始盤面雙方相同。

## 參賽與變現

- Skillz 經濟（現金 / Bonus Cash、Z 幣、Ticketz）。

## 主題與美術風格

- 木質字母牌＋明亮方塊棋盤，延續 Tether「Cube」品牌；簡潔、適合年長族群的大字體。

## 可借用的設計點

- 「不輪流、自己連下 5 手」：把雙人拼字改造成可非同步比較的單人解謎。
- 固定倍率格＋同字母序：讓字彙量成為唯一變因。
- 「暫停不停表」是低成本的作弊抑制。
- 時間獎勵刻意很小，避免「快」壓過「想」——依品類調整速度權重。

## 法規 / 風險備註

- 文字類容易被外部求解器輔助作弊，需伺服器端時間分析與異常偵測。
- Tether 與 Skillz 合約爭議進行中。
