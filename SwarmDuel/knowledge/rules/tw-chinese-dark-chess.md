# 暗棋（Chinese Dark Chess / 翻翻棋）

- **代號**：tw-chinese-dark-chess
- **市場**：台灣
- **形態**：實體（象棋子 + 半張棋盤）＋手機線上 F2P（暗棋大戰 Online、暗棋王、象棋／暗棋合輯 App；娛樂城棋牌館內）
- **代表產品 / 廠商**：暗棋大戰 Online、暗棋無雙 等多款小廠 App；學術界：中研院徐讚昇團隊 TCG 電腦對局賽規則
- **熱度依據**：台灣童年普及度極高的「象棋子小遊戲」，為台灣電腦對局競賽（TCGA／TAAI）常設項目；手機上多為長尾 App，單款營收資料（未證實）
- **技巧 vs 運氣**：技巧＋資訊不完全。翻子帶來運氣，但吃子順序、逼翻、炮位運用的技巧權重高

## 一句話玩法

32 枚象棋子蓋牌亂排 4×8 格，輪流翻子或走子，以大吃小吃光對方。

## 規則書

### 勝負條件
- 對方所有棋子被吃光 → 勝（即使對方仍有未翻的暗子也算輸）。
- 對方輪到時**無合法走步**（例：明子全被困、盤面已無暗子可翻）→ 勝。
- 和局：雙方合計連續 **60 步**（學術版；民間常用 30 步）未吃子也未翻子；或同一盤面重複出現 3 次。
- 學術賽：犯規兩次判負；每步限時（例 15 分鐘）。

### 單局流程
1. 32 子（紅黑各 16：帥／將×1、仕／士×2、相／象×2、俥／車×2、傌／馬×2、炮／包×2、兵／卒×5）全部面朝下隨機放在 4×8 格。
2. 先手第一步翻開一子，**翻出的顏色即為先手的顏色**。
3. 每回合只能做一件事：**翻一顆暗子** 或 **移動一顆己方明子**，不可 pass。
4. 明子每步上下左右走一格；走到對方明子所在格＝吃子（需符合大小規則）。
5. 炮（包）特殊：隔**一顆**任何子（暗子或明子、敵我不拘）直線跳吃對方明子，距離不限，但不可連跳。
6. 依勝負條件判定。

### 計分規則
| 項目 | 規則 |
|---|---|
| 子力大小 | 帥 > 仕 > 相 > 俥 > 傌 > 炮 > 兵 |
| 一般吃子 | 大吃小、同級互吃 |
| 例外 1 | 兵（卒）可吃帥（將） |
| 例外 2 | 帥（將）不可吃兵（卒） |
| 例外 3 | 炮不可「走步」吃（只能跳吃）；學術版規定炮不能走步吃兵或炮 |
| 炮跳吃 | 可吃任何已翻開的敵子（含帥），不受大小限制 |
| 計分（App 常見） | 勝負＋剩子數加成或連勝積分，（未證實）依 App |

### 操作
- 點暗子＝翻；點己方明子再點目標格＝走／吃。

### 公平機制（同種子、同牌序、配對、防作弊）
- 線上：亂數佈局；先手由系統隨機；計時（每步數十秒，（未證實））；防長追：部分 App 規定「同一子連續追捉超過 10 次判負」等，各版本不同。
- 技巧競賽：可用「同佈局雙局換先」抵消運氣。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 翻子位置選擇（避免翻在敵大子旁） | 降低被吃風險 |
| 機率推算（記已翻出子，推剩餘暗子分布） | 決定翻還是走 |
| 炮位經營 | 炮是唯一能越子、可吃帥的子 |
| 兵帥牽制（以兵守帥、以帥逼對方兵外的子） | 終局關鍵 |
| 逼和／步數管理（60/30 步規則） | 劣勢時求和 |

## 隨機 / 運氣來源

- 初始佈局完全隨機；翻出顏色與子種；先手。

## 參賽與變現

- App：廣告 + 去廣告 + 遊戲幣；排位賽、段位；娛樂城內以遊戲幣對局（屬棋弈類，受輔15級規範）。

## 主題與美術風格

- 木質棋盤、紅黑圓棋子、書法字；Q 版三國武將化（帥＝主公、炮＝投石車）常見改編；懷舊台味（柑仔店、課桌）。

## 可借用的設計點

- **翻牌＋走子二選一**：每回合「探索 vs 行動」的取捨，簡潔又深。
- **循環克制（兵吃帥）**：簡單規則創造反殺劇情。
- **越子攻擊單位（炮）**：在網格戰鬥中引入位置技巧。
- **4×8 小盤**：手機直式畫面完美適配，單局 5–10 分鐘。

## 法規 / 風險備註

- 棋類本身無法律問題；若以遊戲幣輸贏且幣可轉讓兌現 → 同棋牌娛樂城風險。
