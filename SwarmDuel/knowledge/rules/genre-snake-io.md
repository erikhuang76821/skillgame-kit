# Snake.io（台區名「貪食蛇大作戰」）／對照：中國《贪吃蛇大作战》

- **代號**：genre-snake-io
- **市場**：台灣＋北美
- **形態**：線上 F2P 手遊（iOS / Android / 網頁 / Switch / Xbox）＋Apple Arcade 訂閱版（Snake.io+）＋Netflix 會員版
- **代表產品 / 廠商**：Snake.io — Kooapps（美國）；對照組《贪吃蛇大作战》— 武漢微派網絡（2016，主攻中國）
- **熱度依據**：
  - **北美**：美區 App Store 約 47.9 萬則評分、4.6 星、策略類免費榜 #22（2026-10 擷取）；Kooapps 部落格稱 Apple 公布 Snake.io+ 為 2024 年 Apple Arcade 下載第 2 名（公司轉述，未獨立驗證）；Google Play 累計 5 億+下載。Sensor Tower 2025 Q4 拉丁美洲 Android 週下載 45.6 萬→70.6 萬，顯示 2025 仍在成長。另有 Netflix 會員版（2025-06 仍在更新）。
  - **台灣**：台灣 App Store 上本作的在地名稱就是「貪食蛇大作戰」，約 4,631 則評分、4.6 星、動作類免費榜 #61（2026-10 擷取），並支援繁體中文——是台灣「貪食蛇」關鍵字的頭部產品。中國微派《贪吃蛇大作战》在台灣 App Store 查無上架（CN 區頁面可查），台灣玩家說的「貪食蛇大作戰」多半指 Snake.io（推論）。
- **技巧 vs 運氣**：技巧主導（走位、切頭、加速）；與 slither.io 同樣有出生位置與同場對手組成的隨機，且 Snake.io 大量使用 bot 填房（第三方 / 玩家說法，未證實）

## 一句話玩法

slither.io 的手機友善版：搖桿控制、單鍵加速、限時活動與排行榜。

## 規則書

### 勝負條件
- 大逃殺式場次：從小蛇開始，吃光點與吃掉其他蛇長大；分數＝本局最大長度，挑戰個人 / 全球排行。
- 蛇頭撞到他蛇身體即死；讓對手撞上你的身體即可擊殺並吃掉其殘骸。
- 每月主題活動有獨立的即時排行榜。

### 單局流程
1. 進場：小蛇出生（線上真人＋bot 混合，比例未證實）。
2. 吃光點 / 殘骸成長；按「加速」鍵以流失長度換速度（商店頁原文為「彈出質量」加速）。
3. 被擊殺 → 結算長度、排名、活動積分；可看廣告續命（玩家評論提到，未證實細節）。
4. 活動模式：每月更換主題規則；玩家評論提及「約每 2 分鐘出現追殺王冠持有者約 49 秒的追擊者」（單一評論，未證實）。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 主分數 | 本局最大長度 |
| 加速成本 | 持續扣長度、掉落光點（數值未公開，未證實） |
| 擊殺獎勵 | 吃到對手殘骸＝大量長度（比例未證實） |
| 王冠 | 場內第一名持有（活動規則依月份變動，未證實） |

**對照：中國《贪吃蛇大作战》模式**（攻略站資料，版本較舊）
| 模式 | 規則 |
|---|---|
| 無盡模式 | 無時間限制、一條命，多為機器蛇 |
| 限時模式 | 一局約 4–5 分鐘（攻略說法，未證實），結束時比長度 |
| 團戰模式 | 三隊對抗，多為真人，比隊伍總長 |

### 操作
- 左手或右手虛擬搖桿＋加速（彈出質量）按鈕。
- Switch / Xbox / PC 版支援同機最多 4 人本地對戰。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原版：外觀不影響數值（皮膚 US$0.99 單買為外觀，未見加成說明）；Snake Pass、Premium 訂閱內容是否含遊戲優勢未證實。
- 原版無正式配對 / 分級；bot 比例不透明。
- **競技化設計建議**（與 slither.io 共通，見 [genre-slither-io.md](genre-slither-io.md)）：
  1. 「限時模式」（中國版做法）是最好的競賽骨架：固定 3–5 分鐘、同起始長度、同地圖光點 seed。
  2. 團戰模式三隊制可降低單人被圍殺挫折，適合台灣好友開黑文化。
  3. 若要非同步同種子：把對手改成「固定 seed 的 bot 行為劇本」，所有參賽者面對同一群 bot，比最終長度（成本低、可重播驗證）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 切頭 | 加速插到對手頭前，最主要的擊殺手段 |
| 圍殺 | 長蛇繞圈困住短蛇 |
| 加速經濟 | 何時花長度換速度 |
| 搶殘骸時機 | 大戰後進場吃屍的風險判斷 |

## 隨機 / 運氣來源

- 出生點、附近 bot / 真人強度。
- 活動追擊者、王冠機制等加入的事件隨機（未證實）。

## 參賽與變現

- 美區內購（2026-10）：去廣告 US$1.99 / US$2.99、Snake Premium 月訂 US$4.99、Snake Pass US$2.99、單款皮膚 US$0.99、小額金幣包 US$0.99。
- 廣告：死亡 / 換局插頁、看廣告取得非排位局（玩家評論）。
- 平台授權：Apple Arcade（Snake.io+，2023-05 上線）、Netflix 會員版——同一 IP 多通路分發。

## 主題與美術風格

- 明亮糖果色、粗描邊、可愛臉部表情的蛇頭；大量聯名 / 節慶皮膚（每月活動主題）。
- 比 slither.io 更卡通、更「休閒手遊化」。

## 可借用的設計點

- 「單鍵加速＋搖桿」：io 玩法的最佳手機化方案。
- 每月主題活動＋獨立排行榜：讓老玩法有 live-ops 節奏。
- 多通路（F2P＋訂閱平台＋Netflix）擴大觸及，F2P 版保留廣告營收。
- 中國版「無盡 / 限時 / 團戰」三模式分層：休閒、競賽、社交各有出口。

## 法規 / 風險備註

- slither.io 於 2025–2026 對 Snake.io 提起商標侵權訴訟（Wikipedia）——同類作品需避免相似 Logo 與名稱。
- 台區名稱與中國作品撞名，在地化命名時要避免混淆。
- bot 填房若用於有獎競賽，必須明確揭露（參考北美 Papaya 因 bot 判賠案）。
