# 一指死神（One Finger Death Punch／OFDP 2）

- **代號**：genre-one-finger-death-punch
- **市場**：台灣＋北美
- **形態**：付費 PC / 主機單機（Steam、Xbox、PS4、Switch）；手機版為 Mobirix 代理的 F2P 改版
- **代表產品 / 廠商**：One Finger Death Punch（2013 Xbox 360 / 2014 PC）、One Finger Death Punch 2（2019，PS4 2020）— Silver Dollar Games（加拿大，Jon & David Flook）；手機版發行 Mobirix（韓國，2015）
- **熱度依據**：
  - **北美**：OFDP 是「左右兩鍵打怪」這個子類型的定義者；OFDP2 Steam 約 3,700–4,500 則評論、約 96% 好評（Overwhelmingly Positive），Metacritic 83 / OpenCritic 84。但 2024–2026 屬長尾：OFDP2 Steam 同時在線 2025–26 月均僅約 5–6 人、2024-08 高峰 29 人（Steambase）；銷量第三方估 14.6 萬–31.6 萬套（差距大，未證實）。
  - **台灣**：繁中圈稱「一指死神」；Steam 頁面未支援繁體中文，在台主要靠實況 / 口碑認識；無台灣銷售或排行數據（未證實）。手機版經營現況不明（未證實）。
- **技巧 vs 運氣**：技巧主導（判斷敵人方向、距離、連擊序列、節奏）；敵人生成有隨機，但故事關卡多為固定設計（未證實），同種子即為純技巧

## 一句話玩法

敵人從左右湧來，進入攻擊範圍時按對應方向的鍵出招；按錯或空揮會露出破綻挨打。

## 規則書

### 勝負條件
- 故事模式：每關有清除目標（擊殺數 / 特殊條件），生命歸零失敗；通關依表現評級（評級方式未證實）。
- 生存模式：無盡，生命歸零結束，以擊殺數排行。

### 單局流程
1. 主角站在畫面中央，敵人從左右兩側走近。
2. 敵人進入攻擊範圍時顯示提示（範圍指示），此時按對應方向鍵即擊中。
3. **空揮（miss）**：範圍內沒有敵人時按鍵 → 揮空，有一段硬直，敵人可趁機攻擊——這是整個遊戲的核心懲罰。
4. 多段敵人：頭上有藍 / 紅標記，代表需要以左 / 右鍵的指定順序連打數次（Boss 同理，按錯或漏按即被 Boss 反擊）。
5. 特殊段落：光劍、雙截棍回合——敵人一擊斃命，但速度與數量逐步上升。
6. 生命歸零 → 結束。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 難度 | Student / Master / Grandmaster：影響每關敵人數、回合速度、玩家生命值（具體數值未證實） |
| 完美回合 | 整關沒有任何一次空揮 |
| 生存模式 | 三種：一般（無盡群戰，隨機插入光劍等段落）、Blind（隱藏敵人頭上的連擊順序與範圍提示）、隱藏模式（與 No Luca No 交叉，還要用游標推開貓） |
| 生存模式解鎖 | 前一個生存模式累積 500 擊殺才解鎖下一個 |
| 生存模式特殊段落 | 每隔一定擊殺轉入雙截棍 / 光劍段落，直到被打中 4 次為止；這 4 次不扣生命；段落中的白色敵人擊殺後回 1 滴血（評論者描述） |
| 玩家生命值 | 依難度不同（未證實具體數值） |
| 技能 | 故事進度解鎖可裝備技能（數量與效果依作品，未證實） |

### 操作
- 兩鍵：滑鼠左鍵＝打左邊、右鍵＝打右邊（手機：點螢幕左半 / 右半）。
- 無移動鍵；主角會自動衝向被擊中的敵人方向。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原作為單機，只有 Steam 排行 / 成就。
- **競技化設計建議**：
  1. 同 seed 敵人序列：所有人面對同一串（方向、類型、間隔、連擊序列）敵人。
  2. 計分：`擊殺 × 100 × 連擊倍率 − 空揮 × 200`；連擊倍率每 10 連擊 +0.1（上限 ×3），空揮或被打中歸零。
  3. 生存制：3 條命、限時 120 秒，比分數；或無限時比存活擊殺數。
  4. Blind 模式作為高段位賽道（拿掉提示＝更純的讀敵能力）。
  5. 輸入以「時間戳＋左右」紀錄，伺服器重播判定；人類反應下限可用來偵測巨集（例如連續 < 80ms 精準命中）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 範圍判斷 | 太早按＝空揮硬直，太晚＝被打 |
| 抗拒狂按 | 評論一致強調：亂按必死，克制是核心技巧 |
| 序列記憶 | 多段敵人需照藍 / 紅順序連打 |
| 優先順序 | 兩側同時接近時先處理哪邊 |
| 節奏感 | 速度上升後接近節奏遊戲 |

## 隨機 / 運氣來源

- 生存模式的敵人組合與特殊段落插入時機。
- 故事關卡的敵人序列是否固定（未證實）。

## 參賽與變現

- PC：買斷（OFDP2 Steam 定價 US$7.99，常態大折扣，第三方記錄最高 −83%）。
- 手機（Mobirix）：改為 F2P，加入雙貨幣與體力制（2015 評論）。
- 無排位 / 無錦標賽。

## 主題與美術風格

- 火柴人＋功夫電影（成龍 / 李小龍式）＋大量物理飛散與慢動作，黑白灰人物配高對比特效。
- 極度可讀：灰色敵人、彩色標記的特殊敵人，一眼可辨。

## 可借用的設計點

- **「空揮有代價」**：兩鍵遊戲不被狂按破解的關鍵；所有左右切換類都應有明確的 miss 懲罰。
- 範圍指示＋連擊序列標記：讓兩顆鍵也能有深度（讀、記、按）。
- 特殊段落（雙截棍 / 光劍）：打斷單調、提供爽快高潮。
- Blind 模式：同一內容拿掉 UI 提示就是高段位賽道，零成本擴充。
- 難度同時調「敵人數、速度、玩家生命」三軸。

## 法規 / 風險備註

- 暴力程度為卡通火柴人，北美分級低；台灣需留意輔導級判斷（肢體打擊、無血腥一般可接受，未證實）。
- 原作 2024–2026 熱度低，作為「機制範本」而非「市場熱度證明」。
