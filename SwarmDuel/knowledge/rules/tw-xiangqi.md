# 象棋（Xiangqi / Chinese Chess）

- **代號**：tw-xiangqi
- **市場**：台灣
- **形態**：實體競技（協會段位賽、縣市長盃）＋手機／網頁線上 F2P（多款兩岸與海外開發的「中國象棋」App；暗棋／象棋合輯平台）
- **代表產品 / 廠商**：台灣 App Store 常見「中國象棋專業版」、「中國象棋 - 天天下…」（Duozr）、「航訊中國象棋」（棋譜／殘局庫）、神來也暗棋 2（暗棋＋象棋，但同 App 內含娛樂城元素，需留意）。騰訊《天天象棋》主要服務中國大陸，台灣是否為主流平台（未證實）。實體：中華民國象棋文化協會、中華民國象棋教育推廣協會、各縣市體育會象棋委員會
- **熱度依據**：台灣每年有多場全國性實體賽，例如 2025-11-09 新竹市長盃（社會甲組冠軍獎金 1 萬元）、2026-07-26 臺北市中正盃全國象棋錦標賽（10 組，含段位 A–D 與小棋手組）；線上平台單款下載／營收資料（未證實）——台灣沒有一款明確主導的本土象棋 App
- **技巧 vs 運氣**：完全資訊、零隨機的純技巧對弈；唯一不對稱是紅方先手

## 一句話玩法

9×10 棋盤，紅黑各 16 子輪流走，先將死或困斃對方的將帥者勝。

## 規則書

### 勝負條件
- **將死**：對方將／帥被將軍且無法解除 → 勝。
- **困斃**：輪到對方走卻無任何合法著法（象棋的困斃算輸，和西洋棋的逼和不同）→ 勝。
- **超時作負**：台灣實體賽規程明訂「超時作負」。
- **違反棋例作負**：長將、長捉無根子等禁止著法，經裁判裁決仍不變著 → 判負（見下）。
- **和棋**：雙方都無勝勢、協議和，或出現「允許著法」的循環且雙方都不變著。

### 單局流程
1. 紅方先行，雙方輪流各走一步，不可 pass。
2. 子力：帥／將 1、仕／士 2、相／象 2、俥／車 2、傌／馬 2、炮／包 2、兵／卒 5。
3. 走法要點：將帥限九宮、不得「對面」（同一直線中間無子）；仕走九宮斜線；相走田字且不過河、塞象眼不能走；馬走日字、蹩馬腳不能走；炮隔一子吃子；兵卒過河前只能前進，過河後可左右。
4. 實體賽採「摸子走子、離手為定」，不得發出干擾對手的聲響。
5. 對局到將死、困斃、超時、判負或和棋為止。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 單局（積分編排制） | 勝 2 分、和 1 分、負 0 分（新竹市 114 年市長盃規程） |
| 同分排名順序（新竹市長盃） | 對手分 → 兩人對賽勝者 → 勝局多 → 後手勝局多 → 後手局數多 → 強對手分 → 技術犯規少 |
| 用時（2026 臺北中正盃段位組、晉段組） | 每方限時 15 分鐘、每步加 5 秒 |
| 賽制 | 積分編排制（瑞士制類），小棋手組 4 人一組循環 |
| 報名費 | 600 元（入門組、小棋手組 500 元） |
| 獎金（2025 新竹市長盃） | 社會甲組（六段以上）冠 10,000／亞 5,000／季 3,000／殿 2,000；其他組冠軍 5,000 |
| 升段 | 段位 B 組八取一升肆段；C、D 組與晉段組六取一升段（中正盃） |

### 棋例（循環局面判定）— 本遊戲最難的規則
台灣賽事多寫明依《中華民國象棋規則》96 年（2007）修訂版。地方規程摘錄的常見棋例：
- **禁止長將**：單方連續將軍形成循環，三回合後經裁判裁決仍不變著 → 長將方判負。
- **禁止長捉**：連續追捉「無根子」（沒有保護的子）形成循環，三回合後仍不變著 → 判負。

《中華民國象棋規則》全文中更細的條文（例如一將一捉）本文未取得原文（未證實）。以下是兩岸傳統棋例的共同框架，整理自世界象棋聯合會刊載的規則沿革文：
| 類別 | 著法 | 結果 |
|---|---|---|
| 禁止（違者判負） | 長將、長要殺、長捉無根子、一將一捉、一將一要殺、一將一要抽、將帥對面 | 犯規方需變著，不變判負 |
| 允許（雙方不變判和） | 一將一閒、長兌、長跟、長攔、解將還將、兵卒長捉、將帥長捉、車馬循環反捉 | 和棋 |
| 雙方都犯規 | — | 一般作和 |
- 「捉」的認定：被捉子若有保護（有根子），一般不算違規的長捉；將帥與兵卒追捉通常不計入長捉。
- 線上 App 一般用「同局面重複 N 次」自動判定，各 App 標準不一。有 App Store 評論反映「電腦可以長捉，玩家不行」，可見自動判例是常見爭議點。

### 操作
- 點選棋子 → 點目標點；App 多有悔棋（限人機）、提示、殘局關卡、棋譜存檔。

### 公平機制（同種子、同牌序、配對、防作弊）
- **先後手平衡**：實體賽統計「後手勝局」作為同分排名條件，以補償後手劣勢；線上一般輪流執紅或隨機分配。
- **棋力分組**：實體賽依段／級位分組並設升段比例；線上以 Elo 類積分配對（各 App 不同，（未證實））。
- **防作弊**：引擎輔助是最大風險。2024-09 中國象棋協會因軟體作弊操縱賽果，終身禁賽特級大師王天一、王躍飛並撤銷等級稱號；2025-01 再處罰 41 人。實體賽禁止教練與陪同人員進入賽場；線上需用行為偵測（著法與引擎吻合度、用時規律）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 開局佈陣（中炮、屏風馬、飛相局…） | 決定中局主動權 |
| 中局戰術（抽將、雙將、悶宮、棄子攻殺） | 直接決勝 |
| 殘局知識（單馬擒士、單車勝士象全等定式） | 子力少時把優勢轉成勝局；台灣比賽規程甚至附殘局題 |
| 棋例掌握（利用允許著法求和、避開禁止著法） | 劣勢方的救命技巧，也是高段棋手的分水嶺 |
| 用時管理（15 分＋5 秒） | 快棋賽常見超時判負 |

## 隨機 / 運氣來源

- 無。只有先手優勢，以及配對時遇到的對手強弱（瑞士制抽籤）。

## 參賽與變現

- **實體**：報名費 500–600 元；獎金由主辦方或政府提供，屬依名次給獎的公開賽；升段證書另收證書費。
- **線上 App**：廣告＋去廣告＋遊戲幣／道具（悔棋、提示）；殘局關卡、排位賽季。台灣部分平台把象棋和麻將、娛樂城放在同一 App，若以遊戲幣輸贏會受「輔 15 級」規範。

## 主題與美術風格

- 木紋棋盤、紅黑圓子、書法字是基本款；常見改編包括 Q 版楚漢／三國武將化、水墨背景、古風音樂。
- 實體賽事文化：正裝出席、「以棋會友」的傳統雅趣定位。

## 可借用的設計點

- **棋例自動裁判**是象棋數位化的難點，做得好就能拉開差距：循環偵測要把「將／捉／閒」逐步標記清楚，並向玩家說明判負原因。
- **段位證書 × 升段比例**：「八取一升段」這類實體制度可以直接搬成線上晉級賽。
- **加秒制快棋（15 分＋5 秒）**：兼顧單局長度與減少因時間不足落敗，適合手機。
- **殘局關卡**：短局、單人、可每日更新，是棋類 App 的留存主力。
- **後手補償統計**：用「後手勝局」當排名條件，是很便宜的公平性設計。

## 法規 / 風險備註

- 棋類本身合法；實體賽固定報名費、依名次給獎、不抽頭，屬技巧競賽。
- 如果線上以可兌現的遊戲幣對賭 → 落入刑法賭博疑慮；遊戲分級若有虛擬幣輸贏的棋弈 → 輔 15 級。
- 引擎作弊與「假棋」（操縱賽果）是信任風險，需要有制度化的懲處。
