# 荒野亂鬥（Brawl Stars）

- **代號**：tw-brawl-stars
- **市場**：台灣
- **形態**：手機線上 F2P 短局 PvP（3v3 團隊目標戰＋大逃殺）
- **代表產品 / 廠商**：《荒野亂鬥》— Supercell
- **熱度依據**：App Store 台灣 4.3 分、**25 萬則評分**，動作類免費榜第 8（2026-10 快照）；Supercell 稱荒野亂鬥是 **2024 年全球成長最快的手遊**，並首次擠進全球營收前 10；AppMagic 估計 2024 年前 4 個月的營收已超過 2023 全年；Supercell 2024 年營收約 30 億美元（年增 77%）。台灣營收排名（未證實）——2024 年台灣手遊營收前十名中未見本作
- **技巧 vs 運氣**：技巧主導（瞄準、走位、地圖控制、組隊配合）；運氣來源是配對隊友、地圖輪替、大逃殺中能量方塊箱的分布，以及「戰力等級」養成落差

## 一句話玩法

選一位英雄（Brawler），在 2–3 分鐘的俯視角短局中完成模式目標。

## 規則書

### 勝負條件（主要模式）
| 模式 | 人數 | 勝利條件 |
|---|---|---|
| 寶石爭奪（Gem Grab） | 3v3 | 隊伍持有 ≥10 顆寶石並守住 **15 秒**倒數；同數時倒數暫停；有一說是 16 秒（未證實） |
| 荒野決鬥（Showdown） | 單人 10 人／雙人／三人（三人組 12 人） | 最後存活；開箱取得能量方塊提升攻擊與血量；毒圈縮小 |
| 亂鬥足球（Brawl Ball） | 3v3（另有 5v5） | 先進 **2 球**，或比賽時間結束時領先；平手進入延長賽 |
| 賞金獵人（Bounty） | 3v3 | 擊倒敵人得分，連殺價值遞增；時間到分高者勝 |
| 金庫攻防（Heist） | 3v3 | 先摧毀對方金庫（2025-04 更新為金庫加入暫時護盾） |
| 淘汰賽（Knockout） | 3v3 | 不復活；先贏 **2 回合**者勝（Bo3 回合） |
- 平分時：寶石爭奪等模式進入「驟死賽」，障礙物移除，先得分者勝。

### 單局流程
1. 選模式 → 配對（盃數／排位分）。
2. 選英雄（排位中段以上採 ban/pick 選角）。
3. 對戰約 2–3 分鐘（依模式，（未證實）各模式精確時長）。
4. 結算：盃數增減（一般模式）或排位分（Ranked）。

### 計分規則（盃數與排位）
| 項目 | 分數 / 條件 |
|---|---|
| 盃數（Trophies） | 每位英雄各自累積；勝加、敗扣；用於一般配對與解鎖（Trophy Road） |
| 排位解鎖 | 總盃數 **1,000** |
| 排位分（Rank Score） | Elo 式分數，和盃數分開；勝過高分對手加更多、輸給低分對手扣更多 |
| 段位 | 青銅、白銀、黃金、鑽石、神話、傳奇、大師（各 I–III）＋ **Pro**，共 **22 階** |
| 段位門檻（社群整理，非官方） | 青銅 0／白銀 750／黃金 1,500／鑽石約 2,500／神話約 4,000／傳奇約 5,500／大師約 9,000／Pro 約 11,250+ |
| 戰力門檻 | 青銅–黃金：3 位英雄達戰力 9；鑽石：9 位達戰力 9；神話以上：**12 位達戰力 11** |
| 對戰格式 | 青銅–鑽石：單局（Bo1）；神話–Pro：**Bo3** |
| 選角 | 青銅–黃金：盲選、不 ban；鑽石：ban＋快速選角；神話以上：同時 ban，之後蛇形選角（擲硬幣決定先選），每次選角 **20 秒** |
| 賽季 | 約 1 個月，與 Brawl Pass 同步；賽季重置往下掉，依上季最高段位給予「Rank Boost」 |
- 段位分數門檻來自代練／指南網站整理，Supercell 未公布官方分數表（標示為社群數值）。

### 操作
- 雙搖桿：左移動、右瞄準普攻（點擊自動瞄準／拖曳手動瞄準）；超級技能鍵、妙具（Gadget）、超級充能（Hypercharge，戰力 11 解鎖）。

### 公平機制（同種子、同牌序、配對、防作弊）
- **戰力等級上限 11**：養成會影響數值（攻擊、血量）以及配件（妙具、星徒能力、裝備、超級充能），是主要的「pay/grind-to-win」來源。
- **排位以戰力門檻＋同段位配對**：高段位要求 12 位英雄滿戰力 11，等於「大家都滿等才進高端」，把數值差壓到最低。
- **ban/pick**：降低版本強勢英雄的影響。
- **電競**：官方賽事使用滿等英雄（未證實具體帳號規範）。
- **觀戰／延遲**：（未證實）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 手動瞄準與預判 | 命中率決定擊殺 |
| 走位、草叢利用、牆體掩護 | 生存與偷襲 |
| 地圖控制（寶石礦、球、金庫路線） | 模式勝負核心 |
| 英雄克制與選角（Draft） | 高段位先決條件 |
| 超級技能／超級充能時機 | 團戰爆發點 |

## 隨機 / 運氣來源

- 隨機隊友（單排）、地圖與模式輪替（排位隨機抽 3v3 模式與地圖）。
- 荒野決鬥的開箱位置與毒圈收縮。
- 部分英雄技能有範圍散射，但不屬於機率判定。
- 抽獎道具（Starr Drop）只影響養成，不影響單局判定。

## 參賽與變現

- 免費遊玩；Brawl Pass（免費軌／付費軌；2024-01-04 起付費軌只能用真錢購買）。
- 2022-12 移除開箱（Box），改為信用點與 Starr Road；Starr Drop 為抽獎式獎勵；Wikipedia 記載 2026-09 Starr Road 被「Brawler Blast」取代（未證實）。
- 寶石（Gems）主要靠付費取得；外觀 Skin 為主要營收來源之一。
- App Store 台灣內購約 NT$33–430（2026-10 頁面所列項目）。

## 主題與美術風格

- 卡通 3D、誇張角色（牛仔、機器人、殭屍、搖滾樂手）、高彩度；季度主題與大型聯名（動漫、玩具）；介面 UI 大按鈕、強回饋。

## 可借用的設計點

- **「每位英雄各自盃數」**：讓玩家有多條進度線，避免單一數字卡關。
- **排位用養成門檻篩選**：高段位要求全員滿等，等於「排位＝準公平賽」，一般模式則保留養成樂趣。
- **段位決定賽制複雜度**：低段 Bo1 盲選、高段 Bo3 蛇形選角，新手不被規則嚇跑，高手得到深度。
- **2–3 分鐘短局＋多模式輪替**：手機碎片時間友善，也避免單一模式疲乏。
- **校園賽**：「校園亂鬥盃」（台港澳國中至大專生，2025-01-22 總決賽）把在地學生社群變成電競入口。

## 法規 / 風險備註

- 台灣分級：**輔導 12 歲級**（App Store 台灣頁面）。
- Starr Drop 等機會型獎勵需公開機率（台灣定型化契約）。
- 未成年付費爭議：以付費軌與抽獎為主要變現手段，需提供家長控制。
