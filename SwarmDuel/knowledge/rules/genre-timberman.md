# 伐木工（Timberman）

- **代號**：genre-timberman
- **市場**：台灣＋北美
- **形態**：超休閒手遊（F2P＋廣告）／Steam 低價版（含本地 8 人模式）
- **代表產品 / 廠商**：Timberman — Digital Melody S.A.（波蘭，作者 Paweł Kitajewski），2014-05 上線；續作 Timberman: The Big Adventure（2023-11，Steam / GOG / Xbox / PlayStation）
- **熱度依據**：
  - **北美**：2014-07 獲 Apple 編輯推薦後 3 天約 100 萬下載、累計 250 萬，App Annie 顯示在 20 多國總榜前五（TechCrunch）。App Store 頁宣稱 2,000 萬+玩家、Steam 頁宣稱近 3,000 萬（開發商說法；SteamSpy 估 Steam 擁有者 50–100 萬）。2024–2026 屬長尾：美區 App Store 僅約 523 則評分、4.0 星，最新版本 2025-04-08（仍在維護）。真正的熱度在其衍生的「左右點擊躲障礙」超休閒模板與大量仿作。
  - **台灣**：台區 App Store 僅 7 則評分（2026-10）；中文圈有 2014 年愛範兒介紹；無台灣排行數據（未證實）。
- **技巧 vs 運氣**：技巧主導（反應＋節奏＋時間管理）；樹枝生成是隨機的，固定 seed 後即為純技巧

## 一句話玩法

點左或右讓伐木工換邊砍樹，躲開往下掉的樹枝，並在時間條見底前持續砍。

## 規則書

### 勝負條件
- 被樹枝打到頭 → 結束。
- 時間條歸零 → 結束。
- 分數＝砍的次數；挑戰最高分 / 全球排行（Game Center）。

### 單局流程
1. 伐木工站在樹幹左或右側；畫面上方有時間條。
2. 點螢幕左半 → 移到左側並砍一下；點右半 → 移到右側並砍一下。每砍一下，樹幹下降一節。
3. 樹枝從樹頂出現、隨每次砍伐往下移；iMore 攻略稱樹枝出現後約 4 次砍伐就會到頭部高度。
4. 若下一節（將落到頭部高度的那節）在你所在那側有樹枝 → 必須先換邊再砍。
5. 每次砍伐補一點時間條；時間條持續流逝，且分數越高（等級越高）流逝越快。
6. 任一失敗條件觸發 → 結算分數。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 每次砍伐 | +1 分（speedrun 社群指出樹枝不額外加分，只是讓你必須換邊） |
| 等級 | 砍越多升級越高，時間條流逝加速（升級門檻與速度值未證實） |
| 時間補充 | 每砍一下補少量；具體補充量與流逝率官方未公開（未證實） |
| 本專案建議參數（非原作數值） | 時間條上限 6 秒；每砍補 `0.15 + 2 / 分數` 秒；流逝率每 20 分 +10% |
| 樹枝規則 | 同一節只會有一側樹枝（未證實，常見仿作規則）；常見節奏「砍兩下、換邊、砍兩下」（攻略觀察，非固定規則） |

### 操作
- 點左 / 點右（或鍵盤左右）。單一輸入同時完成「移動＋攻擊」。

### 公平機制（同種子、同牌序、配對、防作弊）
- 原版：本機最高分＋全球排行，無同種子。
- Steam 版有 Timbermill 模式：最多 8 人本地同時遊玩、限時回合比分（Steam 頁描述）。
- **競技化設計建議**：
  1. 同 seed 樹枝序列：所有參賽者面對完全相同的樹枝排列（第 n 節的樹枝側＝PRNG(seed, n)）。
  2. 兩種賽制：(a) 生存制——比最高砍數；(b) 限時制——固定 30 秒，比砍數（但仍有樹枝即死）。
  3. 計分：`砍數 + 連續無猶豫加成`（例如兩次砍伐間隔 < 0.25 秒計為「疾速」+0.5）。
  4. 防作弊：伺服器以 seed＋輸入時間序列重播；過於規律的間隔（標準差極小）列為巨集嫌疑。
  5. 1v1 同步版：雙方同 seed 分屏，先倒者敗，看得到對手進度（製造壓力）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 預讀樹枝 | 看上方 3–4 節提前規劃換邊 |
| 速度控制 | 越快補越多時間，但越容易判斷錯 |
| 時間條管理 | 前期存滿時間條，後期才有餘裕 |
| 節奏穩定 | 後期流逝極快，需穩定高頻輸入 |

## 隨機 / 運氣來源

- 樹枝序列（固定 seed 即可消除）。

## 參賽與變現

- 2014：免費＋每隔幾局插頁廣告；US$0.99「Golden Edition」去廣告並解鎖內容。
- 現行美區內購：去廣告 US$0.99、全角色 US$1.99、金幣包 US$0.99–6.99、特殊角色包 US$0.99、限時優惠 US$1.99–3.99。
- 角色（外觀）是主要收藏 / 付費點，不影響數值（未見數值差異說明）。

## 主題與美術風格

- 8-bit 像素、伐木工＋大樹＋季節背景；大量可解鎖角色（含流行文化戲仿）。
- 極簡、單一畫面、高對比，非常適合短影音與廣告素材。

## 可借用的設計點

- **「時間條＋每次動作補時」**：把「快」直接轉成「活更久」，不需要額外計分系統就有速度壓力。
- **「單輸入＝移動＋攻擊」**：左右兩鍵已足夠構成完整的決策迴圈。
- 預讀距離（約 4 節）＝難度旋鈕：縮短預讀距離就能提高難度。
- 角色只換外觀：付費不影響公平。
- 同 seed 化成本極低，最適合做每日挑戰與 1v1 分屏對戰。

## 法規 / 風險備註

- 「Timberman」為 Digital Melody 商標；玩法已被大量仿作，機制本身不受保護，但名稱 / 美術需原創。
- 超休閒廣告密度高易遭負評；競技模式應無廣告續命。
