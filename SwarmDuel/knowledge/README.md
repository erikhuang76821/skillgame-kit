# Skill Game 知識素材庫（台灣 / 北美）

純文字素材庫：熱門**純技巧** skill 玩法的**規則書**、兩個市場的**流行內容**、**主題風格**。資料截至 2026-10；無法證實的數值一律標「（未證實）」，每份檔案末尾附來源。

**範圍**：只收結果由玩家技巧決定的遊戲。機率／博弈類（老虎機、魚機、推幣、夾娃娃、禮品機、skill 終端、麻將、撲克）已移到 [_archive/excluded-chance-gambling/](_archive/excluded-chance-gambling/README.md)，排除標準見該檔。

## 兩市場對照

| 面向 | 北美 | 台灣 |
|---|---|---|
| 主流形態 | 手機技巧錦標賽（Skillz、Papaya、Avia）；酒吧／FEC 技巧街機 | 手機 PvP（傳說對決、荒野亂鬥、皇室戰爭）；飛鏢、撞球、音遊機台；棋類 |
| 第一大品類 | 接龍、賓果 | MOBA／3v3 射擊（觸及最大）；營收榜頂端為博弈，已排除 |
| 現金獎 | 約 35–40 州合法（技巧主導測試）；18+ | 無專法；彩票→禮品（每次 ≤1,000 元）較安全 |
| 公平機制 | 同種子非同步對戰 | 排位標準化等級、公開評級（飛鏢 Rating）、確定性計分（音遊） |
| 2026 大事 | Papaya 因 bot 判賠 7.19 億美元 | 博弈類遭監察院糾正、牌類虛擬幣研議 18+；簡體機台退場 |
| 熱門題材 | 牌桌／賓果休閒、Cozy、像素 survivor、Americana、季節活動 | Q 版／LINE 角色、日系 IP、三國、台味夜市、廟會 |
| 避開 | 老虎機視覺、原住民意象、官方運動商標 | 娛樂城紅金語言、簡體／支語、宗教不敬 |

## 跨市場可借用的規則模式

| 模式 | 來源 | 解決什麼 |
|---|---|---|
| 同種子非同步對戰 | Solitaire Cube、Golden Tee | 公平、可驗證、配對流動性 |
| 基礎分＋連擊＋時間獎勵（有上限） | 21 Blitz、Solitaire Cube | 技巧天花板、平衡、異常偵測 |
| 失誤有代價（3 次爆牌出局） | 21 Blitz | 風險決策 |
| 技巧換道具（塗記充能） | Blackout Bingo | 好手拿更多資源 |
| 過關門檻延長時間 | 台灣籃球機 | 技巧直接換多玩時間 |
| 透明保底、不歸零 | 台灣夾娃娃保夾（品類已排除，僅借機制） | 付費上限與信任 |
| 卡片存檔＋全國排行 | 太鼓、maimai | 長線技巧成長 |
| 公開評級（Rating 1–18） | 飛鏢 | 可解釋的實力分級與配對 |
| 禁手＋開局交換 | 連珠 | 用規則而非隨機抵銷先手優勢 |
| 固定波次腳本 | Bloons TD、Kingdom Rush | 塔防天然同種子，可直接競速比賽 |
| 一鍵雙向攻守 | One Finger Death Punch、Snake io | 極簡輸入、高技巧天花板 |
| 年度版本＋聯賽＋世錦賽 | Golden Tee、Big Buck Hunter | 長線營運 |
