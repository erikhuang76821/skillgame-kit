# No Chance Games / Pre-reveal（預揭示型「無機會」機台）

- **代號**：na-v-no-chance-preveal
- **市場**：北美（密蘇里、田納西為主；維吉尼亞、北卡等地有「View All Outcomes Before Playing」同類機）
- **形態**：店面技巧/娛樂機台（加油站、便利店、酒吧）
- **代表產品 / 廠商**：Torch Electronics「No Chance Games（NCG）」— 機台由第三方製造、Torch 母公司採購營運；其他 pre-reveal 機型供應商（未證實）
- **熱度依據**：密蘇里 Torch 為最大營運商，機台遍布加油站（2026 前；台數未公開）；2025-10 聯邦陪審團、2026-02-13 聯邦法官判決後全面停機
- **技巧 vs 運氣**：業者主張「零機會」（玩家下注前就看到結果），實質是預設序列的老虎機；法院一律判定為賭博設備

## 一句話玩法

按下前先在 Prize Viewer 看到「下一局會贏多少」，再決定要不要付錢玩它。

## 規則書

### 勝負條件
- 每局結果為**預先決定、有限長度的序列**中的下一個（未證實具體實作）。
- 玩家在付費前可透過 **Prize Viewer / 預覽鍵** 看到下一局的獎金（含 0）。
- 要看到「再下一局」，必須先把目前這局玩掉（付費推進序列）。

### 單局流程
1. 入鈔換點數。
2. 按「預覽」顯示下一局結果（例如「此局贏 $0」或「此局贏 $5」）。
3. 玩家選擇：
   - 付費遊玩 → 動畫轉輪（類老虎機），結果與預覽一致。
   - 不想玩 → 無法跳過；只能離開，或付費玩掉「已知為輸」的一局以推進序列（業者另有「付費換下一盤」選項者，未證實）。
4. 累積點數列印票券向店家兌現。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 單局結果 | 等於預覽所示，與玩家操作無關 |
| 序列總回報 | 由序列設計決定（實際 RTP 未公開，未證實） |
| 兌換 | 票券→店家現金（各州是否合法即爭點） |

### 操作
- 預覽鍵、押注鍵、Play；部分機台尚有「解謎/點選」步驟作為娛樂元素（未證實）。

### 公平機制（同種子、同牌序、配對、防作弊）
- **業者論點**：資訊完全公開 → 玩家每次都在「已知結果」下做決定 → 不存在 chance，不符賭博三要素（對價、機會、獎品）。
- **法院反論**（田納西 2025 Torch v. Mulroy、密蘇里聯邦 TNT Amusements v. Torch 2026-02-13）：
  - 只看得到下一局，看不到之後；從玩家坐下那一刻起，整段遊玩的結果仍屬未知 → 機會依然存在。
  - 想得到下一個贏局，必須先付錢玩掉輸局 → 就是付費買機會。
  - 依州法「gambling device」定義即可涵蓋。
- 陪審團（2025-10）另認定 Torch 對機台合法性有不實陳述。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 決定何時停手 | 看到 0 就走 → 但無法讓下一位幫你推序列（實際上機台序列由所有人共享，未證實） |
| 「找空機」 | 觀察他人放棄的機台可能接續贏局（玩家社群做法，未證實） |

## 隨機 / 運氣來源

- 序列本身是由 RNG 或預設表產生；玩家只能看到一步。
- 是「把機會搬到序列生成時」的設計，法院不採信。

## 參賽與變現

- 單人機台；營運商、店家分成（比例未公開，未證實）。
- 密蘇里 2026 HB 2989（VLT 合法化）：每點上限 8 台、31% 稅 + 3% 地方稅 — 眾院 83:66 通過，參院特別委員會 5:0 否決。

## 主題與美術風格

- 與一般 Class III / COAM 老虎機同：水果 7、BAR、鑽石、財神、龍、野牛、自由女神/國旗愛國主題（個別款名未證實）。
- 店頭常貼「No Chance」「View All Outcomes Before Playing」「No Skill」標示，視覺上刻意以「透明」為賣點。

## 可借用的設計點

- 「資訊揭露」可以是有趣的設計元素（例如預覽下一個盤面再決定策略），但**不能**用來當合法性護身符。
- 反例教材：任何「付費推進預設序列」的設計，在北美多州會被視為賭博。

## 法規 / 風險備註

- 密蘇里：2026-02-13 聯邦法院判為賭博設備；Torch 表示上訴，但 2026-04-10 起暫停 NCG；州檢察長 Hanaway 擴大執法；有酒吧業主 2026-06 起訴檢察長越權。
- 田納西：2025 年 Shelby County 案判 NCG 為賭博設備、駁回 Torch 訴訟。
- 維吉尼亞：2024 年起出現「View All Outcomes」機台作為禁令後替代品（Virginia Mercury）。
