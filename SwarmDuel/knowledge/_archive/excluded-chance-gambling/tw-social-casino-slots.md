- **代號**：tw-social-casino-slots
- **市場**：台灣
- **形態**：線上 F2P（單向儲值、「不出金」的虛擬幣平台）；平台內含老虎機（拉霸）、捕魚、麻將、百家樂、德撲、賓果、柏青哥、刮刮樂等館
- **代表產品 / 廠商**：星城Online — 網銀國際；包你發娛樂城 — YILE Technology（中文名（未證實））；老子有錢；金好運／金有錢 娛樂城；大福娛樂城；ATT／好玩 等同類（營運主體部分（未證實））。Niko/Sensor Tower 列出台灣主要社交博弈發行商：網銀、Galaxy、Gamesofa、鈊象

## 一句話玩法

儲值買金幣，在各種拉霸、牌桌、捕魚館消耗與贏取金幣，追 Big Win 與 VIP 等級。

## 規則書

### 勝負條件
- 無終局；以金幣存量、VIP 等級、排行榜名次、活動大獎作為目標。

### 單局流程（以老虎機為例）
1. 選館／選機台（主題機台），選擇押注額（每轉金幣數）。
2. 按「轉動」（或自動轉 N 次）。
3. 停輪後依連線表（Paytable）計算中獎；Wild 替代、Scatter 觸發免費遊戲。
4. 特殊：免費遊戲（Free Spins）、倍數加成、Bonus 小遊戲、累積彩金（Jackpot：Mini/Minor/Major/Grand）。
5. 金幣回到餘額；可換館。

### 計分規則
| 項目 | 常見設定（依機台，數值（未證實）） |
|---|---|
| 盤面 | 5×3 為主；亦有 6×5「消除型」（Cascade）、243／1024 Ways |
| 連線 | 25–50 條線，或 Ways 由左至右相鄰同符號 |
| Wild | 替代除 Scatter 外所有符號；可能帶倍數 |
| Scatter | 3 個以上觸發 Free Spins（常見 8–15 轉） |
| Big / Mega / Super Win | 以押注倍數分級（例 ≥15×、≥30×、≥50×） |
| 回饋率 RTP | 社交博弈不受監理，業者自訂、不公開 |
| VIP | 依累積儲值／押注升級；高等級享更高單注上限、專屬客服、回饋 |

### 操作
- 單鍵轉動、自動轉、快速停輪（Turbo）；牌類與捕魚有各自操作（見 tw-fishing-arcade、tw-taiwan-16-mahjong）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 伺服器 RNG；無第三方認證要求。
- 平台風控：OTP 驗證、異常儲值監測（星城）。
- **單向金流**：可儲值、官方不回收／不換現 —— 這是與網路賭博的唯一法律分界（警政署語）。
- 然而多數平台有**玩家間贈禮／轉帳**或交易所功能，遭「幣商」利用（見下）。

- **VIP 階梯與專屬服務**：台灣重度付費者重視身分與「被照顧」。
- **名人＋台味廣告**：觸及 35–65 歲族群最有效的行銷語言。
- **多館集合平台**：一個帳號錢包串多種玩法，提高留存。
- **活動節奏**（節慶、加倍時段、排行賽）：週期化營運。

## 法規 / 風險備註

- **遊戲分級**：遊戲軟體分級管理辦法第6條第6款 —「使用虛擬遊戲幣、結果直接影響虛擬幣增減的棋弈／牌類／益智娛樂類」→ **輔15級**（2019-05-23 由保護級提升）；不影響虛擬幣增減者 → 輔12級。須在包裝／下載頁／起始畫面標示「不得利用遊戲賭博…」警語（違者 3–15 萬罰鍰）。數發部正評估是否提高到限制級 18+。
- **刑法**：第266條（2022-01 起明定網路賭博）、第268條（營利聚眾）。虛擬幣若具「客觀經濟價值＋可變現性」即可能構成「財物」。
- **定型化契約**：電磁紀錄屬業者所有，玩家支配權不含遊戲外移轉、收益；數發部要求業者不得提供虛擬幣換現功能並宣導「本遊戲不提供現金交易」。
- **幣商**：無主管機關（數發部、金管會互推）。高等法院台中分院 114 年度上易字第 61 號（2025，上訴中未確定）認定幣商與娛樂城網站成立共同正犯（證人稱娛樂城聊天室大量幣商廣告，兌換約 1:144）。2025-12 刑事局破獲新北土城幣商集團：會員逾 8 萬筆、出金 38.6 億、資金流 80 億，於 5 款知名平台頻道招攬。
- **監察院 2026-07 調查報告**：批評數發部管制鬆散、要求行政院指定幣商主管機關、檢討博弈遊戲廣告（通傳會 2019–2025 接獲 31 件電視「賭博」廣告陳情，無一處分）、研議賭博網站封鎖（DNS RPZ 1.5 已於 2025 Q1 終止）。
- **機率揭露**：2023-01-01 起，網路連線遊戲須於官網、登入頁或購買頁公布付費機會型商品機率。
