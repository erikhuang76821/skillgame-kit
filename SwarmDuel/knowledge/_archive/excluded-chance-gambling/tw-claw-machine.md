# 夾娃娃機 / 選物販賣機（Claw Machine / 自助選物販賣機）

- **代號**：tw-claw-machine
- **市場**：台灣
- **形態**：選物販賣機（店面無人自助店）＋線上遠端娃娃機 App（附帶）
- **代表產品 / 廠商**：無單一品牌；店型為「場主出租機台、台主上架商品」的無人店；大型連鎖如夾子園（2023 一年內展店約 30 家）；線上有 Toreba 抓樂霸（CyberStep）、卡普抓樂（CAPCOM）
- **熱度依據**：財政部稅籍：2016 年 2,356 家 → 2019 年 9,784 家 → 2020 年破萬家（高峰）；娛樂稅口徑的機台／稅籍數 2021 年 9,508 → 2024 年 10,474（仍緩增）。2024 年全國娛樂稅 20.9 億元，夾娃娃機約占 2 成，為納稅戶數最多的單一類別。2026-05-22 財政部公告「娛樂場所範圍」，正式把夾娃娃機、寶可夢卡匣機列入課稅
- **技巧 vs 運氣**：半技巧。單次是否夾起受爪力設定（台主調整）影響很大；靠「保證取物」累積額度兜底，玩家技巧主要在於降低到達保夾前的花費

## 一句話玩法

投幣操控天車對位下爪，把商品夾或推進出口即可帶走；投滿保證金額必出貨。

## 規則書

### 勝負條件
- 商品掉入取物口即「出貨」（勝）。未掉落則本局結束，投入金額累積進「保證取物」計數。
- 累積投入達機台標示的**保證取物金額**後，機台必須進入強爪／必出狀態，直到商品取出為止。

### 單局流程
1. 投幣（常見每局 NT$10；部分台 NT$20／50 或「100 元 11 次」優惠，（未證實）常見組合）。也有接受悠遊卡等電子支付的機台（2019 起出現）。
2. 倒數計時內（常見 15–30 秒，（未證實））用搖桿前後左右移動天車；部分機種可旋轉爪頭。
3. 按下爪鈕（或時間到自動下爪）→ 爪下降、閉合、上升、回到出口上方張開。
4. 商品落入出口＝出貨；機台的保夾計數歸零重算。
5. 未出貨 → 累積金額 + 本局投幣；顯示「再 XX 元保夾」的機種會提示距離。

### 計分規則
| 項目 | 條件 / 數值 |
|---|---|
| 保證取物金額上限 | 不得超過 NT$990（經濟部 2024-10-14《自助選物販賣事業管理規範》；舊制 2018 評鑑標準為 790 元，且商品市值須達保證金額 7 成） |
| 保夾計數 | 累積投入金額／次數**不得任意歸零**（換商品、斷電、台主清台不能吃掉玩家已累積額度） |
| 必出狀態 | 投足後須維持強爪直到出貨（不能只給一次強爪） |
| 強爪／弱爪設定 | 主機板可設「強力電壓」「弱力電壓」「保夾金額／次數」「天車速度」「爪下降深度」等（項目為業界常見設定，數值（未證實））；投足前把爪力調到極弱屬灰色地帶，若造成無法取物可能涉詐欺 |
| 禁止獎品 | 現金、有價證券、電子支付儲值、菸酒檳榔、藥品與醫材（含醫用口罩）、成人用品、活體動物、刀械、刮刮卡／戳戳樂 等 |
| 禁止裝置 | 改裝、障礙物、彈跳或磁吸裝置、骰子、轉盤、輪盤（加入射倖元素即可能被認定為「電子遊戲機」） |

### 操作
- 搖桿 8 向 + 下爪鈕；部分有「二段下爪」或「旋轉」鈕。
- 機台種類：三爪（主流）、二爪／鋁條「推條台」、剪線台、推台（推落型）、大型巨無霸台；推台與剪線台若加入射倖機構，需特別注意是否違規。

### 公平機制（同種子、同牌序、配對、防作弊）
- 保證取物＝**付費上限保障**，是台灣把夾娃娃從「射倖」轉為「選物買賣」的法律核心。
- 機台外須標示：機具名稱、保證取物金額、台主聯絡方式、評鑑證明、製造商；場主須標示名稱、申訴專線、「理性消費」警語。
- 營業場所距國中小 50 公尺以上（各縣市自治條例；新北 2025 曾提案放寬但遭退回）。
- 監視器多由場主架設；店內無人看管，爭議靠台主電話處理。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 對位（前後側視角確認爪落點） | 決定是否抓到重心 |
| 讀爪力（觀察他人或試 1–2 次） | 判斷是「弱爪等保夾」還是「可技術夾」 |
| 戳洞／推／翻／甩／勾標籤 | 弱爪下用爪尖改變商品位置，逐步推向出口 |
| 計算保夾性價比 | 商品市價 vs 保夾金額 − 已累積額，決定接手或放棄（「撿台」：接手他人已累積的台） |
| 選台 | 擺位靠近出口、爪力強的台優先 |

## 隨機 / 運氣來源

- 強弱爪隨機（多數主機板以機率給強爪，（未證實）具體演算法依板子而異）。
- 商品擺放、重心、包裝材質。
- 「撿台」：前一位玩家留下的累積額度。

## 參賽與變現

- 單局小額付費，靠「快出貨」的期待+保夾兜底吸引長時間遊玩；店家收入＝場主機台租金（2018 報導：每台月租約 NT$3,000–10,000；一店 26–30 台）＋台主賣場差價。
- 台主月收入達門檻須報營業稅（舊報導：台主月 8 萬、場主月 4 萬）。娛樂稅依機台數分級課徵，例：桃園 26 台店每月娛樂稅 5,000 元以上。
- 趨勢：商品從絨毛娃娃轉向零食、泡麵、日用品、公仔、3C；大型店有點數兌換、店員服務；2026 年初超商開設店內夾娃娃區。
- 線上娃娃機：App 內購「代幣」遠端操控真實機台，夾到後累積再寄送（Toreba 每 7 天可免運寄一次；寄台灣超商運費約二百多元，（未證實）依平台）；新手免費次數、每日簽到、月訂閱。

## 主題與美術風格

- 日系動漫 IP 景品（三麗鷗、吉伊卡哇、寶可夢、蠟筆小新）、Q 版絨毛、零食貨架感；霓虹燈、亮色招牌；店名多為台語諧音或「XX 夾樂園」。

## 可借用的設計點

- **保證取物（Pity／保底）**：把「機率」轉為「付費上限」的心理與法律雙重設計，可移植為數位遊戲的保底計數器（需公開、不得歸零）。
- **撿台**：他人沉沒成本可被接手 → 製造圍觀與社交（直播觀看他人累積進度）。
- **「再 XX 元保夾」進度條**：明確距離提示強化續玩。
- **實體獎品＋寄送**：線上娃娃機把實體獎與數位操作結合，適合 O2O。
- **技巧作為降低成本的工具**：技巧不改變終局（保夾一定拿到），但讓高手更省錢，兼顧公平感。

## 法規 / 風險備註

- 主要依據：經濟部《自助選物販賣事業管理規範》（2024-10-14 經授商字第11303415261號）；保夾上限 990 元、不得歸零、禁止獎品與機構清單。
- 越線即變「電子遊戲機」：基隆地檢 2026-04 起訴台主，因改磁吸爪、加障礙／彈網、保夾超過 990 元、出貨可換刮刮樂 → 依《電子遊戲場業管理條例》未領營業級別證及刑法賭博罪起訴。
- 地方法院曾有判決不採經濟部函釋（認為過度擴張），法院見解並不統一。
- 消基會 2024 高雄抽查：31 家中大型店 26 家未張貼許可文件、11 家食品效期標示不清 → 食品類獎品需注意標示。
- 2026-05 起明列娛樂稅課徵範圍；部分縣市派員稽查。
