# 捕魚機（Fish Shooting / Fish Table，例：海王 Ocean King 系列）

- **代號**：tw-fishing-arcade
- **市場**：台灣（同時為台灣廠商出口的主力品類）
- **形態**：遊藝場多人台（電子遊戲場業「娛樂類」機具，限制級場所）＋手機／線上捕魚（娛樂城 App 內的捕魚館、明星3缺1「捕魚爭霸」等）
- **代表產品 / 廠商**：海王（Ocean King）系列 — 鈊象 IGS；星城Online 內捕魚館 — 網銀國際；鯊很大系列 等
- **熱度依據**：鈊象 2025 年營收 220.32 億元（年增 19%），授權遊戲營收占約 67%，網路授權主力即「捕魚系列、棋牌、三國戰紀 IP」；但公司表示台灣同類遊戲眾多、競爭激烈，國內網路遊戲營收衰退、轉向海外
- **技巧 vs 運氣**：運氣主導、技巧輔助。每發子彈的擊殺判定由機率（魚種倍率的倒數附近）決定；技巧在於選目標、選炮倍、時機與資源控制

## 一句話玩法

多人圍桌各控一門炮，花子彈射擊游動的魚，擊殺即依「炮倍 × 魚倍」得分。

## 規則書

### 勝負條件
- 無「勝負」終局；玩家以點數（遊藝場為代幣／分數，線上為遊戲幣）存量衡量成敗。點數歸零即結束。
- 遊藝場（限制級）只能以**獎品**兌換且每次價值有上限；線上 App 僅能「單向儲值、不出金」。

### 單局流程
1. 投幣／儲值換分，入座（實體台常見 6–10 人座，（未證實）依機型）。
2. 選擇**炮倍**（每發子彈消耗的分數，例 1、2、5、10…上至數百或上千倍，（未證實）依台設定）。
3. 瞄準發射；子彈碰到魚即進行一次**擊殺判定**。
4. 擊殺 → 獲得 炮倍 × 魚倍 分數；未擊殺 → 子彈消耗。
5. 魚潮分波次：一般魚群 → 特殊陣型魚潮 → **Boss** 出場 → 換場景。
6. 隨時可退分（實體台換彩票／獎品；線上回到大廳）。

### 計分規則
| 項目 | 分數 / 條件（業界常見，具體數值依機種，（未證實）） |
|---|---|
| 小魚（小丑魚、燈籠魚等） | 2–5 倍 |
| 中魚（海龜、魟魚等） | 8–20 倍 |
| 大魚（鯊魚、鯨等） | 20–100 倍 |
| Boss（海王、巨龍、章魚、海盜船等） | 100–500 倍以上；部分版本宣稱上千倍；需多發命中 |
| 特殊武器魚／道具 | 雷射炮（一定時間貫穿）、炸彈（範圍清魚）、連鎖閃電（同種魚連鎖）、鑽頭、全屏凍結 |
| 抽水（RTP 補數） | 參考文章示例為 10%（即理論回饋約 90%）；實機由營運方設定，（未證實） |
| 擊殺機率 | 約與魚倍成反比（期望值 ≈ RTP），故高倍魚「打很久不死」 |

### 操作
- 實體：搖桿／轉盤瞄準 + 發射鈕 + 加減炮倍鈕；可長按連發、鎖定目標。
- 線上：觸控點擊瞄準、自動射擊、鎖定 Boss（例：「優先攻擊 BOSS」鈕）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 全桌共享魚群：任何人都可打任何魚，**搶尾刀**（別人打殘、我收割）是常見社交張力；但多數實作是「每發獨立判定」，所以並非真的有血量。
- 實體機須經經濟部評鑑分類；不得改機。2025-10 新規：機台介面須正體中文，簡體中文娛樂類機具 2030-09-30 後不得營業。
- 線上：依遊戲分級辦法屬「牌類及益智娛樂類」→ 遊戲結果影響虛擬幣增減者為**輔15級**，須標示「不得利用遊戲賭博」警語。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 炮倍管理（魚少用小炮、Boss 出場切大炮） | 控制資金波動 |
| 目標選擇（慢速、靠近炮口的魚命中率高） | 提升每秒有效命中 |
| 子彈反彈路徑（打牆反彈） | 打到被遮擋的魚 |
| 特殊武器時機（等魚潮密集再用雷射／炸彈） | 一次多殺 |
| 搶尾刀與合作打 Boss | 社交層面的收益分配 |

## 隨機 / 運氣來源

- 每發擊殺判定的機率；特殊武器魚與 Boss 出現時機；轉盤／彩金類加成。
- 坊間「吃分期／吐分期」週期說法（觀察 30 局判斷）屬玩家迷思，無法驗證，（未證實）。

## 參賽與變現

- 實體：投幣換分 → 退分換彩票／獎品；《電子遊戲場業管理條例》第14條限制每次兌換獎品價值（限制級 2,000 元、普通級 1,000 元），**禁止**現金／有價證券與買回獎品。
- 線上：儲值買金幣（單向），VIP 等級、首儲禮、每日簽到、轉盤；捕魚通常是娛樂城 App 內的一個「館」。
- 違法變現：幣商換現、私下買回 → 刑事風險（見 tw-social-casino-slots）。

## 主題與美術風格

- 海洋、龍宮、海盜、美人魚、財神／金蟾蜍（招財）、三國／西遊記 Boss；高飽和、金幣爆噴、大字「BIG WIN」特效；中式紅金配色。

## 可借用的設計點

- **共享場景 + 個人判定**：多人同場競爭目標但互不影響期望值 — 適合非同步 PvP 化。
- **炮倍＝下注大小的直觀化**：把投注轉成「火力」，可轉為技巧型：命中判定改為物理/準度決定，倍率改為固定，達成技巧化。
- **Boss 事件**：全場同時追逐，製造高潮與直播素材。
- **特殊武器**：讓清場變成可規劃的技巧時刻。

## 法規 / 風險備註

- 實體捕魚機屬娛樂類電子遊戲機，僅限 18 歲以上限制級場所；歷年查緝常見「合法牌照掩護兌現賭博」案例。
- 線上捕魚與娛樂城同屬監察院 2026 調查所指「與網路賭博核心要素高度相似」的類別；設計時避免任何可轉讓／回收金幣的機制。
- 若要做「技巧版」捕魚：需讓結果主要由玩家準度決定、獎勵不可兌現，才能避開射倖性爭議。
