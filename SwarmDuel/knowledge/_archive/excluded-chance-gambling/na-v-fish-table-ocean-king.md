# Fish Table：Ocean King / Fish Hunter（實體捕魚機台）

- **代號**：na-v-fish-table-ocean-king
- **市場**：北美（Game room、sweepstakes 遊藝廳、部分 COAM 州、Texas 八線機房）
- **形態**：店面多人技巧（射擊）機台
- **代表產品 / 廠商**：Ocean King 系列（Ocean King、Ocean King 2/3、Ocean King 3 Plus 各分支如 Thanos/Crab Avengers、Legend of the Phoenix）— IGS（Highway Games 曾為歐美代理）；大量中國仿版/改版（Fish Hunter、Golden Legend、Tiger Strike 等）
- **熱度依據**：IGS 2013 年起授權 Ocean King 歐美代理；北美 game room / 魚機館普遍，執法新聞（北卡、德州、喬治亞）頻繁；具體台數無公開統計（未證實）
- **技巧 vs 運氣**：視覺上是射擊技巧，但每發子彈是否「捕獲」由機率判定；北卡上訴法院 2023 認定 Ocean Fish King「主要靠運氣」

## 一句話玩法

6～10 人圍桌各控一門炮，付費發射子彈打魚，捕獲時依魚的倍率 × 炮值得分。

## 規則書

### 勝負條件
- 無「整局勝負」；每發子彈為一次獨立下注。
- 子彈命中魚時，系統判定是否捕獲：捕獲 → 得分 = 魚倍率 × 當前炮值（每發成本）。
- 玩家餘額增減即為輸贏；隨時可結帳（ticket / 櫃台）。

### 單局流程
1. 投鈔/由櫃台上分。
2. 以 + / − 調整炮值（每發成本；倍數炮）。
3. 搖桿瞄準、按鍵開火（可連發 / 自動鎖定）。
4. 每發扣分 → 命中 → 機率判定捕獲 → 加分動畫（金幣噴出）。
5. 計時或擊殺量條滿 → **Boss 魚**出場；特殊蟹/魚觸發全場特效。
6. 場景（關卡/海域）定時輪換，伴隨「魚潮」（大量魚群）。
7. 下分結帳。

### 計分規則（以 Ocean King Jackpot 版本為例；各版本不同）
| 目標 | 數量 | 最高倍率 |
|---|---|---|
| 一般魚 | 13 種 | 最高 20× |
| 巨型魚 | 6 種 | 最高 100× |
| 特殊蟹（功能魚） | 5 種 | 最高 800× |
| 覺醒 Boss | 4 種 | 最高 1,980× |
| Super Sea King | 2 種 | 最高 3,000× |

| 特殊目標（常見） | 效果 |
|---|---|
| Bomb Crab（炸彈蟹） | 爆炸清除範圍內魚並合計得分（原版 Ocean King 小遊戲） |
| Chain Thunder（連鎖閃電） | 閃電串連同種魚一起捕獲 |
| Twister / Vortex（漩渦） | 吸入多條魚 |
| Laser Crab（雷射蟹） | 獲得雷射一擊貫穿多魚 |
| Drill / Smash Hammer 等武器 | 穿透、範圍傷害（版本依存，未證實） |

- Boss 顯示倍率常為「最高可得」，非固定值（由命中當下抽倍率）。
- 炮值範圍、機台 RTP 由營運商設定（未證實具體數值；改版常調整勝率）。

### 操作
- 每席：搖桿（360° 瞄準）、開火鍵、加/減炮值鍵、（部分）鎖定鍵、特殊武器鍵。
- 共用大螢幕（桌面型 6/8/10 人或直立 2～4 人）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 每發子彈的捕獲機率約與「魚倍率」成反比，使長期期望值接近設定 RTP（業界普遍設計，未證實逐款）。
- 魚的「血量感」是視覺包裝；實際每發都是獨立抽籤（部分版本有累積傷害或保底，未證實）。
- 多人同桌共享魚群：可「搶尾刀」，視覺上形成競爭，但不影響個人機率。
- 北卡上訴法院：專家對技巧/運氣意見分歧不重要，因玩法本身無爭議，判定主要為機會遊戲 → 違反州 sweepstakes 禁令。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 目標選擇（打低倍高命中 vs 高倍 Boss） | 影響波動與資金曲線，不改長期期望（若為純機率） |
| 炮值管理（小魚低炮、Boss 高炮） | 控制風險；玩家社群核心攻略 |
| 瞄準與預判（魚會游出畫面） | 子彈打空 = 浪費；遇反彈牆可彎射 |
| 時機（魚潮、特殊蟹出現） | 高密度時一發多中機會較多 |
| 「撿尾刀」 | 別人打殘的大魚（若有累積機制，未證實） |

## 隨機 / 運氣來源

- 捕獲判定 RNG、Boss 倍率抽取、特殊蟹觸發。
- 營運商可調機台難度/抽水。

## 參賽與變現

- 單發即下注；無入場費。部分店有「打魚比賽」或累積大獎（Jackpot）。
- 遊藝廳收入 = 玩家淨輸；常搭配 sweepstakes 文件或「娛樂用途」標示規避（各州執法不一）。

## 主題與美術風格

- 海洋主題：熱帶魚、鯊魚、海龜、金蟾、美人魚、海龍王/金龍。
- 中國風財運：金幣爆出、龍、鳳凰（Legend of the Phoenix）、財神元素。
- 漫畫英雄混搭（Crab Avengers / Thanos 名稱，非正式授權者多）。
- 強烈色彩、粒子特效、大量金幣音效；Boss 進場全螢幕警示。

## 可借用的設計點

- 「共享魚群、各自結算」的多人同桌社交感，是魚機最強的留存要素。
- 倍率階層 + 特殊蟹全場特效，提供爆發與話題時刻。
- 若要真正技巧化：讓命中/捕獲以**可量化的累積傷害**決定（確定性血量），倍率依命中效率結算，才能在法院主張技巧主導。
- 炮值選擇提供「自我調控風險」的掌控感。

## 法規 / 風險備註

- **北卡**：2022 州最高法院（類老虎機屬機會遊戲）、2023 上訴法院（Ocean Fish King）→ 魚機違法，警方持續查抄。
- **德州**：八線機（eight-liner）付現違法，僅「fuzzy animal」條款（非現金獎品批發價 ≤ 單局費用 10 倍或 $5 取低者；刑法 §47.01，本次未取得原文，未證實）豁免；Harris County 2026 持續突襲與重開問題、遊戲室搶案（2026-07 聯邦起訴）。
- **喬治亞**：彩券局通知魚機若要作為 Class B，需符合中央會計系統、含技巧等規範。
