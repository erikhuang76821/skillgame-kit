# 德州撲克錦標賽（Texas Hold'em Tournament，台灣「智力運動」賽制）

- **代號**：tw-texas-holdem-tournament
- **市場**：台灣
- **形態**：實體競技（協會會員制錦標賽）＋國際巡迴賽台北站；線上僅有遊戲幣制 App
- **代表產品 / 廠商**：CTP 中華德州撲克協會（台北 Red Space、Asia Poker Arena）合辦 APT（Asian Poker Tour）、WPT Prime Taiwan；台灣華人德州撲克競技協會（桃園中壢起家）
- **熱度依據**：APT Taipei 參賽人次 2023 年 9,898 → 2024 年 13,804 → 2025 年 22,909（獎金 1,904 萬美元 ≈ NT$6.12 億）；APT Championship 2025（台北，11/14–30）約 200 場、保證獎金 NT$2.88 億，主賽 US$10,000 買入、保證 US$500 萬，號稱亞洲最大保證額；APT 台北站累計占全巡迴獎金約 27%；WPT Prime Taiwan 2025（8/6–19）保證 NT$5,000 萬+
- **技巧 vs 運氣**：技巧主導（長期），單手運氣高；台灣法院以「錦標賽依名次給獎、技巧為主」作為無罪理由之一

## 一句話玩法

每人 2 張底牌配 5 張公牌組最佳五張，以籌碼下注淘汰對手，依淘汰名次分獎金。

## 規則書

### 勝負條件
- 單手：攤牌時最佳 5 張牌型者贏得底池；或其他人全部棄牌。
- 錦標賽：籌碼歸零即淘汰；依淘汰順序決定名次，前約 10–15% 入圍獎金圈（常見比例，（未證實）各賽事公布）。

### 單局流程
1. 按鈕位（Dealer）輪轉；小盲、大盲強制下注（錦標賽常加前注 ante／大盲前注 BB ante）。
2. 發每人 2 張底牌 → **翻牌前**下注（大盲左手起）。
3. **翻牌**（3 張公牌）→ 下注；**轉牌**（第 4 張）→ 下注；**河牌**（第 5 張）→ 下注。
4. 動作：過牌、下注、跟注、加注、棄牌、全下（All-in）。無限注（NLH）為主流。
5. 攤牌比大小；邊池處理全下玩家。
6. 盲注依時間升級（常見每級 20–40 分鐘，主賽較長，（未證實））。

### 計分規則
| 牌型（大→小） | 說明 |
|---|---|
| 同花大順 | 同花色 10-J-Q-K-A |
| 同花順 | 同花色連續 5 張 |
| 四條（鐵支） | 4 張同點 |
| 葫蘆 | 三條 + 一對 |
| 同花 | 同花色 5 張 |

| 三條 | 3 張同點 |

- 花色不分大小；同牌型比點數與踢腳，完全相同則平分。

| 錦標賽結構要素 | 常見設定（台灣賽事；（未證實）以各賽公告為準） |
|---|---|
| 買入（Buy-in） | 日常賽數千元台幣；APT 主賽 NT$55,000（2025 APT Taipei）；冠軍賽 US$10,000 |
| 起始籌碼 | 買入的數十倍至百倍「籌碼點數」（籌碼不具現金價值） |
| 重購／再參賽 | Re-entry、晚報名 至第 N 級盲注 |
| 獎金分配 | 依名次表；含保證獎池（GTD） |
| 行政費 | 從買入中扣除部分作為主辦費用 |

### 操作
- 實體牌桌、專業荷官；線上 App 為觸控按鈕＋下注滑桿、計時（常見 15–30 秒＋時間銀行，（未證實））。

### 公平機制（同種子、同牌序、配對、防作弊）
- 實體：專業荷官、自動洗牌機、監視器、禁止通訊；隨機抽座位與平衡桌。
- 線上：RNG、防共謀（同 IP、行為分析）、防機器人；技巧競賽版可用「複式德撲」（多桌同牌序）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 起手牌與位置選擇 | 基礎勝率 |
| 底池賠率／勝率計算 | 跟注是否 +EV |
| 下注尺度與詐唬 | 讓對手犯錯 |
| 讀人（Tell、下注模式） | 推測範圍 |
| 錦標賽 ICM、籌碼深度管理 | 泡沫期、決賽桌策略 |

## 隨機 / 運氣來源

- 發牌；短期 All-in 勝負（Bad beat）。

## 參賽與變現

- **合法化路徑（台灣）**：以協會會員制、錦標賽形式舉辦；**不設現金局**（現金局普遍被視為違法）；獎金依多場累計後的名次發放而非單手兌現籌碼。新北地院、高等法院曾判協會負責人無罪（理由：結果主要取決於技巧、判斷，發牌不決定勝負）；2024 年台北地院亦有無罪判決。
- 仍有風險：2025-08 台北大巨蛋旁某「撲克協會」被搜索，查扣抽頭金逾 300 萬、帶回 67 人，警方認定假借比賽之名經營賭場（抽頭＝營利供賭場所風險）。檢方立場：撲克像麻將，是否賭博視個案。
- 社群：台大、清大、政大有德撲社；國內賽常破千人、最大近 3,000 人（2024 報導）。
- 線上：只能遊戲幣，不得兌現（同 tw-social-casino-slots 規範）。

## 主題與美術風格

- 國際賽：黑金、霓虹、拉斯維加斯式；台灣賽事強調「智力運動」「競技」形象，避開賭場語彙（籌碼稱點數、獎金稱獎勵）。

## 可借用的設計點

- **錦標賽名次給獎**而非每手輸贏兌現 — 台灣技巧型比賽最可行的獎金架構。
- **保證獎池 GTD + 衛星賽**：小額晉級大賽，擴大漏斗。
- **巡迴賽季＋排行榜**（年度積分）：留存與觀賽內容。
- **複式（Duplicate）**：同牌序比較，降低運氣，強化「技巧」法律論述。

## 法規 / 風險備註

- 刑法第266條（2022 起含網路賭博，罰金上限 5 萬）、第268條（意圖營利供給賭博場所／聚眾賭博）。關鍵要素：是否「以偶然事實決定財物得失」、是否抽頭營利、籌碼是否可兌現。
- 線上德撲（真錢）在台灣違法；APT/WPT 皆為實體賽。
- 最高法院 114 台上 273 號涉及比賽制爭點（細節未讀全文，（未證實））。
