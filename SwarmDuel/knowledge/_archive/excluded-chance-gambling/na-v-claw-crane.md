# Claw / Crane（夾娃娃機）

- **代號**：na-v-claw-crane
- **市場**：北美（超市/餐廳入口、FEC、電影院、娛樂中心；近年專門夾娃娃店與「Claw Arcade」快速增加）
- **形態**：選物販賣機 / 禮品機
- **代表產品 / 廠商**：Elaut（比利時）、Smart Industries、Coast to Coast（Toy Soldier）、Sega UFO Catcher、Andamiro 等（各品牌市佔未證實）
- **熱度依據**：北美最普遍的禮品機；FEC 營收中「票券兌換 + 夾娃娃」為主力（具體比例未證實）；TikTok/直播夾娃娃熱潮推動專門店（未證實）
- **技巧 vs 運氣**：技巧影響「抓位」，但營運商可設定爪力與派彩率，使單次結果大幅依賴機台狀態

## 一句話玩法

限時內用搖桿把爪子移到獎品上方，按鈕下爪，把獎品夾起送入出獎口。

## 規則書

### 勝負條件
- 獎品掉入出獎口 = 獲勝；可得該獎品。
- 限時到期會自動下爪。

### 單局流程
1. 投幣/刷卡（常見 $0.50～$2/次；價格由營運商設定，未證實）。
2. 倒數計時（常見 15～30 秒，未證實）。
3. 搖桿前後左右移動爪子（部分機型僅兩段：先 X 後 Y，各按一次停止）。
4. 按「下爪」鍵（或時間到）→ 爪子下降 → 合爪 → 上升 → 回到出獎口上方 → 開爪。
5. 獎品在途中掉落 = 失敗。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 結果 | 二元：得獎 / 未得獎 |
| 營運商設定 | 派彩率（例如每 25 次或 50 次給一次「強爪」）、抓取力與保持力分開調、爪張開幅度、移動速度 |
| Play Till Win 模式 | 每次付費都會給到獲勝機會，直到贏為止（部分機台/法域要求） |
| 獎品價值 | 多數州規定非現金、價值有上限（各州不同） |

### 操作
- 四向搖桿 + 下爪鈕；部分有「轉向/旋轉爪」或兩段式按鈕。
- 機台內攝影鏡頭（直播/遠端夾娃娃）為新興形式。

### 公平機制（同種子、同牌序、配對、防作弊）
- **爪力控制**：營運商可依機台累積收入決定爪力（「強爪」只在設定次數後出現），美國、南韓、新加坡等地均有報導。
- **法律定性**：
  - 安大略上訴法院：單次付費的技巧夾娃娃機本質為機會遊戲（僅限展覽/嘉年華）。
  - 亞伯達：除非可在一次付費內重複嘗試直到贏，否則違法。
  - 美國多數州：明文豁免於賭博法，但要求低價值、非現金獎品；阿拉巴馬要求玩家須實際控制爪子；馬里蘭要求獎品不可輕易換現；喬治亞、馬里蘭需向州彩券單位登記；紐澤西需認證，2016 年曾提法案要求公布中獎率並禁止「不可能贏」的機台。
  - 德州「fuzzy animal」條款：獎品批發價 ≤ 單局費 10 倍或 $5（取低者）（刑法 §47.01，本次未取得原文，未證實）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 選獎（重心、擺位、靠近出口） | 最大影響因素 |
| 對位（側面觀察深度） | 爪子置中於重心 |
| 抓結構（標籤、縫線、利用爪尖勾） | 提高被夾起或推落機率 |
| 觀察機台（剛有人贏過/投很多次） | 推測派彩週期（未證實有效） |
| 推落/拖移技巧 | 利用多次嘗試把獎品推近出口 |

## 隨機 / 運氣來源

- 營運商的派彩率與爪力設定、獎品堆疊物理、爪子擺動。

## 參賽與變現

- 單次付費；店家以獎品成本率（常見 25%～35%，未證實）控制毛利。
- 新興：會員卡/點數加值、累積保底（夾不到累積點數換獎，台式「保夾」概念，北美少見，未證實）。

## 主題與美術風格

- 填充玩偶（授權 IP：寶可夢、Sanrio、Squishmallows、迪士尼 — 授權角色是最強吸客力）、零食、3C 產品、現金/禮物卡（部分州禁止）。
- 機殼：霓虹燈、彩虹 LED、透明大視窗；日系 UFO Catcher 風、可愛風。

## 可借用的設計點

- 直覺操作（一搖桿一按鈕）+ 獎品實體展示 = 極低學習門檻。
- 「保夾/保底」與 Play Till Win 機制，可同時滿足法規與玩家公平感。
- 可視化物理（娃娃搖晃、險些落下）提供強烈的「差一點」體驗。
- 授權 IP 獎品驅動重複遊玩；可結合集點、直播、遠端夾取。

## 法規 / 風險備註

- 1951 Johnson Act 時代曾大規模查扣「Miami Digger」；現多州以獎品價值上限 + 非現金豁免。
- 爪力隱藏控制在消費者保護訴訟中屬高風險（比照 Key Master 案）。
