# Georgia COAM Class B（喬治亞州投幣娛樂機 B 類）

- **代號**：na-v-georgia-coam
- **市場**：北美（喬治亞州）
- **形態**：店面技巧機台（州彩券局監管的合法灰色機台）
- **代表產品 / 廠商**：供應商 Lucky Coin、GA Skill Games、Bulldog Gaming、Pimero Games、Betson、Zydexo、Bravery Gaming（2025 引入 Konami 遊戲包）；大型營運商 Lucky Bucks、Accel Entertainment（收購 Tom's Amusement）
- **熱度依據**：2025 年 Q1 末約 40,875 台、7,000+ 據點（2025-12 州眾議院聽證，AI 會議摘要，未完全證實）；COAM 2025 年對教育（HOPE / Pre-K）貢獻約 1.92 億美元；2020 年資料：玩家年投入 30 億+、付出獎品 21 億、淨收 9 億+
- **技巧 vs 運氣**：法規要求「含技巧元素」，但實務上是類老虎機的捲軸/牌面遊戲加上一步玩家操作；技巧權重小

## 一句話玩法

類老虎機轉盤後，玩家須做一次「技巧操作」完成組合；贏分只能換禮卡、彩券或再玩。

## 規則書

### 勝負條件
- 每局轉出盤面後，玩家需執行規定的技巧動作（常見形式：Nudge 推動某一軸上/下一格、選擇格位、配對/拼圖等；具體依各款核准遊戲，未證實逐款）以形成得獎組合。
- 達成組合 → 獲得點數；點數只能兌換**非現金**獎勵。

### 單局流程
1. 投幣/紙鈔入點（機台必須連線州中央會計系統）。
2. 選擇押注（per play）。
3. 盤面轉動並停止。
4. **技巧階段**：例如 Nudge 型——玩家判斷哪一軸往哪方向推一格可完成獎線；若不操作或操作錯誤則失去該組合（各款規則依核准文件，未證實）。
5. 結算點數，累積於機台。
6. 兌換：向店家領取 **禮物卡（gift card）／彩券／再玩點數（replay）**。

### 計分規則
| 項目 | 分數 / 條件 |
|---|---|
| 現金兌獎 | **全面禁止** |
| 每次贏分兌換上限 | 約 $5（CDC Gaming 2026 報導「每次贏獎上限 $5」；舊規為每局 $5 商品；2025-26 SB 254 對 gift card 機台另有每局批發價 $2 的上限條文，適用 A/B 類待確認，未證實） |
| 兌換形式 | 2024 HB 353 起可發全州通用 gift card；2026-07-01 起據點只能提供 gift card、彩券或 replay |
| 州政府分成 | 淨收入 13%（2024 起，原 10%）歸彩券局 → 教育 |
| 業者分成 | master licensee 約 42.5%、場地主約 42.5%（CDC Gaming 2026） |

### 操作
- 觸控螢幕 + 實體按鈕（Play / 押注 / Nudge 或選擇鍵）。
- 每據點台數有上限（零售店通常 ≤ 6～9 台，未證實最新數字）。

### 公平機制（同種子、同牌序、配對、防作弊）
- 全部 Class B 機台需連線彩券局中央會計系統（CAS），封閉式安全箱、手工點鈔。
- 彩券局發函：「魚機」若要以 Class B 營運，也必須符合同樣規範並含「some skill」。
- 結果仍由 RNG 決定；技巧步驟只影響是否實現已出現的組合（法規立場為「娛樂機」而非賭博）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 讀盤（看出 nudge/選擇後可完成哪條線） | 決定是否兌現本局獎項 |
| 反應/操作正確 | 部分遊戲限時操作 |
| 押注管理 | 每次贏獎有上限，高押注邊際效益低 |

## 隨機 / 運氣來源

- RNG 決定轉輪停點與可完成的組合；技巧僅是「把潛在獎項撿起來」。
- 兌換上限壓抑大獎，使體驗偏向高頻小獎。

## 參賽與變現

- 單人機台；無錦標賽。
- 變現 = 玩家淨輸額；由彩券局 13%、master licensee、場地三方分。
- 主要營運商透過 master license（約 195 張 Class B master license，2024）經營路線；彩券局曾拍賣 master license。

## 主題與美術風格

- 典型老虎機題材：經典水果/7、BAR、Wild West、埃及、亞洲財神/龍、海洋魚機；Konami 等 Class III 大廠內容開始進場（2025）。
- 店頭機台以直立機殼、彩色 LED 為主，與便利店環境（Taqueria、加油站）融合。

## 可借用的設計點

- 「RNG 開盤 + 玩家必須完成一步判斷」是灰區法規下最常見的最小技巧單位（Nudge / 選格）。
- 非現金兌換、單次獎上限、中央會計系統：可做為新市場合規設計範本。
- 把技巧步驟設計得有趣（多條線取捨、限時推軸），可提升「娛樂性」論據。

## 法規 / 風險備註

- 1991 年合法化 Class B；2013 年起由喬治亞彩券局（GLC）監管。
- 2024 HB 353：稅率 10%→13%，開放 gift card。
- 議員 Cowsert 等持續主張提高稅率（曾提 30%）、認為 gift card 等同現金；業界主張 COAM 已是州內稅率最高行業。
- 彩券局法定應回饋 35%，議員稱實際從未超過 27%。
