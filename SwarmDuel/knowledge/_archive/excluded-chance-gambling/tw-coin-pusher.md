# 推幣機（Coin / Medal Pusher）

- **代號**：tw-coin-pusher
- **市場**：台灣
- **形態**：店面技巧機台（普通級電子遊戲場「益智類」／親子遊樂場，代幣＋彩票兌換）＋手機遠端推幣 App
- **代表產品 / 廠商**：日系大型推幣機（KONAMI、SEGA、BANDAI NAMCO 等）、台灣與大陸製中小型推幣機；通路：湯姆熊歡樂世界（全台 50 多家）、大魯閣「遊戲愛樂園」（10 據點）、百貨／夜市遊藝場
- **熱度依據**：親子遊藝場長青品類；大魯閣運動休閒事業部 2025 前三季占營收約 59%（含遊樂場）；店面數據具體到推幣機的營收（未證實）
- **技巧 vs 運氣**：運氣主導、少量時機技巧（投幣時機與落點）

## 一句話玩法

把代幣投入軌道，落在來回推動的平台上，推落前緣即贏幣，觸發轉盤或 Jackpot 拿大獎。

## 規則書

### 勝負條件
- 無終局；代幣（Medal）或彩票數量即成果。代幣用完即止。

### 單局流程
1. 以現金換代幣（代幣大小、圖樣、重量不得與真鈔幣相同）。
2. 從投幣口投入，代幣沿滑道或擺動軌道落到**推台**上。
3. 推台前後往復，把代幣往前擠；從**前緣**掉落 → 回到玩家出幣口（贏）；從**兩側**掉落 → 歸機台（輸）。
4. 代幣通過特定「入洞／感應口」→ 觸發螢幕抽選（拉霸、轉盤、Bingo）→ 依結果釋放額外代幣、球或觸發 Jackpot。
5. 日系大型機：推落特製球進入 Chance 格 → 旋轉抽選 → 進入主題劇情（例：KONAMI 實況野球推幣，從 7 局下開打、取勝得獎、賽後 Bingo 抽選頂級對決）。
6. 遊玩結束：剩餘代幣可存幣（會員卡）；彩票機則吐彩票換禮品。

### 計分規則
| 項目 | 常見設定（（未證實），依機種） |
|---|---|
| 推落前緣 | 1:1 取回代幣 |
| 入洞抽選 | 小獎數枚～數十枚；大獎觸發 Jackpot 球 |
| Jackpot | 累積池，觸發後一次噴出數百～上千枚 |
| 彩票型 | 推落後依數量出彩票；累積換禮品 |
| 禮品價值上限 | 《電子遊戲場業管理條例》第14條：普通級每次兌換獎品價值 ≤ NT$1,000，限制級 ≤ NT$2,000；不得以現金、有價證券為獎、不得買回 |

### 操作
- 投幣口位置可左右移動或擇時投入；部分機台有發射鈕控制力道。

### 公平機制（同種子、同牌序、配對、防作弊）
- 物理推落為主＋電子抽選；須經經濟部評鑑分類，不得改機（加彈力裝置提高出貨＝改機違法）。
- 普通級場所：未滿 15 歲上課時間與 22:00 後不得進入；不得使用真鈔、信用卡、儲值卡直接投機（只能代幣）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 投幣時機（推台後退時投、讓幣落在前方） | 提高推落效率 |
| 選台（前緣堆積多、即將崩落的台） | 期望值較高（「撿台」概念） |
| 觀察入洞節奏 | 觸發抽選 |

## 隨機 / 運氣來源

- 代幣物理碰撞、電子抽選結果、Jackpot 觸發。

## 參賽與變現

- 現金換代幣（常見套票優惠）；存幣會員制；彩票換禮品。手機遠端推幣 App（例：趣推幣、開心推金幣）以內購金幣、實物或點數獎勵，（未證實）合規差異大。

## 主題與美術風格

- 日系 IP（寶可夢、實況野球、海賊）、海盜寶藏、金字塔、馬戲團；大型機台燈光秀、透明壓克力展示「快掉下來」的幣堆。

## 可借用的設計點

- **「快掉下來」的可視化懸念**：物理堆疊製造 near-miss 張力。
- **撿台**：前人投入留在檯面，形成接手誘因與圍觀。
- **物理＋電子抽選雙層**：可做成物理模擬手遊（技巧＝落點控制）。
- **存幣制度**：會員留存。

## 法規 / 風險備註

- 必須在合法電子遊戲場（有營業級別證）營運；若放在選物販賣機店並加入射倖兌換，常被判非法經營電子遊戲場＋賭博。
- 2025-10 起新評鑑機須正體中文介面；簡體益智類機具 2028-09-30 後不得營業。
