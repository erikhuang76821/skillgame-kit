## 1. 一頁結論

| # | 結論 |
|---|---|
| 1 | 台灣營收榜頂端是社交博弈，**2024 營收前十沒有任何技巧 PvP**；純技巧遊戲的熱度靠「觸及＋社群＋賽事」而非營收。 |
| 2 | 手機技巧 PvP 觸及最大的是 **傳說對決**（App Store 約 77 萬評分、台灣第一電競）、**荒野亂鬥**（25 萬）、**極速領域**、**皇室戰爭**、**蛋仔派對**（保護級、家庭類 #3）。 |
| 3 | 實體技巧最有組織的是 **電子飛鏢**（全國錦標賽用 DARTSLIVE 機台、國際賽事常駐台灣）與 **撞球**（球場數萎縮，但台灣選手 2025–2026 世界賽成績亮眼）。 |
| 4 | **音遊機台**（太鼓、maimai DX、CHUNITHM）計分完全確定、有段位與全國排行，台灣是 maimai／CHUNITHM 的官方海外市場。 |
| 5 | 棋類（象棋、五子棋連珠、圍棋）有正式賽事與協會；台灣曾在 2017 台北連珠世錦賽奪金，但 App 端都是長尾小廠。 |
| 6 | 資策會 2024 調查：81.4% 網友玩數位遊戲、手遊 83.9%；付費動機首次出現「**想贏得比賽**」→ 競技需求正在上升。 |
| 7 | 避開虛擬幣輸贏即可維持普遍級／保護級；博弈類正被監察院點名，對純技巧遊戲是順風。 |

## 4. 法規快查

| 項目 | 要點 |
|---|---|
| 賭博罪 | 刑法 §266/§268：「偶然決定財物得喪」；純技巧且不可兌現即避開 |
| 分級 | 技巧 PvP 多為輔12（傳說對決、荒野亂鬥）、蛋仔派對為保護級；有虛擬幣輸贏的棋弈／牌類 → 輔15（研議 18+） |
| 機率揭露 | 若有付費抽卡、轉蛋，須公布機率（2023 起） |
| 實體機台 | 電子遊戲場業管理條例：須評鑑分類（益智／鋼珠／娛樂）；普通級獎品每次 ≤1,000 元；機台須正體中文 |
| 夜市攤位 | 消保法（標價、獎品標示）；撈金魚涉動保法；玩具槍涉槍砲條例 |
| 技巧賽發獎金 | 無專法；以「固定報名費、依名次給獎、不抽頭」為原則，先請法務確認 |

## 5. 給新作的設計清單（台灣）

1. **技巧主導要可證明**：同種子／複式賽制，排名分數完全確定（音遊模式）。
2. **可解釋的實力分級**：借飛鏢 Rating 或音遊段位，讓玩家知道自己為何升降。
3. **運氣放在獨立模式**：排位只留純技巧，派對／道具模式另開（跑跑道具賽、蛋仔模式）。
4. **先手優勢用規則補償**，不靠隨機（連珠禁手、圍棋貼目）。
5. **單局 2–5 分鐘**，排位標準化等級，降低付費落差。
6. **不做虛擬幣輸贏**：保住普遍級／保護級與年輕族群。
7. **社群與在地賽事**：LINE 登入與分享、好友房、校園／在地電競、鄰台同步對戰。
8. **在地化**：正體中文、台語配音加分、台味／廟會題材＋日系 IP 聯名；與娛樂城語言區隔。
9. **空缺機會**：左右切換打怪、去隨機化的 PvP 塔防、同種子貪食蛇在兩市場都沒有當紅作品。
