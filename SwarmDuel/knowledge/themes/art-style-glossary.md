# 美術風格詞庫（Art Style Glossary）

> 用途：美術方向討論＋圖像生成 prompt 關鍵詞。Prompt 關鍵詞以英文為主（生成模型對英文較穩定），可直接複製。
> 市場適配：◎ 很適合／○ 可用／△ 需調整／✕ 不建議。
> 「Skill 定位風險」= 是否容易被看成賭博（影響北美 skill 法律定位與台灣分級）。

| 目標 | 推薦風格 | 理由 |

## 3. Prompt 共用尾綴（建議）

| 用途 | 尾綴 |
|---|---|
| 手遊 UI 資產 | `game UI asset, isolated on transparent background, centered, high readability at small size` |
| 角色立繪 | `full body character design, front view, clean silhouette, consistent style sheet` |
| 避免賭場感（負面提示）| `no slot machine, no casino chips, no playing-card suits, no dice, no jackpot text` |
| 避免文字亂碼 | `no text`（文字於引擎內排版，繁中字型另行套用）|
