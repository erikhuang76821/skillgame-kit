# 00 Overview — Swarm Duel: Cryptid Camp

- **目的**：一頁式定位、設計支柱、A+B 來源
- **相關系統**：全部
- **狀態**：Draft

## 設計意圖（Why）

Survivor-like（自動攻擊、走位求生、局內升級）上手快、單局短，但它的勝負有大量隨機（敵人生成、升級選項、掉落）。北美 skill game 需要「**技巧為主導因素**」才站得住，所以本作把所有隨機**種子化並對雙方公開一致**：同一場對戰的兩名玩家面對完全相同的敵潮、相同的升級選項、相同的掉落。剩下唯一的差異是玩家的操作與決策。

## High Concept

> 3 分鐘、同一個種子、兩位玩家各自守營地。誰在外星人潮中活得更久、打得更漂亮，誰就贏。

## 設計支柱（Pillars）

| # | 支柱 | 判準（設計決策用來檢查） |
|---|---|---|
| P1 | **技巧主導（skill game 精髓）** | 分數只來自玩家行為；同種子、同視野、規則透明、可重播驗證——七條檢查表見 [03](03_skill_integrity.md) |
| P2 | **技巧天花板高、入門低** | 單手可玩（移動自動攻擊）；高手差異來自走位、衝刺 i-frame、主動技時機、升級路線 |
| P3 | **3 分鐘可結算** | 單局固定 180 秒；結算畫面 10 秒內可重開 |
| P4 | **輕量** | 包體 ≤ 8MB；像素原生解析度素材；音效程式合成 |
| P5 | **可驗證** | 確定性模擬；伺服器以輸入紀錄重播驗分 |
| P6 | **手機直版唯一（硬需求）** | 只設計 9:16～9:20 直版；不做橫版。電腦上也是同一個直版欄位；手機橫拿時暫停並提示轉直 |

## A+B 機制對映

| 來源 | 機制 | 在新作的角色 |
|---|---|---|
| Vampire Survivors 類 | 自動攻擊、經驗球、局內三選一升級 | 核心戰鬥（02） |
| PokéSurvivor（skill 來源） | 八方向像素角色、腳底錨點、Y 排序 | 美術與渲染契約（docs/asset_pipeline） |
| 非同步技巧對戰平台 | 同題目非同步 1v1、錦標賽、分級配對 | 對戰外殼（01、06） |
| 每日挑戰（Daily Seed） | 全服同種子排行榜 | 留存（09 未展開，見 01） |

## 單局玩家流程

1. 選角（排位賽為標準化配置，見 02）→ 配對 → 取得 `matchSeed`
2. 0–180 秒：移動、衝刺閃避、收集 Ecto 球升級、時機施放 Howl
3. 第 60 / 120 秒小頭目；第 170 秒「母艦光束」收尾壓力
4. 死亡或時間到 → 分數結算 → 上傳輸入紀錄 → 伺服器重播驗分
5. 對手完成（非同步）→ 比分 → 獎勵

## 市場定位（北美）

- 平台：Mobile Web / PWA 首發（**直版鎖定**）；可包 Capacitor 上 App Store / Google Play；可接入第三方技巧競賽 SDK
- 操作：單手拇指（拖曳任意處移動、輕點 Dash、大按鈕 Howl）；電腦以 WASD/滑鼠操作同一直版畫面
- 年齡：一般模式 13+（ESRB E10+ 目標）；現金參賽模式依平台規範 18+ 並地理圍欄
- 題材：美國都市傳說（Bigfoot / Mothman / Jackalope）vs. 灰色外星人，露營地場景，週末早晨卡通調性
