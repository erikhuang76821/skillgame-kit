# 05 玩法規格（草案；最新條目見 v7 區塊）

> 範本：[game-spec-template.md](../../.claude/skills/lite-skillgame-stack/references/game-spec-template.md)。改編來源：[af-horde-defense](../../knowledge-base/ad-funnel/af-horde-defense.md)、[af-survivor-skill-pick](../../knowledge-base/ad-funnel/af-survivor-skill-pick.md)（§13 逐條回應）。設計意圖見 [01](01_concept.md)；單位與剋制數值見 [04](04_combat.md)。
> **v2（2026-11-17）**：拿掉指揮官；操作全部是點擊與拖曳；小兵可重拖但有代價；主城升級選英雄。數值是起始值，N4/N5 用 bot 調。改數值先改這裡，sim 用同名常數。

> **v7（2026-11-18）以 `game/src/sim/sim.js` v7 與 `stages.js` 為準，下列條目優先於本檔舊段落**（舊段落待全面改寫）：
> - **關卡**：5 個主題關（5／8／10／12／15 分），每關是資料 `{分鐘、地圖主題、開放出怪口、首領時間表}`。`stages.js` 的 `buildScript()` 依此產生底流與事件腳本，詳見 [07 §1](07_difficulty_curve.md)。最後一隻王出現後有 90 秒可以擊倒，打倒即過關；每關是獨立的 GameDef，id 為 `lantern-hold-<關卡>`。
> - **經濟**：只剩金幣。
>   - 價格：軍營 20 ＋ 15×已有座數；升級 Lv2 30、Lv3 50（分別解鎖盾兵、牧師）。弓箭手 8／盾兵 12／牧師 12，訓練 2／4／5 秒。
>   - 工人在主城買，金 10、訓練 3 秒，最多 4 名。工人自動修城牆與軍營（3 耐久／秒），被打時先反擊。花錢修牆已拿掉。
>   - 城牆三級：木柵 5、石牆 12、鐵牆 20。
>   - 人口上限 = 4 ＋ 守望等級 ＋ 4×軍營數（最多 32）。
> - **城牆與路線**：牆留缺口就是路線。怪物對城牆的偏好分三種：
>   - 必拆：甲蟲、爆裂菇、攻城蝸牛、影弓手、所有王。
>   - 必繞（沿環走到最近的缺口）：狼。
>   - 一半一半：影鼠，由種子決定，每隻固定。
>   - 牆全封死時一律拆牆。地面怪優先打附近 70 內的軍營。
> - **兵種行為**（數值在 `UNIT`，見 [04 §3.2](04_combat.md)）：
>   - 弓箭手：原地不追擊，射程 140；被近戰打會被推開，最多離守點 48；1 秒沒目標就走回守點。
>   - 盾兵：迎敵半徑 90、追擊上限 70；血量低於 35% 撤回守點，回到 70% 才再迎敵。
>   - 牧師：友軍低於 80% 時發出恢復訊號，牧師走到 60 內（最多離守點 100），詠唱 0.67 秒後治療；目標離開或死亡會中斷詠唱。
> - **輸入**：指令是連續 3 個 byte `[op, a, b]`。
>   - op 1 建軍營、2 選單（a=255 主城：0 工人；軍營：0／1／2 出兵、3 升級）、3 移動單位（工人不能拖）、5 城牆蓋／升級。
>   - 選卡用 core 的 `choice`：0–2 選卡、3 重抽、4–6 忽略該卡兵種、7–9 鎖定該卡兵種。`maxChoices = 30 + 2 + 1 + 1`。
> - **隨機來源**：stream `trickle`、`event`、`offer`（加權洗牌：每張 2 票，鎖定兵種 3 票）、`foe`（每隻影鼠繞或拆）。`chest` stream 保留不用：**寶箱不擲骰**。
> - **寶箱**：張數只看來源。限時清完標記事件 2 張、擊殺 100／250 各 1 張、首領 1 ＋ 王級加成（弱 1、小 2、大 3、超 3）、羈絆「豐收」+1。升級順序固定：已擁有、等級最低、最早拿到的卡先升。
> - **成長曲線**：事件與護衛規模 = 100% ＋ 0.6%／秒（2:00 後）＋ 再 0.6%／秒（4:00 後）；一般怪耐久 +0.67%／秒（3:00 後）；後段底流更密。
> - **計分**：主城耐久分只在結算時計入。`GAME.version` = 7。
> - 尚未做：英雄卡、聖騎／熔岩牆進化、商隊、霧潮；8–15 分關卡只產生了腳本，還沒調平衡。

## §2 輸入編碼（每 tick 16 bit）

| bit | 內容 |
|---|---|
| 0–3 | 指令類型（下表） |
| 4–15 | 參數（12 bit） |

| 指令 | 值 | 參數 | 觸控 |
|---|---|---|---|
| 無 | 0 | — | |
| 建造 | 1 | `slot<<4 \| kind` | 點空地 → 選建築 |
| 建築選單 | 2 | `slot<<2 \| option`（主城：買工人／升級；軍營：弓／盾／牧／升級；牧場、礦場：升級） | 點建築 → 點按鈕 |
| 選取單位 | 3 | 單位 id | 手指按住單位（拖曳開始） |
| 放到格子 | 4 | 格子 0–239（64 px 網格 12 × 20） | 拖曳放開在地上 |
| 放進建築 | 5 | slot | 拖曳放開在牧場／礦場上（只限工人） |
| 選英雄 | 6 | 0 法師、1 戰士、2 召喚師、3 刺客 | 主城升級後彈出四張卡 |
| 英雄方位 | 7 | `hero<<4 \| sector`（8 = 繞城） | 拖英雄到羅盤 |
| 城牆 | 8 | `wall<<2 \| op`（蓋／升級／修理） | 點牆段 → 點按鈕 |

- 一次拖曳 = 連續兩個 tick 的「選取＋放下」；render 層佇列保證順序，每 tick 一個指令，慢幀不吞輸入。
- 無效指令（資源不足、冷卻中、超出放置範圍、條件不符）sim 直接忽略，不改狀態。

## §3 隨機來源

| stream | id | 用途 | index | 範圍 |
|---|---|---|---|---|
| `trickle` | 1 | 第 i 批底流的出怪口與數量 | 批次序號 i | 口 0–7、數量 1–3 |
| `event` | 2 | 第 e 個事件的方向 | 事件序號 e | 口 0–7（夾擊取相對兩口） |

- 時間表固定，種子只換方向與數量。
- 英雄是固定四選一，不用種子；無暴擊、無機率掉落；目標選擇是固定規則。

## §4 Tick 順序

```
1. 清空 events
2. 套用輸入指令（§2）
3. 經濟：牧場、礦場產出；主城生工人；軍營訓練（新兵站在軍營門口，狀態 = 守備）
4. 生成：底流批次、事件（預警提前 PREWARN_TICKS）
5. 移動：敵人（流場／飛行直線）→ 小兵與工人（守備規則／移動中）→ 英雄 → 燈靈
6. 攻擊、治療（04 §1 公式），依 id 排序；累積經驗 → 升級
7. 死亡：敵人掉金幣（直接入帳）；建築／牆歸 0 變瓦礫並重算流場；單位陣亡 pop−1
8. 事件完成判定、計分、tick++
```

## §9 Bot（技巧分級）

| 等級 | 可見資訊 | 策略 | 誤差 |
|---|---|---|---|
| novice | 同畫面 | 有錢就買弓箭手，兵留在軍營門口不調；工人全進牧場；不升牆 | 指令延遲大 |
| intermediate | 同畫面 + 預警 | 固定開局（工人 → 軍營 → 牧場 → 礦場 → 主城 Lv2）；預警時把最近的兵調過去；英雄固定選戰士 | 中 |
| expert | 同畫面 + 預警 | 依敵種剋制配兵（輕→弓、重→戰士／刺客＋盾擋）；盾前弓後牧中；老兵優先調往事件方向；工人在事件前拉出、喘息時放回；牆依蝸牛方向升級 | 小 |

誤差用 `hash32(seed, salt, 事件序號)`。`tools/strategies.mjs` 的簡單策略：只買弓箭手、全工人生產、兵全放主城門口、只守一側、從不調防（`RULE-SKILL-BEATS-SIMPLE`）。
