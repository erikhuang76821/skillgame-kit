# 01 企劃總覽 — 守望之戰 LanternHold

> 改編來源：[af-horde-defense](../../knowledge-base/ad-funnel/af-horde-defense.md)（英雄守城割草）＋ [af-survivor-skill-pick](../../knowledge-base/ad-funnel/af-survivor-skill-pick.md)（倖存者割草＋三選一）。參考截圖（4X 主城）只借「中央主城＋環狀城區」的版面，名稱、題材、美術全部原創（不做雪地、暖爐、寒冷末日）。

## 1. 一句話

夜林中央有一座主城，怪從 360° 不斷跑來。打怪得金幣，用來蓋軍營、買兵、蓋城牆；打怪也累積守望值，升級時從三張卡選一張。卡片湊出流派：火燒連環爆、冰封、雷電連鎖、箭雨……特定兩張湊滿會進化。小兵拖到想守的位置。撐過 4 分 30 秒，擊倒最後的「永夜之喉」。

**數據原則：少而清楚。** 只有一種資源；每張卡最多 3 級；傷害是整數，一張 3×3 剋制表決定強弱。

## 2. 遊戲循環

```
怪跑過來 ─▶ 小兵、主城、卡片效果打怪 ─▶ 金幣 ＋ 守望值 ＋ 小兵經驗
   ▲                                          │
   │          ┌───────── 金幣 ─────────┐     守望值滿 → 三選一（世界暫停）
   │          │ 軍營 · 弓箭手 · 盾兵 · 牧師 · 城牆 │     │
   │          └────────────────────────┘     ▼
   │                    │               卡片：湊羈絆 → 反應 → 進化
   │                    ▼                     │
   └────── 拖曳布陣（配合流派） ◀────────────────┘
            限時清事件 → 寶箱（1 / 3 / 5 張）
```

兩條線互相要求：**金幣決定你有多少兵、站在哪；卡片決定這些兵會變成什麼**。例如「火牆」要有牆才有用，「霜盾」要有盾兵，「箭雨」要弓箭手把怪留在燈光外圍。

### 2.1 開場：主城＋一名小弓箭手

| 時間 | 畫面上發生的事 | 玩家學到 |
|---|---|---|
| 0:00 | 只有主城和一名小弓箭手；單一出怪口零星影鼠 | 弓箭手會自動射進圈的怪 |
| 約 0:10 | **第一次三選一** | 卡片會改變戰鬥方式 |
| 0:15 | 金幣夠 → 點空地蓋軍營 → 買弓箭手 → 拖曳放下 | 生兵、布陣 |
| 0:25 | 第一次事件（小股突襲） | 預警、補防 |
| 0:50 | 飛蛾群：飛過城牆撲軍營 | 牆擋不住所有東西 |
| 1:40 | 甲蟲隊（寶箱事件）：30 秒內清完 → 寶箱；越快清分越多 | 事件＝驚喜的機會 |
| 1:05–1:45 | 第一次進化 | 「原來可以變這樣」 |

提示只是 UI，不進 sim。

### 2.2 節奏：連續、不分回合

時間一直走，只有三選一時暫停（暫停不算時間）。節奏三層：

| 層 | 內容 | 頻率 |
|---|---|---|
| ① 零星小怪（底流） | 8 個出怪口輪流出 1–3 隻 | 每 1.5–3 秒一批，30 秒加一級 |
| ② 事件（波峰） | 突襲、飛蛾群、鼠潮、甲蟲隊、爆裂菇、攻城蝸牛、精英夾擊、月蝕、Boss（依負荷由小到大）；**提前 6 秒預警方向**；4 個有寶箱 | 每 20–30 秒 |
| ③ 喘息 | 事件清完後底流減半 8 秒 | 每個事件後 |

成長的節奏疊在上面：約每 25 秒一次三選一、4 次寶箱機會、1–2 次進化（1:05 起）。

## 3. 資源

| 資源 | 怎麼來 | 拿來做 |
|---|---|---|
| **金幣** | 打怪必掉（固定量；「賞金」卡加成；「牧場」卡定時產） | 軍營、弓箭手、盾兵、牧師、木柵、修牆 |
| **守望值** | 打怪（擊殺分） | 升級 → 三選一；人口上限 +1 |

顯示文字可以叫「金幣」，但**圖示不能畫成錢幣**（`RULE-ART-TW-TABOO`），改畫金塊或皮袋。

## 4. 單位與建築

| 想要 | 在哪買 | 金幣 |
|---|---|---|
| 軍營（人口上限 +4） | 點空地 | 20，之後每座 +15（20 / 35 / 50…） |
| 弓箭手（遠程，打輕甲） | 點軍營 | 8 |
| 盾兵（坦、嘲諷，打重甲） | 點軍營 | 12 |
| 牧師（治療） | 點軍營 | 12 |
| 木柵 | 點牆位 | 5（修理 3） |
| 牧場 | 只能從卡片拿到 | — |

人口上限 = 4 ＋ 守望等級 ＋ 每座軍營 4（最多 32）。金幣的去向因此一路有意義：前期買兵，人口滿了就蓋下一座軍營或補牆。

### 4.1 小兵

- 放置後依「警戒半徑、活動半徑、攻擊射程」自動行動（[04 §3.2](04_combat.md)），不能指定打哪隻怪。
- **可以重新拖曳（調防），但有代價**：

| 代價 | 規則 |
|---|---|
| 走過去 | 不瞬移；途中不攻擊，被打照樣扣血 |
| 調防冷卻 | 同一個兵 10 秒內只能調一次 |
| 放置範圍 | 主城燈光內（「燈塔」卡擴大），或友軍附近 |
| 抵達後 | 1 秒架設才開始攻擊 |

- **小兵打怪升級**（最高 3 級）：擊殺 5 / 15 次升 Lv2 / Lv3，血量與攻擊 ×1.4 / ×1.8、防禦 +1 / +2。牧師以治療量、盾兵以擋下的傷害累積經驗。

### 4.2 卡片（取代主城升級、建築升級、英雄四選一）

18 張卡、6 種標籤（弓、火、冰、雷、守、金）、6 個羈絆、3 個元素反應、4 個進化、寶箱。全部規則：[06](06_cards.md)。

### 4.3 城牆（有耐久）

- 24 段；金幣蓋木柵，「石牆」卡讓所有牆更硬（耐久 +50%/級、防禦 +1/級）。
- 外觀依耐久：完好 → 龜裂 → 殘破；歸 0 變瓦礫，可重蓋。
- 甲蟲啃牆、攻城蝸牛專打牆、爆裂菇自爆對牆加倍、飛蛾無視牆。

### 4.4 主城

- 耐久 1000、慢速光束（射程 = 燈光半徑）；「避雷塔」卡讓光束連鎖。
- 耐久歸 0 = 結束（保留分數）。

## 5. 敵人與事件

| 敵人 | 護甲類 | 行為 |
|---|---|---|
| 影鼠 | 輕 | 小、快、成群，底流主力 |
| 甲蟲 | 重 | 慢、厚，啃牆 |
| 飛蛾 | 輕 | 飛行、無視牆，撲軍營 |
| 爆裂菇 | 輕 | 自爆，對牆與建築加倍 |
| 攻城蝸牛 | 重 | 極慢、極厚，遠程打牆 |
| 披甲狼（精英） | 重 | 高耐久，掉大量金幣 |
| 永夜之喉（Boss） | 重 | 推進、範圍攻擊 |

事件時間軸見 [07](07_difficulty_curve.md)。

## 6. 計分（公開，結算逐項列出）

`分數 = 擊殺分 + 事件完成分 + Boss 分 + 主城剩餘耐久分（結算時） + 3 級老兵`

## 7. 與原作的差異（Skill Game 化）

| 原作做法 | 本作 |
|---|---|
| 局外養成、加速、抽英雄 | 無，全部局內從 0 |
| 隨機技能卡 | 三選一保留，但**同種子同選項**（第 k 次選卡由種子決定）；重抽、忽略兵種、鎖定兵種是有限的技巧資源 |
| 機率掉落、暴擊 | 無暴擊；寶箱在固定條件必掉，張數由種子決定、人人相同；開箱不用金光 |
| 玩家操控英雄走位割草 | 拿掉操控角色；技巧是選卡路線＋布陣＋調防時機 |
| 回合制建造期 | 連續即時、事件疊加；只有選卡時暫停 |
