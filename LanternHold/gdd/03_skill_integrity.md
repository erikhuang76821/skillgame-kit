# 03 技巧完整性

> 方法：[01_skill-integrity](../../knowledge-base/01_skill-integrity.md)（三問、精髓七條、去隨機化）。七條答案見 [05 §10](05_game_spec.md)。

## 1. 每個系統的三問

| 系統 | 運氣？ | 雙方相同？ | 可驗證？ |
|---|---|---|---|
| 底流與事件 | 時間表固定；方向與數量由種子 | 同種子相同 | 重播 |
| 英雄 | 固定四選一；重複選 = 升 2 階 | 相同 | 重播 |
| 小兵升級 | 只看累積經驗（擊殺／擋傷／治療） | 相同 | 重播 |
| 掉落 | 金幣依敵種必掉固定量 | 相同 | 重播 |
| 傷害 | 固定值，無暴擊、無閃避機率 | 相同 | 重播 |
| 敵人 AI | 流場 + 固定目標規則；無隨機偏移 | 相同 | 重播 |

## 2. 去隨機化對照

| 原作隨機 | 本作 |
|---|---|
| 隨機技能卡 | 移除 |
| 抽英雄 | 固定四選一，不用種子 |
| 合成機率升星 | 不存在；重複選必升階 |
| 機率掉落、寶箱 | 固定掉落 |
| 暴擊 | 移除 |

## 3. 技巧來源（高手比中手多拿分的地方）

1. **剋制配兵**：輕甲用弓箭手、重甲用盾兵與爆炸類卡片、蝸牛前先蓋牆。
2. **預判與調防**：看 6 秒預警，決定調哪個兵過去；調防有冷卻、移動中不攻擊，太早太晚都虧。
3. **布陣**：盾前弓後牧中；放置位置也決定誰吃得到擊殺、誰會升級。
4. **選卡路線**（v3）：同種子大家看到同樣三張，差別在讀懂卡片上的進化路線與羈絆提示、何時重抽、忽略或鎖定哪個兵種，以及金幣先補兵還是先蓋牆（[06 §7](06_cards.md)）。
5. **照顧老兵**：3 級小兵比新兵強近一倍，局末存活另有分。
6. **流派配合布陣**：火牆要牆、霜盾要盾兵、箭雨要怪留在燈光外圍；限時清寶箱事件要提前調防。

## 4. 風險：主導策略

經營類最怕「固定開局建造順序」壓過一切；卡片類最怕「某個進化永遠最強」。N5 要用 `tools/strategies.mjs` 的簡單策略（只買弓箭手選第一張、只升已有的卡、平均布陣追進化不調防）比對；若某個固定順序贏過 expert bot，調整事件方向的變化與費用曲線。
