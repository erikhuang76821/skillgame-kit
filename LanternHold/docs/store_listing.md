## 規範對照

| 規範 | 本作 | 依據 |
|---|---|---|
| 技巧型遊戲，不能靠運氣決定勝負（骰子、抽卡、轉盤、刮刮樂） | 勝負來自布陣、城牆路線、調防時機、選卡路線。<br>傷害固定，沒有暴擊、閃避。<br>寶箱**不擲骰**：張數只看來源，升級順序是固定規則。<br>三選一的選項由固定種子決定：同一關每次都一樣，玩家用重抽、忽略、鎖定來控制。<br>開箱不用金光。 | [06 §2.1、§6](../gdd/06_cards.md)、[03](../gdd/03_skill_integrity.md) |
| 不能有任何金錢或獎品 | 沒有內購、廣告、獎品；遊戲裡的「金」只是局內資源，圖示畫成金塊，不畫錢幣 | `RULE-ART-TW-TABOO` |
| 只能用 PixiJS（可搭配 GSAP）或純 HTML5；程式庫放進資料夾 | PixiJS 8.22.0 ＋ GSAP 3.15.0，打包進 `index.html`；沒有其他遊戲引擎 | [10](../gdd/10_tech_constraints.md) |
| 一定要能用手機觸控玩；直式或橫式擇一 | 直式。<br>觸控：點建築／牆、拖曳布陣、雙指縮放。<br>電腦：滑鼠點擊、拖曳、滾輪縮放。 | `src/main.js` |
| 單機，不連線；不做線上對戰、聊天、排行榜、雲端存檔 | 全部本機。結算畫面的「重播驗證」也在本機跑，不上傳 | — |
| 圖片、音效、字型都打包 | 像素圖以 data URI 內嵌在 `index.html`。音效用 Web Audio 即時合成，沒有音檔。字型用系統字型 | `scripts/singlefile.mjs` |
| 不連外部網站 | 單檔版本開啟後沒有任何網路請求（2026-11-18 實測）。檔案裡只剩函式庫版權字串裡的網址 | — |
| 不能有密碼或金鑰 | 沒有 | — |
| 10 MB 內，建議 5 MB | 約 265 KB | `npm run build:zip` 會擋超過 10 MB |
