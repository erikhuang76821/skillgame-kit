# TwinStrike 難度曲線（腳本化編排，sim v3）

> 試玩回饋：「請用人性考量試玩，利用腳本化編排設計難度曲線，不斷提升難度」。
> 實作：`game/src/sim/sim.js` 的 `PHRASES` + `SCRIPT`；人性化試玩：`game/tools/humanBots.mjs` + `game/tools/difficulty-curve.mjs`；最新報告：[docs/difficulty_curve.md](../docs/difficulty_curve.md)。

## 1. 從「隨機出題」改成「腳本編排」

| | v1–v2 | v3 |
|---|---|---|
| 出題 | 每拍依權重抽樣式（單音 / 二連 / 重甲），種子決定一切 | **固定腳本**決定每小節的難度級與拍速；種子只在同級樂句中挑一句、決定左右鏡像 |
| 難度形狀 | 6 段階梯，種子不同、難度起伏不同 | 每個種子形狀相同（跨日公平），只是內容不同 |
| 拍速 | 120 → 150 → 180 → 164 → 200 BPM（跳躍） | 112 → 120 → 129 → 144 → 157 → 171 BPM（逐段上升）；無雙段 138 / 164 |
| 新元素 | 疾兵、重甲從開局就可能出現 | 一次只教一件事：先單邊、再換邊、再八分音、**再**疾兵、**再**重甲，最後才混合 |

## 2. 樂句庫（每句 = 一小節 4 拍 = 8 個八分音符）

符號：`.` 休止 · `A`/`B` 步兵（A = 本小節先出現的一側）· `a`/`b` 疾兵 · `X`/`Y` 重甲的一擊（連續 X/Y = 同一隻，最多 3 擊）。

| 級 | 教什麼 | 樂句 |
|---|---|---|
| L1 | 單邊、兩拍一下 | `A...A...` `A...B...` `A.......` |
| L2 | 每拍一下、簡單換邊 | `A.A.A.A.` `A.A.B.B.` `A.B.A.B.` `A.A.A.B.` |
| L3 | 同側八分音二連 | `AA..A.B.` `A.A.BB..` `AA..BB..` `A.B.AA..` |
| L4 | 疾兵登場（前後留空） | `A.A.a...` `A...a.B.` `a...B.B.` `A.B...b.` |
| L5 | 重甲登場（單獨出現、後面休止） | `XXX.....` `A...XXX.` `XXY...B.` `XYX.....` |
| L6 | 快速左右換邊 | `ABA.BAB.` `AB..AB..` `A.BA.B.A` `AABBA.B.` |
| L7 | 疾兵 + 重甲混合 | `XYXa..B.` `a.AAb.BB` `XXXB.a..` `AB.b.XYX` |
| L8 | 高密度連打 | `ABABAB.a` `AABBAABB` `XYXABAB.` `aBAb.ABA` |

## 4. 人性化試玩（不是只看技巧等級）

`humanBots.mjs` 的三位「玩家」（新手 / 一般 / 熟手）模擬人為什麼會失誤：

| 因素 | 模型 |
|---|---|
| 讀取負荷 | ±0.5 秒內敵人越多，時機誤差越大、越容易漏按 |
| 快速換邊 | 與前一隻不同側且間隔 < 0.3 秒：誤差 +15～35%，點錯邊機率上升 |
| 新敵人 | 第一次看到疾兵 / 重甲誤差大，約 6 隻後學會（指數衰減） |
| 反應時間 | 預告時間比反應時間短 → 只能晚點、或乾脆漏掉 |
| 急躁 | 偶爾提早 150–250 ms 出手（空揮 → 硬直） |
| 疲勞 | 60 秒後誤差 +3～8% |

報告每段列出負荷（notes/s、快速換邊比例、難度指數 DI）與三位玩家的命中率 / Perfect 率 / 扣血，並自動檢查**斷崖**（一般玩家命中率在相鄰主段落掉 > 12 pp → exit 1）。

## 5. 調校過程（30 個種子）

| 版本 | 改動 | 結果 |
|---|---|---|
| 腳本 r1 | 第一版腳本 | DI 在第二次無雙段暴衝 4.6 → 7.6；新手在 44–63 秒間 47% → 3% 全滅；起手段就出疾兵 |
| 腳本 r2 | 疾兵延到交鋒、無雙段降一級並放慢、激戰從 L4 起 | DI 平順上升；新手仍在 54 秒前倒下 |
| **腳本 r3（現行）** | 三個調息段各回 1 血 | 新手 80% 撐過激戰、在猛攻（54–64 s）被淘汰；一般玩家全部打完但 Perfect 率 80% → 59% 逐段下滑；熟手維持 91% 以上；無斷崖 |

技巧主導（3 組種子）：96.8–97.8%，expert vs intermediate 100%。

## 6. 公平

- 腳本固定、所有人相同；種子只換樂句與鏡像（E2）。
- 調息回血是固定事件，所有人一樣，不是靠技巧換的（不影響技巧比較）。
- 計分公式不變；音符總數變少（約 220–250），理論滿分隨種子略有不同 → 跨日比較用達成率。

## 7. 狸貓改成頭目戰（sim v4，2026-10-21）

試玩回饋：「狸貓太難」、「降低狸貓攻擊懲罰（很快就死了）」。

| | v3 | v4 |
|---|---|---|
| 出現方式 | 混在一般樂句裡（L5、L7、L8），3 下八分音連打，常左右換邊 | **頭目小節**：只在交鋒、激戰、猛攻、決戰的段落結尾登場（決戰中段再一次），共 5 場，那一小節只有牠 |
| 節奏 | 八分音（171 BPM 時間隔 0.18 s） | **四分拍**（間隔加倍，171 BPM 時 0.35 s） |
| 換邊 | 第一次出現就可能換邊 | L9 三下同側 → L10 四下換一次邊 → L11 四下交替 |
| 懲罰 | 每漏一下扣 1 血（0.5 s 保護期內除外） | **每場頭目最多扣 1 血**，其餘漏接只斷連 |
| 提示 | 頭上 3 個小箭頭 | 下一擊：**大橘箭頭顯示在要點的那一側攻擊框上方**，外圈縮小圈在拍點收合（Cytus 式）；該側攻擊框變橘色；剩餘擊數排成小箭頭佇列；登場時橫幅「狸貓頭目登場！」 |

原本 L5 / L7 / L8 裡的狸貓位置改成疾兵與換邊樂句。人性化試玩（30 個種子）：無斷崖；新手撐過激戰的比例 80% → 90%；技巧主導 97.3%。

## 8. 全面自動化試玩（`npm run playtest`，sim v5，2026-10-21）

`game/tools/playtest.mjs` 逐小節分析整局，輸出 [docs/playtest_report.md](../docs/playtest_report.md) 與互動圖表頁 docs/playtest_report.html（`TwinStrike/docs/playtest_report.html`，未收錄）（DI、拍速、三種玩家命中率、存活率、反拍與切分；滑鼠移上去看每小節數值）。任一檢查失敗時 exit 1。

| 面向 | 量什麼 |
|---|---|
| 難度 | 每小節 DI（密度 × 換邊 × 疾兵 / 狸貓）；主段落線性擬合（斜率、R²）與 Spearman ρ；高於 / 低於擬合線 2σ 的尖峰與凹陷；各段高峰是否鋸齒向上 |
| 玩家 | 人性化 bot（新手 / 一般 / 熟手）逐小節命中率、存活率、血量；一般玩家是否落在心流帶（主段落 90–99%）；新手中位倒下時間 |
| 節奏 | 每個音符都在八分音格上；反拍比例、切分比例（反拍音且下一拍空）隨段落變化 |
| 樂句 | 主段落小節數是否為 4 的倍數 |
| 旋律 | keysound 每小節音域與最大跳進（半音） |
| 公平 | 技巧主導（技巧佔比、expert vs intermediate） |

### 第一次全面試玩發現 → 調整（v4 → v5）

| 發現 | 調整 | 結果 |
|---|---|---|
| 起手、交鋒、激戰、猛攻都是 6 小節，不成 4 / 8 小節樂句 | 起手 4、交鋒 8、激戰 8、猛攻 4 小節 | 全部主段落 4 / 8 小節 ✅ |
| 起手 → 交鋒難度持平（DI 2.0 → 2.1），決戰暴衝到 7.2（第 42、45 小節超出擬合線 2σ） | L8 提前到猛攻、激戰後半加 L7；R² 0.66 → 0.69 | 無尖峰、無凹陷；ρ 0.85 |
| keysound 左右兩側差兩個八度，每小節最大跳進約 30 半音 | 低音側 keysound 上移一個八度 | 最大跳進約 15–23 半音 |
| 反拍比例 | （不變） | 暖身 0% → 起手 15% → 激戰 27% → 決戰 43%：節奏複雜度隨難度上升 ✅ |

結果（30 個種子）：技巧主導 97%；一般玩家主段落命中率 98% → 95% 緩降（心流帶內）、全部打完；熟手 99%；新手中位數在第 58 秒（猛攻）倒下。
