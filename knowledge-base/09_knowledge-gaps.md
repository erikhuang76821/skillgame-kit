# 09 知識缺口 — 要「快速生成」Skill Game 還缺什麼

> 盤點日期 2026-10-19。依「擋住快速生成的程度」排序。P0 = 每款新遊戲都會卡住；P1 = 部分品類或上線前才會卡；P2 = 品質 / 長線。

## 總結

現有知識庫在**為什麼（市場、法規、公平原則）**與**用什麼做（技術棧、包體、DC、打擊感）**很完整，但從點子到可玩原型中間的**「怎麼把一種玩法快速做成確定性、可驗證的 sim」**幾乎只有 SwarmDuel 一個實例，而且綁死在 survivor-like + 8 方向像素角色上。換一個品類（撞球、節奏、三消、接龍）時，以下缺口會直接卡住。

## 建議補齊順序

1. ✅ **G1 + G3**：抽 skill-core 進範本、定玩法規格格式 → 新遊戲從「抄 SwarmDuel」變成「填規格」。
2. ✅ **G2 選 2 個品類先做配方**：建議「節奏 / 時機」（OFDP、Timberman：市場空缺、實作最輕）與「確定性物理」（撞球 / 泡泡龍：北美現金賽主力）。
3. ✅ **G6 音效配方** + **G4 輸入公平**：時機類必要。
4. **G11** 把外部 skill 收進 repo（或寫明安裝步驟）。
5. G7–G9 等確定要走現金賽 / 排行榜時再做。
