# 英雄守城割草（Horde Defense / Hero Tower Defense：Kingshot 開場、Thronefall 型）

- **代號**：af-horde-defense
- **類別**：4X 前導小遊戲（塔防 + 英雄走位 + 割草）
- **代表作 / 廠商**：Kingshot — Century Games（App Store 2025-02-22；廣告 2024-08 起投）；其開場被多方形容為仿 *Thronefall*（Grizzly Games，PC 獨立作）；同公司 Whiteout Survival 也屬「idle + 小遊戲」路線
- **投放熱度依據**：
  - SocialPeta：至 2025-06-04 累計約 1 萬支素材，6 月初單日峰值 > 2,000 支（Android > 1,500、iOS > 600）；**曝光最高的單支素材是「實機 + 割草（塔防）」，2 天約 220 萬曝光**，遠高於真人迷因（72 萬 / 3 天）與 AI 短劇類（[SocialPeta 2025-06](https://socialpeta.com/en/blog/with-2000-ai-creatives-daily-century-games-kingshot-dominates-mobile-charts-in-the-us-japan-and-korea-in-june)）。
  - AppGrowing 2025-04：單日近 1,500 組素材、3 月投放量月增 1,327%；北美約占投放支出 1/4，美國單國 > 14%；上線一個月由美國 iOS 暢銷約 #200 升至前 50（[AppGrowing](https://appgrowing.net/blog/en/kingshot)）。
  - SocialPeta × Reforged Labs（2026-01）：Kingshot 累計 45.3K 支素材、79.4% 影片；**很少用失敗誘導**，素材偏平靜、多展示前期實機（[GameDevReports](https://gamedevreports.substack.com/p/socialpeta-and-reforged-labs-mobile)）。
  - Lancaric 2025-11：Kingshot 據稱日營收約 300 萬美元（未證實）（[Brutally Honest](https://lancaric.substack.com/p/the-rise-of-sophisticated-onboarding)）。
  - 台灣：未取得 Kingshot 台灣投放占比（未證實）。
- **廣告真實度**：**真實～部分真實**。AppGrowing 實測：開場確實是玩家操控英雄、武裝村民、波次越來越大、後期出攻城器械；數次入侵事件後轉為標準 SLG（Lancaric）。
- **技巧 vs 選擇 vs 運氣**：戰前建塔配置屬選擇；戰鬥中主要技巧是英雄走位；後期被數值（建築等級）壓過，技巧占比下降。

## 一句話玩法

白天蓋塔與城牆，夜晚操控英雄在城門前割草，撐過一波比一波大的敵潮。

## 為什麼廣告有效（Hook）

| 元素 | 說明 |
|---|---|
| 前 3 秒畫面 | 布置好的塔與城牆，大量敵兵湧來被一路割倒（「mowing down」）；部分素材前 3 秒插入怪奇或舒壓的真實生活畫面（AppGrowing）。 |
| 失敗誘導（fail bait） | Kingshot **少用**（Reforged Labs 觀察）；改用「規模感」：敵潮越大、清得越快越爽。 |
| 「我來一定行」的錯誤示範 | 非主要策略；靠「我也想蓋這樣的防線」的經營慾。 |
| 爽感 / 解壓點 | 割草（大量敵人同時倒下）、升級後塔的視覺變化、城牆擋住敵潮。 |

## 遊戲規格

> 「建議值」為本工作室規格；原作數值未取得者標（未證實）。

### 核心循環
1. **建造期**（暫停 / 計時 15 s）：用本局金幣在固定建造點蓋箭塔 / 兵營 / 城牆。
2. **夜晚波次**：敵人沿 2–3 條路線推進；英雄由玩家拖曳移動，自動攻擊範圍內敵人。
3. 擊殺掉落金幣（固定量，非機率）→ 下一建造期。
4. 撐過 N 波 → 結算；原作此後轉入主城 / 聯盟 4X。

### 規則與勝負
- 主堡 HP 歸 0 = 失敗。
- 英雄死亡後 5 s 於主堡復活（建議）。
- 兵營變體：塔換成兵營，持續出兵與敵方對撞（AppGrowing 描述的「兩軍互撞」版）。

### 操作
- 單指拖曳英雄（浮動搖桿）；建造期點擊建造點選塔種。

### 關卡結構與難度曲線
| 關卡段 | 新元素 | 難度槓桿 |
|---|---|---|
| 波 1–3 | 步兵、單路 | 英雄單殺即可 |
| 波 4–7 | 第二條路、弓兵（遠程） | 英雄需在兩路間奔走 |
| 波 8–12 | 攻城器（高 HP、專打牆） | 必須英雄親自處理 |
| 波 13+ | 精英 / Boss | 原作此後由主城數值主導（未證實具體波數） |

### 計分 / 星等 / 獎勵
- 原作：戰利品箱與勝利資源保證掉落、建築自動修復（AppGrowing 實測）。

### 失敗與轉換點（廣告續命、IAP、導流到主遊戲的位置）
- 數次「入侵事件」後解鎖世界地圖 / 聯盟 → 4X 付費（建築加速、英雄抽取，未證實細節）。
- Kingshot 主打「no-ads」素材（多語系 17 萬曝光 / 25 天），表示本體不靠插頁廣告變現（SocialPeta）。

## 可玩廣告（Playable Ad）結構

- Kingshot playable 細節未取得（未證實）。建議：建造 1 次（3 個建造點選 1）→ 1 波 20 秒割草 → Boss 出現時 CTA。
- 共 25–30 秒、互動 2 步（建塔、拖英雄）。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 英雄走位 | 讓英雄的攻擊範圍蓋住最多敵人（聚怪割草）並在多路間切換 |
| 建造配置 | 塔種與位置對應路線與敵種 |
| 經濟時機 | 先蓋經濟還是先蓋防禦 |
| 威脅排序 | 攻城器 / 弓兵優先處理 |

## 隨機 / 選擇噱頭

- 原作戰鬥不太依賴隨機；真正的「勝負」在後期被建築等級與付費加速決定。
- 「保證掉落」其實是好設計（無機率），可直接沿用。

## Skill Game 化改造（必做）

> 用這份規格書做遊戲時（含「復刻」），玩法規格 `gdd/05_game_spec.md` §13 要逐條回應下列每一條：採用就寫本作做法，不採用就寫理由與替代做法。「復刻」只復刻玩法結構與操作，不跳過本節（`RULE-AF-ADAPTATION`，`npm run audit` 檢查）。

1. **一局完整、無局外數值**：所有建築在局內從 0 開始，資源只來自本局擊殺（固定掉落）。
2. **英雄走位成為主技巧**：英雄自動攻擊改為**揮砍有方向的扇形**（120°、半徑 90 px，建議），朝最後移動方向；聚怪後轉身一刀清群 → 走位 + 時機。加一個 8 s CD 的衝撞技（手動觸發）。
3. **同種子**：波次表（敵種、數量、出生時間、路線）= `rng(seed,"wave",i)`；雙方完全相同；建造點固定。
4. **計分公式（建議）**：`Score = 擊殺分（步 1、弓 2、攻城 10、Boss 50）+ 主堡剩餘 HP% × 5 + 未花金幣 × 0.5 − 英雄死亡 × 30`；撐不過全部波次仍計分（不歸零）。
5. **局長**：8 波 × (10 s 建造 + 15 s 戰鬥) ≈ 200 秒；可做 3 分鐘快速版（6 波）。
6. **非同步對戰**：雙方各自防守同一份波次表比分數；或「我擊殺的敵人送到對手波次」的同步版（需伺服器）。

## HTML5 輕量實作規格

| 項目 | 規格 |
|---|---|
| 畫面 | 直版 720×1280；斜俯視 2.5D 或 3D 低多邊形（Thronefall 風）；主堡在下方，敵人從上方三路下來 |
| 實體與資料結構 | 敵 SoA ≤ 300（type、x、y、hp、lane、pathIdx）；塔 ≤ 12；子彈 / 箭 SoA ≤ 200；英雄 1；路徑為預烘焙折線；空間雜湊 cell 48 px，依 id 排序 |
| 關鍵參數 | 敵速 步 60 / 弓 50 / 攻城 30 px/s；英雄速 220 px/s；揮砍 0.5 s 一次、傷害 3；箭塔射速 1.2/s、射程 220；建造期 10 s |
| 渲染 / Draw Call 估計 | 2D：地圖 1、角色 + 塔 + 敵（同 atlas）1、箭 / 投射物 1、BitmapText 1、刀光扇形（預生成 sprite）併入角色 atlas → **4 DC**。3D（three/ogl）：地形 1、敵兵 instancing 1（300 隻共用 mesh，顏色 / 動畫相位用 instance attribute，頂點動畫）、塔 instancing 1、城牆 1、英雄 1、投射物 instancing 1 → **6 DC**（≤ 9 上限）|
| 美術資產清單 | 2D 版：英雄 8 向 × 4 幀、敵 4 種 × 4 幀、塔 3 種 × 2 級、城牆、主堡、地圖 1 張（WebP）；3D 版：低多邊形 glTF 8 個（Meshopt）+ 1 張 256² 調色盤貼圖 |
| 包體估計 | 2D：程式 1.0 MB + atlas 0.8 MB + 地圖 0.3 MB + 音 1.8 MB ≈ **3.9 MB**；3D：+ three 0.6 MB、模型 0.4 MB ≈ **4.6 MB** |

## 主題與美術風格

- 原作：中世紀寫實 / 低多邊形 Q 版混合；Kingshot 素材另有大量 AI 油畫風、動漫風混剪（SocialPeta）。
- 改造：低多邊形 + 單色調色盤最省包體；可換「農場防狐狸」「蜂巢防黃蜂」。

## 可借用 / 要避開

- **可借用**：實機割草素材效果最好（Kingshot 曝光數據）——代表**真實玩法廣告可行**；保證掉落；英雄 + 塔的雙層決策。
- **要避開**：後期由建築等級 / 付費加速決定勝負；局外英雄養成帶入比賽。
