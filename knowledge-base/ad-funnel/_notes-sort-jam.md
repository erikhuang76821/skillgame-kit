## 3. 為什麼這波有效

1. **規則一眼懂**：同色進同色（門、盒、公車、瓶），零教學；廣告前 3 秒就能傳達規則。
2. **看似低技巧、實則重規劃**：所有爆款的失敗條件都是「有限暫存區被塞滿」（螺絲 5 孔、Pixel Flow 5 格、公車等候格、三消 7 槽、水排序空瓶）。觀眾看示範者塞爆，會強烈覺得「我會先處理那個」——正是 fail bait 的心理。
3. **確定性盤面 = 失敗怪自己**：DoF 分析 Pixel Flow：沒有隨機，輸了只能怪順序或時機 → 願意重試、願意付錢跳過那一步。
4. **整理 / 清空的解壓感**：清空像素畫、拆光螺絲、瓶子變單色、亂線解開；ASMR 式音效（旋出、倒水、啵）。
5. **超短局、高頻**：Pixel Flow 每人每天約 10 次、合計約 1 小時（DoF）；Block Blast 平均單次 12 分鐘、每日 2.7 次（Udonis）。
6. **可玩廣告即本體**：玩法輕到能完整放進可玩廣告。Pixel Flow 美國 75% 曝光來自可玩、一支可玩跑了 8 個月（AdMapix）；Segwise 引 Liftoff 2025 稱可玩的曝光到安裝轉換約為非可玩的 16 倍（[Segwise](https://segwise.ai/blog/understanding-playable-ads-guide.md)，二手）。
7. **換皮成本低、主題可輪替**：毛線、硬幣、咖啡、公車、豬——同一骨架換題材就能重測 CPI（Knit Out、Coin Sort、Coffee Mania 都是此路線）。

## 4. 變現結構（三種模型）

| 模型 | 代表 | 特徵 |
|---|---|---|
| 純廣告（IAA） | Block Blast、Hexa Sort、Bus Out、Arrows 小廠作品 | 量極大、留存極低（Block Blast D7 4.1%），靠插頁 + rewarded；去廣告 / 去廣告訂閱是主要 IAP |
| 混合（約 50/50～60/40） | Pixel Flow（廣告 30–40%）、Color Block Jam、Screw Jam、Bus Jam | AppMagic 認為 50/50 是成功混合休閒益智的典型；前 15–20 關無廣告保護新手，之後插頁變密 |
| 純 IAP | Match Factory（無廣告）、Magic Sort（AppMagic 口徑） | 高 ARPU：Magic Sort 以 3.4% 的 DAU 拿 43% IAP；Match Factory 上線 100 天 RPD $4.55 |

**共同收費點**（依出現頻率）：
1. **失敗當下的續關 / End Game Offer**：+1 瓶、+1 暫存格、加時、付約 $2 續玩；Screwdom、BitEpoch 把它當主力（BitEpoch 把 fail-offer 從 $4.99 調到 $5.99）。
2. **生命制**：上限 5 命、失敗扣 1，等待回復 / 看廣告 / 買「無限生命」包。
3. **道具**：撤銷、清一色、敲碎、多一格、凍結時間；用金幣買，金幣再用 IAP 補。
4. **連勝 / 連續天數保護**：Magic Sort 的 IAP 大宗是「為保連勝付費續關」；Arrows 直接賣 Streak Freezer。
5. **LiveOps**：競速活動（2025 H1 超過 60% 混合休閒遊戲有 race 類活動，AppMagic 經搜尋摘要）、Battle Pass、每日挑戰、排行榜。
6. **難度刻意設計成付費壓力**：DoF 直言 Pixel Flow 保護難度是因為難度驅動 IAP；Color Block Jam 玩家抱怨倒數；Bus Jam 玩家稱特定關不買道具過不了；Match Factory 在 200–250 關道具使用量升至約 1.5 倍（Udonis）。

**留存對照**：混合休閒建議 D7 15–20%、D30 約 10%（Gamigion）；純廣告的 Block Blast D7 僅 4.1%（Udonis）。

## 5. 給 Skill Game 工作室的教訓

1. **「有限暫存區」是本品類的公平核心，把它留下、把付費擴充拿掉**。所有爆款的張力都來自 5 格 / 7 槽 / 空瓶；我們保留固定容量，刪除「+1 格」「續關」類商品。這同時解決「錢買不到分數」。
2. **這些遊戲多半已是確定性盤面 → 改造成本低**。只需三件事：同種子選題（或程序生成）、資訊對等（佇列預告、去除隱藏層）、移除 DDA / 自適應難度（Block Blast、Magic Sort、Match Factory 都有，必須拿掉）。
3. **把「過 / 不過」改成連續分數，並加入時間或效率維度**。純選擇謎題（水排序、箭頭、螺絲）大家終究都解得出來，比賽要比「多快、多省步」；用求解器算 par、用時間獎勵拉出技巧天花板。關卡時間到不判死，保留已得分，避免一次失誤毀局。
4. **優先挑「可程序生成、保證有解」的子類**：水排序（反向打亂）、箭頭（反向放置）、方塊擺放（種子出塊）可零關卡檔、無限題目、天然防背題；Pixel Flow / 公車 / 螺絲需要手工關卡池，內容成本較高。
5. **物理與 3D 是陷阱**：Match-3D 的物理堆疊、Screwdom 的 3D 模型都不確定且超出 DC / 包體預算；改用 2.5D 分層 + 預渲染 sprite。本清單 8 款全部可在 ≤ 3 DC、≤ 3.5 MB 內實作。
6. **找「排序 + 操作」的混合技巧**：Pixel Flow 的 slinging（連點超載）與公車的走路時間，證明排序遊戲也能有手速天花板；這是把選擇型謎題拉到 skill-dominance ≥ 70% 的關鍵。輸入必須走時間戳佇列。
7. **導流素材要真實、要能玩**：此品類最強素材就是可玩的本體（Pixel Flow 75% 曝光來自可玩）；我們的 HTML5 本身就能當可玩廣告。避免 Block Blast 式的無關開場、假「新版本無廣告」對話框、拿其他品牌比較、灰色地帶 IP 圖像。
8. **跟風窗口很短，差異化要在機制不在皮**：仿作潮兩三個月內就湧入（Pixel Flow 後 pixel / flow 命名數百款，Color Blaze Shooter 因抄襲下架）；Screw 因山寨過多已降溫、Bus Frenzy 一季內下載掉 96%。選題時看「機制骨架能否延伸出技巧維度」，而不是追當月最熱的皮。
