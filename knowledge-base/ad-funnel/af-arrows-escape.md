## 一句話玩法

點一支箭頭，它就沿箭頭方向滑出盤面；被擋到會撞上並扣心，清光所有箭頭即過關。

## 為什麼廣告有效（Hook）

| 元素 | 說明 |
|---|---|
| 前 3 秒畫面 | 點陣背景上密密麻麻交纏的箭頭線條，像一團打結的線；點一下就「咻」地滑出畫面。 |
| 失敗誘導（fail bait） | 示範者點了被擋住的箭頭 → 撞上、紅心少一顆；最後一顆心時又點錯。 |
| 「我來一定行」的錯誤示範 | 觀眾看得出「最外面那支朝外的明明沒被擋」。 |
| 爽感 / 解壓點 | 解開一團亂線的整理感；連續點對時箭頭接連飛出的節奏；盤面越來越空。 |

## 遊戲規格

### 核心循環
1. 盤面：點陣格上放著多支箭頭（每支佔一段連續格，頭端有方向）。
2. 點一支箭頭 → 它沿頭的方向移動（身體跟著頭走），直到離開盤面。
3. 若前進路徑上有其他箭頭 → 碰撞、扣 1 心，箭頭回原位（推定，未證實「回原位」細節）。
4. 清空全部箭頭 = 過關；3 顆心用完 = 失敗。

### 規則與勝負
- 心：3 顆，點錯扣 1，用完停止；可看廣告續玩（App Store 評論）。
- 無計時（開發者說明明寫）。
- 箭頭形狀：短直線到多段轉彎的蛇形長線（從截圖與同類描述推定，轉彎蛇形未證實）。
- 難度分級：Normal / Hard / Super Hard / Nightmare（攻略站），另有每日挑戰與連續天數。
- 關卡：開發者稱「數千手工關卡」；評論稱達一定複雜度後轉為隨機生成（未證實）。

### 操作
- 單點。可加雙指縮放大盤（推定）。

### 關卡結構與難度曲線
| 關卡段 | 新元素 | 難度槓桿 |
|---|---|---|
| 入門 | 5–15 支直箭頭 | 依賴 1–2 層 |
| 中期 | 轉彎長箭頭、交錯 | 箭頭數量、依賴鏈長度 |
| Hard 以上 | 數十～上百支（評論：越難箭頭越多） | 視覺密度、依賴環被精心避開的「陷阱外觀」 |

### 計分 / 星等 / 獎勵
- 原作以過關與連續天數（streak）為主，沒有分數。

### 失敗與轉換點（廣告續命、IAP、導流到主遊戲的位置）
- 心用完 → 看廣告續、或買「Refill Global Lives」$1.99。
- 提示：「Buy Hints」$1.99。
- 連續天數：Streak Freezers $1.49、Streak Fixer $4.99 —— 把**每日習慣**變成付費點。
- 去廣告：買斷 $9.99 / $16.99，或訂閱 1 個月 $9.99、3 個月 $22.99、6 個月 $39.99（App Store 價目）。
- 以廣告為主的模型（大量插頁），去廣告與訂閱是主要 IAP（推定）。

## 可玩廣告（Playable Ad）結構

- 推測（未證實）：0–2 秒 8–12 支箭頭 + 手指提示最外圍那支 → 3–5 次點擊清掉外圍 → 中央剩下互相卡住、看起來像死結的 3 支 → 玩家點錯扣心 → CTA。

| 技巧 | 影響 |

## 隨機 / 選擇噱頭

- 零隨機；只要盤面無依賴環，**任何拓撲順序都能解** → 解法很多，困難只在「看出來」。
- 這使它天生適合做「速度 + 正確率」競賽：題目公平、解答不唯一（不會被背答案）、難度可由程式控制。

## Skill Game 化改造（必做）

> 用這份規格書做遊戲時（含「復刻」），玩法規格 `gdd/05_game_spec.md` §13 要逐條回應下列每一條：採用就寫本作做法，不採用就寫理由與替代做法。「復刻」只復刻玩法結構與操作，不跳過本節（`RULE-AF-ADAPTATION`，`npm run audit` 檢查）。

1. **同種子程序生成（零關卡檔）**：`rng(seed)` 生成箭頭盤面——採「反向放置法」：從空盤開始，每次放一支「放下後仍可沿頭方向滑出」的箭頭，等於從最後一個被清除的往前建，保證依賴圖無環、必有解；箭頭長度、轉彎數、密度由難度參數決定。
2. **限時 + 連續計分**：一局 90 秒、連續出題（盤 1 → 盤 2 → …，難度遞增），比的是清掉的箭頭數。
3. **計分公式**（建議）：
   - 每清 1 支：`+10 + 長度格數 × 1`
   - 連擊：連續無錯點擊 n 次，每支額外 `+min(n, 20)`
   - 撞擊：−30 並斷連擊、0.5 秒硬直（sim 鎖輸入 30 tick）
   - 清盤：+200 + 該盤用時獎勵 `max(0, 目標秒數 − 實際秒數) × 10`
   - 取消「心」：錯誤以扣分 + 硬直懲罰，不提前結束，避免一次失誤毀局
4. **確定性**：箭頭以格座標與方向存；可否脫出 = 頭的射線上是否有其他存活箭頭的格（O(格數) 查表，用 `occupancy: Uint16Array` 存 arrowId）；移動動畫只在渲染層。
5. **移除付費影響**：無提示購買、無續心、無 streak 保險；每日種子挑戰只看分數。
6. **對戰形式**：非同步同種子 90 秒排行；1v1 同盤同時開打（同樣盤序，各自進度）。
7. **技巧主導驗證**：bot 以「每次反應時間 + 錯誤率」分三級（例：600 ms / 10%、350 ms / 4%、200 ms / 1%），30+ 種子跑 skill-dominance。

## HTML5 輕量實作規格

| 項目 | 規格 |
|---|---|
| 畫面 | 直版 720×1280；盤面點陣 10×14～20×28 格（依難度），每格 32–64 px；上方 HUD 為 HTML |
| 實體與資料結構 | `arrows[]{id, cells: Int16Array(路徑格索引, 頭在末端), dir, alive}`；`occ: Uint16Array(W*H)`（0 空、否則 arrowId+1）；`canExit(id)`：沿 dir 從頭走到邊界檢查 `occ`；`events[]`（exit / collide / clearBoard） |
| 關鍵參數 | sim 60 Hz；局長 90 s；撞擊硬直 30 tick；脫出動畫 250 ms（sim 立即移除，不阻擋下一次點擊）；每盤箭頭數 12 → 120 遞增 |
| 渲染 / Draw Call 估計 | 箭頭用 Pixi `Graphics` 畫粗線 + 三角頭，整盤共用 1 個 Graphics（盤面變動時重建）：1 DC；點陣背景用 tiling sprite：1 DC；分數 BitmapText：1 DC → **約 3 DC**；完全不需要點陣圖美術 |
| 美術資產清單 | 幾乎為零：點陣背景 1、撞擊閃光 1、清盤星光 1；配色表（6–8 色，色弱安全） |
| 包體估計 | 程式 0.7 MB；圖片 < 0.05 MB；音效 0.15 MB；BGM 1.5 MB（或程式合成，見 [14 音效](../14_audio.md)）→ **≈ 2.4 MB；去 BGM 可 < 1 MB** |

## 主題與美術風格

- 原作：極簡點陣 + 單色或少色箭頭，深色模式；「禪」與「腦力訓練」包裝。
- 改造：可包成「解耳機線」「拆鞋帶」「車流脫困」；或保留極簡風（製作成本最低、包體最小，是本清單中最適合快速原型的品類）。

## 可借用 / 要避開

- **可借用**：反向放置法保證有解的程序生成；「無環就必可解、解法不唯一」→ 天然防背題；極低美術成本；每日種子挑戰。
- **要避開**：streak 保險付費（把習慣變成焦慮）；心數制一錯即死；名稱與 Lessmore 作品過度相近（市場已有大量同名作與下架案例）。
