# 畫線護主（Draw to Protect：Save the Doge / Draw & Guard）

- **代號**：af-draw-to-protect
- **類別**：畫線解謎（一筆畫牆 + 物理撐時間）
- **代表作 / 廠商**：Save The Doge — Miracle Game（約 2022，未證實）及大量同名仿作（App Store 上有多款「Save the Dog / Draw To Save My Doge」）；*Those Games 2* 的「Draw & Guard」模式（50 關，畫線圍住貓、撐過時限）— Monkey Craft / D3 Publisher（2024-07）
- **投放熱度依據**：
  - **2025–2026 投放熱度未取得證據（未證實）**。第三方攻略稱 Save The Doge 曾在 Facebook / YouTube / TikTok 廣泛曝光（[mytour](https://mytour.vn/en/blog/bai-viet/how-to-play-save-the-doge-on-your-phone.html)，二手來源）；搜尋到的仿作多為低下載量（Cafebazaar 某仿作僅約 190 安裝）。
  - 收錄理由：格式本身**最接近真技巧**（畫線品質 × 物理），且被 *Those Games 2* 證明可撐 50 關；熱度判定：低（2022–2023 高峰，現為長尾）。
  - 台灣 / 北美：均無 2025–2026 數據（未證實）。
- **廣告真實度**：**真實玩法**（超休閒本體即廣告內容）；被 4X 借用的案例未查到（未證實）。
- **技巧 vs 選擇 vs 運氣**：畫線形狀與長度是真技巧；蜂群路徑若含隨機則有運氣（原作未證實）。

## 一句話玩法

用一筆畫出牆，把狗圍住，擋住蜂巢衝出的蜂群撐過倒數。

## 為什麼廣告有效（Hook）

| 元素 | 說明 |
|---|---|
| 前 3 秒畫面 | 呆萌狗 + 蜂巢，手指開始畫線。 |
| 失敗誘導（fail bait） | 示範者畫的線有缺口 / 太短 / 被蜂群推倒，狗被叮腫（搞笑失敗動畫）。 |
| 「我來一定行」的錯誤示範 | 畫線人人會，缺口位置一眼可見。 |
| 爽感 / 解壓點 | 蜂群撞牆被彈開、倒數歸零狗安然無恙；失敗動畫本身也有喜感（可分享）。 |

## 遊戲規格

### 核心循環
1. 觀察場景（狗、蜂巢位置、地形、障礙）。
2. 一筆畫線（墨水量有限），放手後線變成受重力的剛體。
3. 蜂群自蜂巢湧出、追向狗並推擠線條。
4. 撐過倒數（各版本 5–10 s 不等；某 App Store 版本為 10 s）= 過關。

### 規則與勝負
- 只能畫一筆；墨水上限（例 100%）；墨水剩餘越多星等越高（原作常見，未證實）。
- 線條不可穿過狗或地形；狗被蜂碰到 = 失敗。

### 操作
- 單指按住拖曳畫線、放開完成。

### 關卡結構與難度曲線
| 關卡段 | 新元素 | 難度槓桿 |
|---|---|---|
| 1–10 | 平地、單蜂巢 | 圍一個圈即可 |
| 11–30 | 斜坡、會滾的狗、多蜂巢 | 線要能撐住重心 |
| 31–60 | 岩漿 / 水、炸彈、活動平台 | 線兼作支架與牆 |
| 60+ | 墨水極少 | 最短有效形狀 |

### 計分 / 星等 / 獎勵
- 原作：過關 + 墨水剩餘星等；過關後「看廣告雙倍領取」（[mytour](https://mytour.vn/en/blog/bai-viet/how-to-play-save-the-doge-on-your-phone.html)）。

### 失敗與轉換點（廣告續命、IAP、導流到主遊戲的位置）
- 失敗 → 插頁廣告 / 看廣告跳關；IAP 去廣告、皮膚。

## 可玩廣告（Playable Ad）結構

- 1 關、10–15 秒：畫線 3 秒 → 蜂群 5–10 秒 → 成功 / 失敗動畫 → CTA。互動 1 步。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 形狀設計 | 封閉、穩定、不會被推倒 |
| 墨水經濟 | 越短越高分 |
| 物理直覺 | 線條重心、支點、與地形的卡合 |

## 隨機 / 選擇噱頭

- 若蜂群路徑或數量隨機，同一條線可能時過時不過 → 必須確定化。
- 本格式「選擇噱頭」最少，是本批中最容易做成技巧遊戲的一個。

## Skill Game 化改造（必做）

> 用這份規格書做遊戲時（含「復刻」），玩法規格 `gdd/05_game_spec.md` §13 要逐條回應下列每一條：採用就寫本作做法，不採用就寫理由與替代做法。「復刻」只復刻玩法結構與操作，不跳過本節（`RULE-AF-ADAPTATION`，`npm run audit` 檢查）。

1. **確定性物理**：線條離散為定長節點鏈（每 8 px 一節，整數子像素），用位置式動力學（PBD）固定迭代 4 次；蜂為粒子，路徑 = 追蹤 + 分離，全部整數 / 定點運算（見 12_genre-recipes §2、04_tech-stack §4）。
2. **同種子**：關卡由種子從手工池選取並鏡像；蜂群出生時刻表與初速由 `rng(seed,"bee",i)` 決定。
3. **輸入紀錄**：畫線以 `{tick, x, y}` 序列記錄（降取樣至每 2 tick 一點）供伺服器重播驗分。
4. **連續計分**：`Score = 存活秒數 × 20 + 剩餘墨水% × 3 + 撐滿時限獎勵 200 − 狗被碰觸次數 × 50`（改成 HP 3 次，而非一碰即死）。
5. **進階技巧**：允許**倒數期間再畫第二筆**（墨水共用，畫線時間停用 0.5 s）→ 即時補洞技巧。
6. **局長**：5 關 × 15 秒 ≈ 90 秒；非同步同種子對戰。

## HTML5 輕量實作規格

| 項目 | 規格 |
|---|---|
| 畫面 | 直版 720×1280；關卡區 720×1000 |
| 實體與資料結構 | 線節點 ≤ 150 `Int32Array(x,y,px,py)`；約束 = 相鄰節點距離；地形為折線多邊形；蜂 ≤ 80 SoA；狗為圓形剛體 |
| 關鍵參數 | 墨水上限 1,200 px；節距 8 px；重力 0.4 px/tick²；PBD 迭代 4；蜂速 3 px/tick、推力 0.2；倒數 10 s |
| 渲染 / Draw Call 估計 | 背景 1；線條用 `Graphics` 每 tick 重繪（或改成節點 sprite 鏈避免打斷合批）1；狗 + 蜂 + 蜂巢 + 道具同 atlas 1；UI BitmapText 1 → **4 DC** |
| 美術資產清單 | 狗 3 表情、蜂 2 幀、蜂巢、地形 tileset、墨水筆刷 sprite、失敗動畫（狗腫臉）4 幀 |
| 包體估計 | 程式 0.8 MB；atlas 0.3 MB；關卡 JSON 0.1 MB；音效 0.2 MB；BGM 1.5 MB → **≈ 2.9 MB** |

## 主題與美術風格

- 原作：Doge 迷因狗 + 蜂（迷因 IP 有授權疑慮，勿直接使用 Doge 形象）。
- 改造：自有吉祥物；可換「保護蛋糕不被螞蟻吃」「替小雞擋冰雹」。

## 可借用 / 要避開

- **可借用**：一筆畫的低門檻與高上限；失敗動畫的喜感（分享素材）；墨水經濟計分。
- **要避開**：非確定物理（Box2D 浮點跨裝置不一致）；看廣告雙倍領取；迷因 IP。
