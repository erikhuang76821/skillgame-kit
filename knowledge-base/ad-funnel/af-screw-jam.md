## 一句話玩法

點掉板子上的彩色螺絲，送進同色工具盒；暫存孔塞滿就輸。

## 為什麼廣告有效（Hook）

| 元素 | 說明 |
|---|---|
| 前 3 秒畫面 | 一疊木板 / 鐵板被五顏六色的螺絲釘住，上方是等色的工具盒；一點螺絲就轉出來飛進盒子，板子掉落，物理感強。 |
| 失敗誘導（fail bait） | 5 格暫存孔只剩 1 格，示範者又點了錯色螺絲 → 全滿失敗。 |
| 「我來一定行」的錯誤示範 | 觀眾看見「先拆上層那顆紅的、下面就會掉出兩顆紅的」，覺得示範者太笨。 |
| 爽感 / 解壓點 | 螺絲旋出的觸覺音效、盒子裝滿蓋上飛走、板子嘩啦掉落；3D 版（Screwdom）把整個模型（房子、鴨子、方塊）拆光的拆解感。 |

## 遊戲規格

### 核心循環
1. 盤面：多層板子，每塊板子被 1–N 顆螺絲固定；上層板子遮住下層；部分螺絲藏在彩色玻璃層下。
2. 上方：當前開放的工具盒（各一色，有固定孔數）。
3. 點一顆**沒被擋住**的螺絲 → 若有同色且未滿的工具盒 → 飛進盒子；否則進入暫存孔。
4. 工具盒裝滿 → 蓋上飛走 → 下一個工具盒進場；暫存孔裡同色螺絲自動補入。
5. 板子上所有螺絲都拔掉 → 板子掉落，露出下層。
6. 全部工具盒填滿 = 過關；暫存孔全滿 = 失敗、扣 1 命。

### 規則與勝負
- 暫存孔：**5 格**（Rollic 官方說明）。
- 工具盒容量：官方未寫明（常見 3 孔，未證實）。
- 同時開放的工具盒數：未證實（常見 1–2 個）。
- 玻璃層：把彩色玻璃清掉才露出下層螺絲（官方）。
- 生命：上限 5 命，失敗扣 1，可等待回復或看 rewarded 廣告換 1 命（官方）。
- 計時：原作無（官方說明未提）。

### 操作
- 單點螺絲；3D 版可旋轉鏡頭看背面（Screwdom 從 2D 改 3D，AppMagic：3D 物件遮住關卡 80% 以上內容）。

### 關卡結構與難度曲線
| 關卡段 | 新元素 | 難度槓桿 |
|---|---|---|
| 入門 | 2–3 色、1–2 層板 | 暫存孔寬裕 |
| 中期 | 玻璃層隱藏螺絲 | 資訊不完全 → 要先開視野 |
| 後期 | 多層互相壓住、特殊螺絲（官方 FAQ 提到螺絲類型與障礙，細節未取得） | 工具盒出場順序 vs 可拔螺絲的錯位 |
| Screwdom | 3D 模型、需轉鏡頭 | 單關 5–15 分鐘，失敗代價高（QQ 轉述） |

### 計分 / 星等 / 獎勵
- 過關給金幣；金幣買道具或失敗時買額外孔（官方）。

### 失敗與轉換點（廣告續命、IAP、導流到主遊戲的位置）
- 道具（Screw Jam 官方）：**Extra Slot**（整關 +1 暫存孔）、**Hammer**（打碎玻璃露出下層）、**Double Toolbox**（下一個工具盒提前開放，同時解兩盒）。
- 失敗當下：花金幣買額外孔繼續（官方）；玩家評論曾見「3 孔 225 金幣」（舊版價格，未證實）。
- Screwdom：失敗時跳 **End Game Offer**（EGO）付費續關，是主要收費點；金幣包為主力 IAP（AppMagic、QQ）。BitEpoch 把 fail-offer 從 $4.99 調到 $5.99（GameDevReports Q2 2025）。
- 這個品類的錢幾乎都收在「差一步就過」的失敗畫面。

## 可玩廣告（Playable Ad）結構

- 推測（未取得實際可玩，未證實）：0–2 秒 2 層小板 + 手指指向正確螺絲 → 3–5 次點擊裝滿第一盒 → 板子掉落 → 第二盒需要的顏色被壓在下面、暫存孔快滿 → CTA。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 依工具盒順序挑螺絲 | 主技巧，避免暫存孔堆積 |
| 預判「拆哪顆會讓板子掉」 | 解鎖下層的時機 |
| 玻璃 / 背面資訊管理 | 先揭露再決策 |
| 暫存孔水位控管 | 失敗條件本身 |

## 隨機 / 選擇噱頭

- 原作關卡固定，但「下一個工具盒是什麼顏色」與「下層藏什麼」對玩家是不可見的 → 第一次玩容易像運氣。
- 付費孔位直接把難度換成錢。

## Skill Game 化改造（必做）

> 用這份規格書做遊戲時（含「復刻」），玩法規格 `gdd/05_game_spec.md` §13 要逐條回應下列每一條：採用就寫本作做法，不採用就寫理由與替代做法。「復刻」只復刻玩法結構與操作，不跳過本節（`RULE-AF-ADAPTATION`，`npm run audit` 檢查）。

1. **資訊對等**：顯示工具盒佇列的**下 2 個**顏色；玻璃下的螺絲顏色以半透明顯示（不再藏資訊），把勝負集中在規劃。
2. **加入時間壓力**：每關 50 秒；時間到不判死，以已入盒螺絲計分 → 從「過 / 不過」改為連續分數。
3. **計分公式**（建議）：
   - 螺絲入盒 +10；工具盒裝滿 +50
   - 暫存孔：每次螺絲進暫存孔 −5（鼓勵直送）
   - 清關 +300 + 剩餘秒數 × 10
   - 暫存孔全滿：該關結束、保留已得分
4. **同種子**：`rng(seed,"lvl",i)` 從手工關卡池抽 5 關；工具盒佇列順序屬關卡資料，固定。
5. **確定性**：**不用物理引擎**。板子掉落是「最後一顆螺絲拔掉的那個 tick 從圖層移除」，掉落只是渲染層 GSAP 動畫；遮擋關係以「螺絲是否被更高層板子覆蓋」的預算表判斷。
6. **移除付費影響**：無 Extra Slot / Hammer / EGO 購買；生命制取消。
7. **對戰形式**：非同步同種子 5 關 ≈ 4 分鐘；排行榜。3D 版不做（DC 與包體都超標，且鏡頭操作會稀釋規劃技巧）。

| 項目 | 規格 |
|---|---|
| 畫面 | 直版 720×1280；上方工具盒列（當前 1–2 盒 + 佇列預覽 2 盒）；中段 5 格暫存孔；下方板子區 640×760 |
| 實體與資料結構 | `screws[]{id, color, x, y, plateIds[]}`；`plates[]{id, layer, polygon/rect, screwIds[], alive}`；`blockedBy[screwId] = plateIds of higher layers covering the hole`（關卡載入時預算）；`boxes: Queue<{color, cap, filled}>`；`bench[5]`；`events[]`（pick / toBox / toBench / boxDone / plateFall / fail） |

| 渲染 / Draw Call 估計 | 板子（9-slice 木紋 / 金屬）、螺絲、盒子、暫存孔共用 1 atlas：1 DC；掉落用 GSAP 位移 + 旋轉；分數 BitmapText 1 DC → **約 2–3 DC**；玻璃層用半透明 sprite，不用 filter |
| 美術資產清單 | 螺絲頭（灰階 tint）1、螺絲側視 1、孔 1、板子 9-slice 2 材質、玻璃 1、工具盒 1（tint）+ 蓋子 1、暫存孔 1、背景 1 |
| 包體估計 | 程式 0.8 MB；atlas 0.25 MB；關卡 JSON 300 關 ≈ 0.2 MB；音效（旋出、入盒、掉落）0.2 MB；BGM 1.5 MB → **≈ 3.0 MB** |

## 主題與美術風格

- 原作：木工 / 五金寫實質感，彩色螺絲；3D 版是可拆解的小模型。
- 改造：可換「拔圖釘收進文具盒」「拆積木零件」；避免工具 / 五金以外的危險物品聯想即可，題材自由度高。

## 可借用 / 要避開

- **可借用**：「點一下就飛進盒子」的極低門檻操作；工具盒佇列 × 暫存孔的雙重壓力結構；拆光的完成感。
- **要避開**：隱藏資訊造成「第一次玩一定輸」；失敗當下的付費續關（EGO）；3D 鏡頭版（輕量化不划算）；在一個已被山寨淹沒、AppMagic 判斷正在降溫的子類做純換皮。
