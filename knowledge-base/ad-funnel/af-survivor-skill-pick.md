# 倖存者割草 + 技能三選一（Survivor-like / Skill Pick：Survivor.io / Archero 2 / Capybara Go!）

- **代號**：af-survivor-skill-pick
- **類別**：吞噬成長 / 割草 roguelite（廣告即實機）
- **代表作 / 廠商**：Survivor.io（2022，未證實；TikTok 爆量期約 2022–2023）、Archero 2（2024-11-19 先上港澳台韓；全球上線 2025，未證實）、Capybara Go!（2024-10 全球）、Wittle Defender（2025，台灣 2025-04 開預約）— 皆為 Habby
- **投放熱度依據**：
  - SocialPeta 2025 H1 iOS 投放量前 10 名含 Archero 2（[Mobilegamer.biz 2025-08-20](https://mobilegamer.biz/data-digest-appsflyers-rumoured-4bn-exit-top-ad-spenders-market-data-plus-company-financials-and-investment-news/)）。
  - **台灣是主戰場**：AppGrowing 2024-12：Capybara Go! 約 80% 營收（不含中國大陸）來自台日韓；Archero 2 約 70% 營收來自台港韓；Habby 11 月投放地區前七：香港、台灣、韓國、澳門、美國、新加坡、法國（[AppGrowing 2024-12-13](https://appgrowing.net/blog/en/nov_game/)）。Archero 2 上線即進港澳台 iOS 遊戲營收前三，上線後單日 > 1,100 組素材、Meta 占 95%+（[AppGrowing 2024-11-28](https://appgrowing.net/blog/en/archero_2)）。
  - Wittle Defender（2025）：台灣預約期每日素材由 < 50 組升至近 1,000 組，上線日 > 5,000、峰值近 10,000 組（[AppGrowing 2025-07-04](https://appgrowing.net/blog/en/hunaodilao/)）。
  - 北美：Capybara Go! 美國素材表現落後亞洲，需在地化（[Brutally Honest UA case 摘要](https://gameindustrylibrary.com/documents/brutally-honest-capybara-go-global-launch-ua-case)）。
- **廣告真實度**：**真實玩法為主**（廣告大量直接展示實機；Capybara Go! 用「角色一再被打敗」激起挑戰慾，AppGrowing 2024-11 稱為「心理戰」，[AppGrowing](https://appgrowing.net/blog/en/capybara/)）。
- **技巧 vs 選擇 vs 運氣**：走位閃避（技巧）+ 技能三選一（選擇）+ 技能出現順序（運氣，原作隨機）；後期被裝備數值主導。

## 一句話玩法

在敵潮中走位閃避，自動攻擊升級，每次升級從三個技能挑一個疊出流派。

## 為什麼廣告有效（Hook）

| 元素 | 說明 |
|---|---|
| 前 3 秒畫面 | 角色被數百隻怪包圍，技能特效清屏（Survivor.io）；或 Capybara 呆萌角色被反覆打倒（Capybara Go!）。 |
| 失敗誘導（fail bait） | 示範者選爛技能（例如只加移速）→ 被 Boss 秒；或站著不動被圍。Capybara Go! 的「一再被打敗」素材即此類。 |
| 「我來一定行」的錯誤示範 | 「三選一」選項在畫面上一目了然，觀眾自認知道哪個強。 |
| 爽感 / 解壓點 | 割草：成片怪物蒸發；技能進化（兩技能合成超武）的閃光時刻。 |

## 遊戲規格

> 「建議值」為本工作室規格；原作數值未取得者標（未證實）。

### 核心循環
1. 角色自動攻擊；玩家只控制移動。
2. 擊殺掉經驗寶石，撿起 → 升級 → 暫停並給 3 張技能卡選 1。
3. 每 N 分鐘一個精英 / Boss；撐到時限（原作 Survivor.io 一章 15 分鐘，未證實）或擊敗最終 Boss = 過關。
4. 局外：裝備、天賦、寵物升級（付費主軸）。

### 規則與勝負
- HP 歸 0 失敗；時限到 / Boss 死 勝利。
- Archero 系變體：房間制、**移動時不攻擊、停下才射**（走位與輸出互斥 → 技巧核心，未逐代證實）。

### 操作
- 浮動搖桿單指移動；技能卡點選。

### 關卡結構與難度曲線
| 關卡段 | 新元素 | 難度槓桿 |
|---|---|---|
| 0–1 分 | 慢速雜兵 | 熟悉移動 |
| 1–5 分 | 快速兵、遠程兵 | 密度上升、包圍 |
| 5–10 分 | 精英、彈幕 | 需要特定技能組合 |
| 10 分+ | Boss | 原作在此設數值牆（裝備不足必死）|

### 計分 / 星等 / 獎勵
- 原作：通關時間、擊殺數、章節進度；獎勵為裝備材料。

### 失敗與轉換點（廣告續命、IAP、導流到主遊戲的位置）
- 死亡時「看廣告復活」或鑽石復活；體力制；裝備抽取與戰令。
- 這是**本體**，非導流，但被 4X（Kingshot、Whiteout 等）借作素材視覺（「數字成長 + roguelike」，SocialPeta 2025-06 描述 Kingshot 素材）。

## 可玩廣告（Playable Ad）結構

- 20–30 秒：移動 10 秒割草 → 1 次三選一（其中一張明顯是「清屏大招」）→ 清屏特效 → Boss 出場時 CTA。
- 互動 2 種（拖曳、點卡）；Archero 2 素材 99%+ 為影片，playable 細節未證實。

## 技巧要素

| 技巧 | 影響 |
|---|---|
| 走位（風箏、繞圈聚怪） | 存活與擊殺效率的主因 |
| 拾取路線 | 經驗寶石分布 → 升級速度 |
| 技能構築 | 流派協同（例：投射數 + 穿透）|
| 停射時機（Archero 系） | 輸出與閃避的取捨 |

## 隨機 / 選擇噱頭

- **技能卡隨機**：原作每次升級的三選一由 RNG 抽，運氣成分大。
- **掉落隨機**：寶箱、道具、Boss 掉落。
- **局外數值**：裝備等級決定後期能否過關 → 錢買分數。

## Skill Game 化改造（必做）

> 用這份規格書做遊戲時（含「復刻」），玩法規格 `gdd/05_game_spec.md` §13 要逐條回應下列每一條：採用就寫本作做法，不採用就寫理由與替代做法。「復刻」只復刻玩法結構與操作，不跳過本節（`RULE-AF-ADAPTATION`，`npm run audit` 檢查）。

1. **技能卡同種子**：第 k 次升級的三張卡 = `rng(seed,"offer",k)` 打亂整池取前 3（見 01_skill-integrity §3）；雙方第 k 次看到的選項完全相同。因為玩家升級時機不同，用「第 k 次升級」而非「第 t 秒」取值。
2. **全部局內成長**：無裝備、無天賦、無寵物；起始條件完全相同。
3. **移除暴擊 / 機率掉落**：傷害固定；寶箱在固定擊殺數（每 100 殺）必掉，內容由種子決定。
4. **加入主動技巧**：Archero 式「停下才射」+ 一個 6 s CD 的翻滾無敵幀（0.25 s），讓高手能穿過彈幕。
5. **計分公式（建議）**：`Score = 擊殺數 × 1 + 精英 × 20 + Boss 擊殺剩餘時間(秒) × 10 + 無傷秒數 × 0.5`；死亡時保留當下分數。
6. **局長**：3 分鐘一局（原作 15 分鐘太長）：0–60 s 雜兵、60–150 s 精英兩波、150–180 s Boss。升級節奏壓縮為約 8 次升級。
7. **對戰**：非同步同種子排行榜；或「影子對戰」顯示對手同種子的分數曲線。

## HTML5 輕量實作規格

| 項目 | 規格 |
|---|---|
| 畫面 | 直版 720×1280；世界 2,000×2,000 可捲動或固定 720×1280 競技場（建議固定，公平視野 E3）|
| 實體與資料結構 | 敵 SoA ≤ 600、投射物 SoA ≤ 800、經驗寶石 SoA ≤ 400（物件池）；技能為資料驅動表 `{id, level, cd, dmg, count, pierce}`；空間雜湊 cell 32 px |
| 關鍵參數 | 玩家速 200 px/s；敵速 60–140 px/s；接觸傷害 10、玩家 HP 100；升級經驗曲線 `need(k)=5+3k`；翻滾 15 tick 無敵、360 tick CD |
| 渲染 / Draw Call 估計 | 地面 tile 1；敵 + 玩家 + 寶石（同 atlas）1；投射物（加色）1；BitmapText 傷害數字 1；技能卡 UI 為 DOM（0 DC）→ **4 DC**。600 敵 + 800 彈同材質合批；數量再上升改 `ParticleContainer`。清屏特效用 sprite 擴散環，不用 filter |
| 美術資產清單 | 主角 4 向 × 4 幀、敵 6 種 × 3 幀、Boss 1（Spine 可選）、投射物 8 種、寶石 3、技能圖示 24（UI atlas，WebP）、地面 tile 1 |
| 包體估計 | 程式 1.1 MB；遊戲 atlas 0.7 MB；UI 圖示 0.2 MB；音效 0.3 MB；BGM 1.5 MB → **≈ 3.8 MB** |

## 主題與美術風格

- 原作：Survivor.io 現代殭屍、Capybara Go! 呆萌動物、Archero 2 Q 版奇幻；在台投放常搭配舞蹈網紅、TikTok 迷因（AppGrowing 2024-11）。
- 改造：Q 版動物 / 小精靈最省美術；避開寶箱開箱光芒、抽卡金光（博弈聯想）。

## 可借用 / 要避開

- **可借用**：廣告即實機——Habby 在台灣證明這類真實玩法素材能大量投放；三選一的「構築爽感」；翻滾無敵幀的高手空間。
- **要避開**：隨機技能卡、局外裝備、看廣告復活、體力制；15 分鐘以上局長。
