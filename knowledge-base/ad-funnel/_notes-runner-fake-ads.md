**台灣 vs 北美的差異（歸納）**

- 北美：4X 主力（Last War、Kingshot、Whiteout）、gate 類素材、名人代言（Kingshot 找足球員，[Mobilegamer.biz](https://mobilegamer.biz/century-hires-a-flurry-of-footballers-for-kingshot-ad-spots-during-world-cup/)；Last War 找 Antony Starr，[Notebookcheck](https://www.notebookcheck.com/Jemand-hat-tatsaechlich-eines-dieser-Fake-Werbespiele-gemacht-und-es-ist-ueberraschend-gut.1188721.0.html)）；Capybara Go! 在美素材表現落後亞洲（[Brutally Honest UA case](https://gameindustrylibrary.com/documents/brutally-honest-capybara-go-global-launch-ua-case)）。

## 2. 「假廣告」現象的演變

1. **2019–2020 純假廣告期**：Hero Wars 以拉針謎題廣告起家，與 idle RPG 本體無關；Evony 同年跟進（[PocketGamer.biz 2025-01-03](http://www.pocketgamer.biz/the-evolution-of-pull-the-pin-why-is-this-a-good-thing-for-the-games-industry/)）。Playrix 的拉針小遊戲僅約 0.03% 玩家到得了，2020 遭 ASA 禁播（[Marketing-Interactive](https://www.marketing-interactive.com/popular-mobile-games-gardenscapes-and-homescapes-called-out-for-misrepresentation-of-game-in-ads)）。
2. **「把假廣告做成真的」**：Hero Wars 2019 起把謎題放進遊戲（[Aftermath](https://aftermath.site/so-i-dont-totally-hate-those-hero-wars-ads.md)）；Playrix 把拉針關移到前期；Royal Match 加入「King's Nightmare」救國王特殊關；Lily's Garden、Angry Birds Dream Blast 也加入拉針。
3. **2023–2026 漏斗化（onboarding funnel）**：廣告 → 與廣告相同的前導小遊戲 → 漸進轉入付費核心。Last War（門型射擊 → 4X）、Kingshot（仿 Thronefall 塔防 → 4X）、Carnival Tycoon / Top Tycoon（idle 大亨 → 骰子 / 博弈式核心）（[Lancaric 2025-11](https://lancaric.substack.com/p/the-rise-of-sophisticated-onboarding)、[Gamigion](https://www.gamigion.com/?p=24490)）。Gamigion 稱 FirstFun 量測「廣告玩法」與「核心玩法」留存曲線調節轉換節奏（推測，未證實）。小遊戲保留為支線，但後段由主城數值主導 → 技巧不再決定勝負。
4. **真實玩法素材回歸**：Kingshot 最高曝光素材是實機；Habby 系廣告即實機；Reforged Labs 觀察到 Kingshot 少用失敗誘導。另一方面，同一批 4X 也大量用 AI 生成與真人短劇素材（Kingshot 單日 2,000 支）。
5. **反諷與「轉正」作品**：*Those Games*（2023）/ *Those Games 2*（2024）把 Pin Pull、Number Tower、Numbers Dungeon、Draw & Guard、過門射擊等做成主機 / PC 正式遊戲，各 250 關（[Wikipedia](https://en.wikipedia.org/wiki/Those_Games)）；*Real War (Not Fake)*（2025-11，iOS / Android）把 Last War 廣告的「射數字」做成真遊戲並加排行榜（[Notebookcheck](https://www.notebookcheck.com/Jemand-hat-tatsaechlich-eines-dieser-Fake-Werbespiele-gemacht-und-es-ist-ueberraschend-gut.1188721.0.html)）。A.V. Club 評 *Those Games*：只有拉針撐得起整個遊戲，其他模式深度不足——**選擇噱頭直接搬過來不夠，需要加技巧**。

## 3. 法規與平台壓力

| 地區 / 機構 | 規範 / 案例 | 重點 |
|---|---|---|
| 英國 ASA / CAP | Playrix Homescapes / Gardenscapes（2020）| 小遊戲只有極少玩家能到；「Not all images represent actual gameplay」免責無效 |
| 英國 ASA | Evony（Top Games，**2024-04-03**）| 射數字桶廣告違反 CAP Code 3.1：遊戲雖有類似小遊戲，但核心是城建；未來廣告須反映核心體驗（[ruling](https://asa.org.uk/rulings/top-games-inc-a23-1213924-top-games-inc.html)）|
| 英國 ASA | Gold and Goblins（AppQuantum，日期未證實）| 實際玩法與廣告顯著不同；應只用實機或清楚標示模擬片段（[Osborne Clarke](https://marketinglaw.osborneclarke.com/advertising-regulation/whats-a-gold-to-a-goblin/)）|
| 英國 ASA | 2025-09 KamaGames「無內購」宣稱誤導；2025-11 多件 App Store 頁面的隨機付費物揭露不足（[CMS](https://cms.law/en/gbr/legal-updates/asa-rules-that-kamagames-ltd-t-a-blackjackist-misled-consumers-with-no-purchases-advertising)、[Foot Anstey](https://www.footanstey.com/our-insights/articles-news/marketing-matters-review-of-november-2025/)）| 2025 年焦點轉向付費揭露，未查到 2025–2026 新的「玩法不符」裁決（未證實是否存在）|
| 中國 CADPA | 遊戲廣告標準（**2025-02-06 生效**）| 禁止展示遊戲中不存在的玩法 / 事件、禁用第三方素材、禁操弄評分；違者可警告、罰款、禁投、停運（[WN Hub](https://wnhub.io/news/marketing/item-47009)）；屬協會標準，法律效力未證實 |

| Google Play | 未查到 2025–2026 針對「站外廣告玩法不符」的明文（未證實）；2022 年政策針對插頁廣告干擾 | — |
| 美國 FTC | 未查到 2024–2026 針對遊戲玩法不符廣告的執法案例（未證實）| — |
| 台灣 公平會 | 公平交易法第 21 條（虛偽不實廣告）；遊戲類處分集中在**機率不實**（新楓之谷 2023 罰 200 萬、天堂M 2022 罰 200 萬）；2024-02 立委提案將罰鍰上限由 2,500 萬提高至 3 億（[自由時報](https://ec.ltn.com.tw/article/breakingnews/4428198)、[CNA](https://www.cna.com.tw/news/aipl/202402290201.aspx)）| 未查到「廣告畫面與實際玩法不符」的處分案（未證實），但第 21 條文義可涵蓋 |

**結論**：監管一致方向是「廣告要代表核心體驗」，免責字樣無效，且「遊戲裡有這個小遊戲」不足以抗辯（Evony 案）。對我們最安全的做法：**廣告 = 實機 = 遊戲全部**。

## 4. 給 Skill Game 工作室的教訓

1. **我們天生沒有假廣告問題——把它當賣點。** 我們的遊戲就是那個小遊戲；可以學 *Real War (Not Fake)* 的反諷定位：「廣告裡的遊戲，這次是真的，而且比技術」。
2. **只借「Hook 結構」，不借「選擇噱頭」。** 前 3 秒危機 + 數字暴漲 + 失敗誘導是可借的；但「選大的門」「選小的怪」這種一眼可解的抉擇不能當競技核心——*Those Games* 評論與我們的 E1 / E5 都指向同一件事。每個格式都要加入**連續控制量**（走位、時機、流量、瞄準、分配比例）。
3. **失敗誘導要對應真實的技巧缺口。** 我們的素材可以展示真玩家的失敗，但失敗原因必須是操作（沒閃過、時機早了），不是「選錯了」——這樣觀眾的「我來一定行」才會在遊戲裡被兌現或被挑戰。
4. **數字暴漲很爽，但計分要 log 化或封頂。** gate / tower 類的指數成長若直接當分數，會讓分數失去比較意義且容易溢位；結算逐項列出（E4）。
5. **局外養成是這些格式在原作中「被付費接管」的地方，全部移除。** 起始人數、射速、裝備、建築等級、看廣告復活——一律刪；成長只在局內，且由同種子決定。
6. **素材量是 2026 的主戰場，實機素材有效。** 策略類素材數月增 53%（AppGrowing），Kingshot 實機割草是最高曝光。我們的確定性重播可以**自動產出大量真實素材**（同種子不同高手的重播、極限通關剪輯），成本比 AI 短劇低且無法規風險。
7. **台灣市場偏好 roguelite 割草與 SLG，素材偏網紅舞蹈；北美偏 4X、名人、gate。** 首發台灣可優先做 [af-survivor-skill-pick](af-survivor-skill-pick.md) 或 [af-horde-defense](af-horde-defense.md) 型；北美測 [af-gate-runner](af-gate-runner.md) 的分配版。
8. **最容易做成技巧遊戲的排序**：畫線護主（物理 + 一筆畫）> 倖存者割草（走位）> 守城割草 > 加乘門射擊（手動射擊版）> 過橋搶磚 > 群體加乘門（分配版）> 拉針（加流量控制）> 數字塔（需即時化才成立）。
